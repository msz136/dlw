# 方向 C — 结论清单（每条注明证据等级与 Lean 定理名）

等级标签：`实验验证` / `Lean 代数验证` / `Lean 结构验证` / `数学证明，尚未完整形式化`。
对象：DLW 系统 (1)–(2)，`λ = -2`，`a` 任意，**仅** `y` 方向离散，`x,t` 连续。

---

**C1.** 在 (1')–(2') 中 `y` 导数只通过约束 `w = u_y` 出现，故任何 `y` 离散对半离散系统的
影响恰好是一对 `(M_h, D_h)`；三个变体（一致质量 P1、集中质量 P1、P0/P1 DG 迎风）都是这对
对象的不同取法。
证据等级：`数学证明，尚未完整形式化`（结构恒等式来自 spec §1.1 [MAIN-VERIFIED — V5] 的逐项改写）。
Lean：`unformalised`（半离散 PDE 层面，本方向未形式化 PDE）。

**C2.** P1 单元质量矩阵为 `(h/6)[[2,1],[1,2]]`（对角 `h/3`），`det = h²/12 ≠ 0`（`h ≠ 0`）；
单元与整体行都严格对角占优。
证据等级：`Lean 代数验证` / `Lean 结构验证`。
Lean：`p1_mass_entry`、`p1_mass_det`、`p1_mass_det_ne_zero`、`p1_mass_diag_dominant`、
`p1_mass_global_diag_dominant`。

**C3.** 质量矩阵**不**产生任何虚假核：质量符号 `2+cosθ ∈ [1,3]`，处处非零，Nyquist 处为 `1`。
证据等级：`Lean 结构验证`。
Lean：`mass_symbol_bounds`、`mass_symbol_ne_zero`、`mass_symbol_at_nyquist`。

**C4.** P1 单元刚度矩阵为 `(1/h)[[1,-1],[-1,1]]`，精确湮灭常数向量与常数二次型；
整体刚度符号在 `θ=0` 为零。这是 §5.1 零模精确保留的基础。
证据等级：`Lean 结构验证`。
Lean：`p1_stiffness_kills_constant`、`p1_stiffness_quadform_constant`、
`p1_stiffness_symbol_at_zero`。

**C5.** 一致质量 P1 的半离散符号为
`μ_h(ℓ) = i·3 sin(ℓh)/(h(2+cos ℓh)) = iℓ·R(ℓh)`，`R(θ) = 3 sinθ/(θ(2+cosθ))`
（自行由 `M`、`Aᵀ` 的三点符号推导，与提示一致）。
证据等级：`实验验证`（SymPy 精确符号差 `A3 = 0`；节点级数值 `C3` 与闭式吻合到 1e-12）。
Lean 相关：`p1_symbol_normalisation`（代数骨架 `R·θ(2+cosθ) = 3 sinθ`）为 `Lean 代数验证`。

**C6.** `R(θ) = 1 - θ⁴/180 - θ⁶/1512 - θ⁸/25920 + O(θ¹⁰)`，从而
`μ_h(ℓ) - iℓ = -iℓ⁵h⁴/180 + O(h⁶)`：一致质量 P1 是 **4 阶符号相容**（节点导数超收敛）；
数值误差比恒为 `16`（`h` 减半）。
证据等级：`实验验证`；极限/余项**未形式化**（缺口 G1）。
Lean：`p1_symbol_deviation` 给出精确商式（`Lean 代数验证`），但 `R → 1` 本身 `unformalised`。

**C7.** 集中质量（行和）P1 使 `M = hI`，此时 `D_h` 退化为中心差分，`μ_h = i sinθ/h`，
只有 2 阶符号精度。
证据等级：`数学证明，尚未完整形式化` + `实验验证`（三点符号）。
Lean 相关：`ctr_symbol_nyquist_zero`（`Lean 代数验证`）。

**C8.** P0 DG 迎风给出 `M = hI`、`D_h U|_j = (U_j-U_{j-1})/h`，
`μ_h = (1-e^{-iθ})/h = iℓ + hℓ²/2 + O(h²)`：**1 阶**相容，实部 `(1-cosθ)/h ≥ 0`（耗散）。
证据等级：`数学证明，尚未完整形式化`；`Re μ_h ≥ 0` 与 `|1-e^{-iθ}|²` 恒等式为 `Lean 结构验证`
(`dg_symbol_re_nonneg`, `dg_symbol_norm_identity`)；`O(h)` 阶数为 `实验验证`（SymPy A9/A11、数值 C8）。

**C9.** 迎风 `y` 迁移算子满足精确耗散恒等式
`2Σ_{j<N} u_{j+1}(u_{j+1}-u_j) = Σ(u_{j+1}-u_j)² + u_N² - u_0²`，故零边界数据下非负；但它
**不是**反对称算子（无 SBP），耗散只作用于 `y` 导数项。
证据等级：`Lean 结构验证`。
Lean：`dg_upwind_dissipation_identity`、`dg_upwind_dissipation_nonneg`。

**C10.** P1 DG 迎风（每单元 2 自由度，左迹迎风）：物理支 `μ_h = iθ/h + θ⁴/(72h) + O(θ⁵)`
（`O(h³)` 精度），寄生支 `≈ 6/h - 3iθ/h - θ²/h`（被强阻尼），
Nyquist 处 `μ_h = (1±i√11)/h ≠ 0`。
证据等级：`实验验证`（SymPy Bloch `2×2` 铅笔解，输出 B1）；未形式化（缺口 G7）。

**C11.** **否面结论（FEM 特有）**：一致质量 P1（以及中心差分）的 `μ_h` 在 Nyquist 消失：
`μ_h(π/h) = 0`，故 `D_h = M^{-1}Aᵀ` 有一个由交错向量 `(-1)^j` 张成的**虚假核**，
半离散系统退化为 DAE；该零**不来自质量矩阵**（C3），而来自 `sinθ` 的刚度/迁移符号。
证据等级：`Lean 代数验证`。
Lean：`muP1_nyquist_zero`、`ctr_symbol_nyquist_zero`；带内无零由 `p1_symbol_pos_in_band` 支持。

**C12.** **否面结论**：在退化模（P1 的 Nyquist 模与 `ℓ=0` 模）上离散铅笔化为
`σ² + iAkσ + i(v₀+2λ)k³ = 0`，给出与连续色散无关的**虚假 `O(1)` 增长**：
`u₀=0.4, a=0.7, λ=-2, v₀=1.1, k=1.3` 时 `σ = -1.6043-3.1556i` 与 `+1.6043+0.8156i`
（`Re σ = ±1.6043`）。这是"一致质量 P1 无 Nyquist 零"这一候选被**否定**的显式反例。
证据等级：`实验验证`（C7 输出）；`unformalised`。

**C13.** DG 迎风**没有** Nyquist 零：P0 的 `μ_h(π/h) = 2/h ≠ 0`（P1 DG 为 `(1±i√11)/h`），
故无虚假核、约束 `w = D_h u` 精确可解——这是 DG 变体优于一致质量 FEM 的关键结构差异。
证据等级：`Lean 结构验证`。
Lean：`dg_symbol_no_nyquist_zero`、`dg_symbol_re_at_nyquist`。

**C14.** **局部性（FEM 特有发现）**：单元/张量层严格局部（`M`、`A`、`K` 三对角，三乘积张量 `T` 带状），
但一致质量 FEM 必须求逆 `M`，而均匀周期网格上
`(M_h^{-1})_{jk} = (√3/h)Σ_{w∈ℤ} r^{|j-k+wN|}`，`r = √3-2 = -0.267949`，
即 `M^{-1}` **稠密**、每个节点与所有节点耦合。局部性的恢复只能是条件性的：
(a) 指数衰减截断，误差约 `0.268^{m+1}`；
(b) `M = h(I+(h²/6)Δ)` 的 Neumann 级数截断到 `M` 项给出 `(2M+1)`-带状局部算子，
算子范数误差 `≤ (3/h)(2/3)^M`。
证据等级：`实验验证`（与 `np.linalg.inv` 偏差 `5.6e-16`，衰减比 `0.26795/0.26804`）+ `数学证明，尚未完整形式化`（缺口 G2/G3）。

**C15.** P0 DG 迎风（`M = hI`）在 `y` 方向**完全局部**（仅最近邻耦合）；一致质量 FEM 用非局部
`M^{-1}` 换取 `O(h⁴)` 符号精度。这是两条路线的核心取舍。
证据等级：`数学证明，尚未完整形式化`（同 C8/C14）。

**C16.** 连续极限正确：`μ_h(ℓ) → iℓ` 且 `x,t` 未离散，故半离散系统对 `h` 的形式极限逐项为
(1')–(2')，即 (1)–(2)（spec V5 逐系数恒等），经 VT 即论文 (6)–(7)（`λ=-2`）。
但离散层面**没有**双线性结构（Galerkin 把乘积换成 `T` 与 `M^{-1}`），不存在 FE/DG 的离散 tau 解族。
证据等级：`数学证明，尚未完整形式化`；`unformalised`。

**C17.** 提示给出的离散色散关系需更正：正确形式为
`(σ + i(u₀+2a)k)² = k⁴ − i(v₀+2λ)k³/μ_h(ℓ)`（多一个因子 `i`）；代入 `μ_h = iℓ` 精确还原
spec §2 [V6]。逐模数值验证：`k = 0.7 / 1.3 / 2.5` 时"组装矩阵 → 逐模符号 → 逐模铅笔"
与上式吻合到 `1.490e-15 / 1.110e-15 / 3.972e-15`。
证据等级：`实验验证`（含推导）；`unformalised`（缺口 G4）。

**C18.** **standing obstruction 不受 `y` 离散影响**（必须显式声明的否面结论）：
`k⁴` 项来自 `x` 结构、不含 `y` 导数，故任何 `(M_h, D_h)` 都无法改变 `|Re σ| ~ k²`（实 `k`）。
因此本方案**没有**、也不可能有对一般初值的无条件适定/网格一致稳定/收敛结论；
FEM 的隐式性、DG 的耗散、零模精确保留、离散守恒**均不能**消除它。
证据等级：`数学证明，尚未完整形式化`（依赖 spec §2 [MAIN-VERIFIED — V6]）；`unformalised`。

**C19.** 条件性稳定/一致性结论（唯一可主张的形式）：
(C1) 固定 `h` + 有限 `x` 频带 `|k| ≤ K` + 非退化 `y` 模：`σ` 有限但增长率仍 `≳ K²`，无一致界；
(C2) 具名精确解族 `v ≡ 4, u = U(x,t), u_y = 0` 被精确保持（两方案都精确湮灭常数，C4）；
(C3) 在 `v₀ = -2λ = 4` 背景上 `k³/μ_h` 项消失，离散色散对**所有** `y` 模与 `h` 等于连续色散，
退化模方程退化为 `σ² + iAkσ = 0`，根 `σ = 0`（零模）与 `σ = -iAk`（数值 `C7`: `0` 与 `-2.34i`），
与 spec V6/V7 一致；
(C4) DG 迎风的 `Re μ_h > 0` 只把 `k³/μ_h` 平移 `O(h)`，对 `k⁴` 无作用。
证据等级：`实验验证` + `Lean 结构验证`（C4 的常数湮灭部分）；定性部分 `数学证明，尚未完整形式化`。

**C20.** VT 可行性：离散层面**不可行**——(i) `ln∘插值 ∉ V_h`，Galerkin 解要求
`U = M^{-1}b`、`b_i = ∫2∂_x ln(f_h/g_h)φ_i`，一般 ≠ `2∂_x ln(F_i/G_i)`（质量矩阵耦合，无闭式）；
(ii) P1 的 `Aᵀ` 在 Nyquist 退化使约束 `w = u_y` 不可解，由 VT 逐点生成的 `u_h` 一般不满足约束；
(iii) 双线性恒等式不是 Galerkin 投影的不变量。
唯一正面点：P1 插值保正性使 `ln(f_h/g_h)` 逐点良定义（离散极值原理），高阶/谱方法无此性质。
VT 只在 `h→0` 连续极限层与方案相容。
证据等级：`数学证明，尚未完整形式化`；`unformalised`（缺口 G6）。

## 汇总

* 正面（Lean 结构验证）：C2、C3、C4、C8(部分)、C9、C13。
* 否面（显式反例/矛盾，均已限定范围）：C11、C12（一致质量 P1 的 Nyquist 零与虚假增长）、
  C18（standing obstruction 不可移除）、C20（VT 离散不可行）。
* 实验验证（SymPy/NumPy，未形式化）：C5、C6、C7、C10、C14、C15、C17、C19。
* `unformalised`：C1、C16、C18、C20 及 C6/C12/C14/C17/C19 的分析部分。
* 全部结论均为**半离散**；`x,t` 未离散，两类守恒不混谈。
