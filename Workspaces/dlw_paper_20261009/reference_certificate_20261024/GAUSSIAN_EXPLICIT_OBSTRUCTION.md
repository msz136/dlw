# 周期高斯：带显式常数的横向正则性障碍

2026-10-24。续接 `TAIL_ESTIMATE_CONTINUATION.md` 第5节。本轮重新检查三角层级、树展开、符号和频率求和，并补足一个统一的显式常数。状态：经过本会话复核的数学证明稿及 Arb 常数核验；不是独立审稿或形式化核验。没有得到原初值连续全场参考解的误差认证。

## 1. 对象与结论

保持原周期192、z=y+2∈[0,4]、u(x,0,t)=0，以及获准的周期高斯初值不变：

    u0=.05 sin(πz/4) G(x), v0=.03 sin(πz/4) G(x),
    G(x)=Σ_j exp(-((x+192j)/6)^2).

记 d=π/96，σ=9，c=π/80，C_G=√π/32。随动坐标 X=x−4t 中，a=u_z+v、b=u_z−v 满足

    a_t=−a_XX−(ua)_X+4u_X,
    b_t= b_XX−(ub)_X−4u_X,
    u=(1/2)∫_0^z(a+b)ds.

令 a_m=∂_z^m a(X,0,t)/m!，b_m 同理。假设解在闭时间区间内具有至m阶的这些边界迹，并有充分的x,t正则性，使原方程的z微分、边界取迹、Fourier系数及Duhamel公式成立。通常的、具有所述阶数混合导数的经典解满足这些条件；仅声称弱解或有限低阶经典解并不自动满足。

取 N=901、m=900、t*=1801/180200。若上述假设成立，则对 K=dNℓ、ℓ为正整数且K⁻²<t*，必有

    Re(i^900 â_900(Nℓ,t*))
      ≥ C K^−900 exp(K²/180200) − D exp(−K²/360400),             (E1)
    C=e^−1 N(c C_G)^N/(2N)^900 > exp(−12265),
    D < exp(26000).

右端随ℓ增长快于任意多项式，与周期分布的Fourier系数至多多项式增长矛盾。因此，这一初边值问题在[0,.01]上没有满足上述900阶a,b边界正则性的解。相应涉及u的901阶、v的900阶横向导数。

例如在ℓ=5000，即原周期Fourier指标n=4,505,000，(E1)已给出严格下界exp(97000)。这是归一化的900阶边界导数系数的条件性下界，**不是u或v的物理幅值下界，不是候选误差下界**。单个有限频率本身也不推出分布矛盾；非存在性使用ℓ→∞的整条序列。

## 2. 三角层级与展开次数

Leibniz公式给出

    U_j=(a_(j−1)+b_(j−1))/(2j), U_0=0,
    (a_m)_t=−(a_m)_XX−∂_X Σ_(j=1)^m U_j a_(m−j)+4∂_X U_m,
    (b_m)_t= (b_m)_XX−∂_X Σ_(j=1)^m U_j b_(m−j)−4∂_X U_m.  (E2)

逐层Duhamel代入产生有限种树结构，但每种仍含无限离散频率求和和时间积分。每个二次节点降低总横向阶数1；每个线性节点也降低1。若叶子的初始横向阶数之和为q，总内节点数为h，则q+h=m。故h≤m，Gaussian叶子数p≤m+1。

最大p=m+1恰有m个二次节点、无线性节点，且全部叶子来自a_0、b_0；其初始Fourier系数都是正的c C_G exp(−σξ²)。所有树有共同相位(−i)^m；除此之外，符号只来自内节点的输出频率乘积。

任意初始a_j或b_j的每个Fourier系数均为λ_j exp(−σξ²)，其中|λ_j|<1：可用

    |λ_j| ≤ C_G(.05κ^(j+1)+.03κ^j)/j! < 1, κ=π/4<1.

这个宽松界也包括高阶初始sin导数的正负号。

## 3. 所有应扣除项的共同指数

设叶子频率为ζ_1,…,ζ_p∈dZ，K=Σζ_j，S=Σζ_j²。任意时刻活动子树划分叶子集，故热传播指数满足

    E=−σS+∫Σ_C s_C K_C² ds, s_C∈{−1,1}.

对p≤N−1，由Σ_C s_C K_C²≤pS得到E≤−(σ−pt*)S。

对p=N、至少一个叶子非正的项，K>0时有S≥K²/(N−1)。顶层生成时间τ之前，每个真子树最多含N−1个叶子，故

    E≤−[σ−(N−1)τ]S+(t*−τ)K².

设

    γ=1/180200,
    θ=1/3604,
    α=9/6494408=θ[σ−(N−1)t*].

把方括号的系数分成θ与1−θ两部分，并用S≥K²/(N−1)，得到

    E≤−αS−γK²/2.                                             (E3)

具体而言，剩下的K²系数不大于−γ+θσ/(N−1)=−γ/2；其中−θτ≤0被舍去。对p≤N−1也有(E3)，因为

    σ−pt*−α−pγ/2 ≥ (N−1)γ/2−α >0.

因此低次数的全部项和最大次数中全部含非正叶子的项，可用同一个Gaussian矩上界处理。其余最大次数项的所有叶子均正，提出共同相位后均非负，不需扣除。

## 4. 显式求和常数

首先控制树结构的总绝对系数。忽略频率导数、Gaussian因子和热传播，把每个初始叶子的绝对系数替换为1；a_m,b_m两种输出合计的树系数总和用W_m控制。由(E2)，有

    W_0=2,
    W_m ≤ 2 + (1/2)Σ_(j=1)^m W_(j−1)W_(m−j) + 4W_(m−1).

这里舍去的1/j和1/m只增大上界。以等号定义右侧majorant，其非负生成函数为

    W(s)=2/(1−s)+(s/2)W(s)^2+4sW(s).

在s=1/32处，右侧对W=4的值为64/31+1/4+1/2<4。从零开始的正迭代有界且单调，故系数和收敛并有

    W_m ≤ 4·32^m.                                             (E4)

每树至多m次空间微分，每次输出频率绝对值≤Σ|ζ_j|。因此所有频率多项式被(1+Σ|ζ_j|)^m控制。时间积分域包含于[0,t*]^h⊂[0,1]^h，体积≤1，不再产生增大的因子。

由Σ|ζ_j|≤√(NS)及(1+r)^m≤2^m(1+r^m)，

    (1+Σ|ζ_j|)^m exp(−αS)
       ≤ 2^m[1+(Nm/α)^(m/2)] exp(−αS/2).

此处使用sup_(S≥0) S^(m/2) exp(−αS/2)=(m/(αe))^(m/2)，再舍去e。解除输出频率约束只增大绝对和，且由单调Gaussian的积分比较，

    Σ_(n∈Z) exp(−αd²n²/2) ≤ 1+√(2π/α)/d = Z.

p≤N且Z>1，故所有应扣除项合计至多D exp(−γK²/2)，其中

    D=4·64^m [1+(Nm/α)^(m/2)] Z^N.                            (E5)

这是有限的显式常数，不依赖输出频率K。Arb区间计算给出25923<log D<25924，因此可取更宽的D<exp(26000)。

## 5. 保留的正链与严格不等式

在最大次数项中保留每次取−∂_X(a_0 a_(j−1)/2)的全a链，全部N个叶子频率均为K/N=dℓ。令m个生成时间位于0<s_1<…<s_m<δ=K⁻²<t*。积分体积为δ^m/m!；内节点频率乘积为N!(K/N)^m；非顶层反热传播均≥1，顶层传播≥exp(t*K²−1)。于是这一项至少为

    e^−1 N(c C_G)^N/(2N)^m · K^−m exp[(t*−σ/N)K²].

t*−σ/N=γ，合并(E3)–(E5)即得(E1)。低层在t*<σ/(N−1)下由Gaussian支配绝对收敛。临界层的固定输出K亦可用真子树估计、σ−(N−1)t*>0保证求和绝对收敛。因此并未在未定义的乘积或发散频率和上使用形式抵消。

`explicit_obstruction_check.py`用256-bit Arb核对所有阈值、生成函数上界及ℓ=5000示例，结果在同名JSON中。该计算只核验上述显式实数不等式；数学推导和函数空间假设不能由数值断言替代。

## 6. 对当前参考解请求的实际含义
