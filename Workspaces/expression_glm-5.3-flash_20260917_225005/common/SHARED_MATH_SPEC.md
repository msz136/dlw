## 1. 连续系统与约定

原系统（Sheng & Yu, Physica D 432 (2022) 133140, DOI 10.1016/j.physd.2021.133140, 式 (1)(2)）：

    u_yt + v_xx + u u_xy + u_x u_y + 2a u_xy = 0                      (1)
    v_t + (u v)_x + u_xxy + 2a v_x + 2λ u_x = 0                      (2)

首轮约定：λ = −2（论文行 134），a 任意。u = 水平速度，v = 波高。
x, t 连续；只沿 y 离散。h > 0 为格距；格点 y_j = jh（整数点），Y_j = (j+1/2)h（半点）。

非线性改写（主 Agent 已验证 ⇔，见 RUN_CONTEXT M1；假设 u 光滑、混合偏导相等）：

    w := u_y
    w_t + ∂_x[v_x + (u + 2a) w] = 0                                  (W1)
    v_t + ∂_x[(u + 2a) v + w_x + 2λ u] = 0                           (W2)

λ=−2 时 (W2) 中 2λu = −4u。(W1) 中 ∂_x[(u+2a)w] = (u+2a)w_x + u_x w。

## 2. 常数背景线性化（所有方向必须正视）

背景 (u0, v0) 常数，扰动 e^{st+i(kx+ℓy)}，ℓ ≠ 0（主 Agent M2/M3 已验证）：

    eq1:  i ℓ s U − k² V − (u0+2a) k ℓ U = 0
    eq2:  (s + i(u0+2a)k) V + i k (v0 + 2λ − k ℓ) U = 0
    色散:  [s + i(u0+2a)k]² = k⁴ − (v0 + 2λ) k³/ℓ

结论（M4）：固定 ℓ≠0、|k|→∞ 时 |s| ~ k²（s/k² → ±1），连续问题对一般初值沿 y 强不适定。
推论纪律：

- 任何"稳定性/收敛性"主张必须限定：有限频带初值、或修改后的问题（加耗散/滤波/正则化须说明改变了什么）。
- 隐式、守恒、有限元、辛等结构性质不消除此障碍，不得作为反驳。
- 离散谱与连续谱对照是每个方向的必做诊断：对离散 ℓ-模态，比较离散 s(k, ℓ) 与连续色散。
