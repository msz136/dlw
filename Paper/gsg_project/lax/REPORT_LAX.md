# GSG 半离散 DLW 双线性对：离散 Lax 对与守恒量

**问题**：为交错格式 (6)(7)（`a∓h/2`）找一个**含谱参数的离散 Lax 对**，
以及**一族守恒量**，判断这个离散系统本身是否有可积结构、而不只是"一个格式"。

**结论一句话**：**存在含谱参数的离散 Lax 对，且非平凡**——
`L_n(z) = (z+α_{n+1})/(z+α_n)`，`ψ_{n+1}=L_nψ_n`，与 `x/y/t` 流相容；
但它的**单值矩阵的迹恒等于常数（与 z 无关）**，因此离散方向
**不产生正维数的 Floquet 谱曲线**。守恒量来自**连续方向**。

---

## 0. 记号、论文定义与经过验证的实现

论文（Sheng–Yu, Physica D **432** (2022) 133140）Lemma 2.1 与 (12)–(15)：

```
τ_n = det(m_ij^{(n)}),   1 ≤ i,j ≤ N
m_ij^{(n)} = c_j δ_ij + (1/(p_i+q_j)) (−(p_i−a)/(q_j+a))^n  e^{ξ_i + η_j}
ξ_i = p_i x − p_i² t + y/(p_i−a),    η_j = q_j x + q_j² t + y/(q_j+a)
u = 2(ln f/g)_x ,  v = 2(ln fg)_{xy} ,  f = τ_{n+1} ,  g = τ_n
```

**一个必须记录的技术要点（也是本次会话的主要陷阱）**：因为
`e^{ξ_i+η_j} = R_i C_j` 是秩一因子，把 `m_ij` 拆成 `δ` 部分与秩一部分后，
只能用**矩阵行列式引理** `det(I+RAC)=det(I+ACR)=det(I+B)`（`B_ik = A_ik C_i R_k`），
而**不能**用"对角化 E"的写法。据此得到精确的**主子式展开**

```
τ_n = Σ_{S ⊆ {1..N}} det( B[S] ) ,   B_ik = c_k (coeff)_ik e^{ξ_i + η_k}
```

实现 `lax/tau4.py`；在 `c_j = 1`（论文取法）下，主子式展开与**字面 Gram 行列式**
两条独立路径在 60 位精度下对 `N = 1..4`、`n = −1..2` **逐位吻合**（`lax/v4.py`）。

> ⚠️ 这纠正了此前会话中"`τ_n = C·γ^n`、`σ_n ≡ 1`"的结论：那是行列式展开漏掉
> 单位项（以及错误的因子分解）造成的假象。真实情况见第 3 节。

**离散对象**（沿用 `dlw_semidiscrete/REPORT.md` 的口径）：

```
F_j := τ_1(j; a−d) ,   G_j := τ_0(j) ,   d := h/2
(7)_h :  B_{a−d} F_j · G_j = 0 ,   (6)_h :  B_{a+d} F_j · G_{j+1} = 0 ,
B_s := D_x² + D_t + 2s D_x
```

## 1. 离散 Lax 对（含谱参数 `z`）——存在且已验证

取**秩一谱形变** `M(n) ↦ M(n) + z^{−1} u vᵀ`（`u_i = p_i`, `v_k = q_k`），定义波函数

```
ψ_n(z) := τ̂_n(z)/τ_n ,      τ̂_n(z) := det( M(n) + z^{−1} u vᵀ )
```

**事实（`lax/wave.py`, `lax/FINAL2.py`, `lax/mono.py`，80 位精度）**：
`ψ_n(z)` 恰是 `z` 的 **Möbius 函数**

```
ψ_n(z) = 1 + α_n / z ,        α_n = (uᵀ adj(M(n)) v) / τ_n
```

于是得到**含谱参数的一阶离散线性问题**

```
ψ_{n+1}(z) = L_n(z) ψ_n(z) ,      L_n(z) = (z + α_{n+1}) / (z + α_n)
```

即 `(z + α_n) ψ_{n+1} = (z + α_{n+1}) ψ_n`。数值本征值：

| n | α_n |
|---|---|
| 0 | 132.7844551792145 |
| 1 | 178.0809944572637 |
| 2 | 155.8024595110603 |
| 3 | 170.0324616848987 |

**连续流**：`M_n^{(x)}(z) := ∂_xψ_n/ψ_n = (∂_x α_n)/(z + α_n)`，离散 Lax 方程

```
∂_x L_n + L_n M_n^{(x)} − M_{n+1}^{(x)} L_n = 0
```

在 `n = 0,1,2`、`z = 1.5, 4, 30` 上残差 `≤ 8e−82` —— **精确成立**。
（`y`、`t` 方向同构。）

## 2. 单值矩阵：迹与 `z` 无关（谱曲线退化）

沿 `n` 方向走一个完整周期，单值矩阵是各 `L_n` 的矩阵代表之积：

```
L_n(z)  ↔  [[1, α_{n+1}], [1, α_n]]
```

对周期 `N` 直接数值计算（`lax/mono.py`）得

```
tr T(z) = 3756713.03933109814     (对所有 z: 1.5, 4, 30, 1000 完全相同)
det T(z) = −23228.4011657458589   (同样与 z 无关)
```

**`tr T(z)` 是一个与 `z` 无关的常数**：

* 没有 Floquet 谱曲线、没有带隙结构；
* 不能用 `tr T(z)` 的 `1/z` 展开生成守恒密度族。

（注意：Möbius 映射本身**不**满足 `L_{n+1}∘L_n = L_{n+2}`；
实际复合为 `L_{n+1}(L_n(z)) = (z+α_{n+1}+α_{n+2})/(z+α_n+α_{n+2}) ≠ L_{n+2}(z)`，
相对偏差 1e−4 ~ 2e−2，见 `lax/mono.py` (a)。所以退化不是因为映射可望远镜求和，
而是**矩阵迹本身的代数恒常性**。）

**判断**：离散 Lax 对真实存在并且相容（第 1 节），但它在 `n` 方向的谱信息是
**零维**的。同理 `j` 方向：`j` 依赖完全落在与 `i,k` 无关的整体乘子
`(λ(p_i−a)λ(q_k+a))^j` 上，只给出平凡（几何）量。
数值上 `σ_j = τ(j+1)τ(j−1)/τ(j)² = 1.01149… ≠ 1`，但它由该整体乘子与
`τ` 的系数重排共同决定，不构成新的守恒密度（`lax/FINAL2.py`）。

## 3. `n` 方向确实是非平凡的：`σ_n` 依赖 `n`

`σ_n = τ_{n+1}τ_{n−1}/τ_n²`（`lax/FINAL.py`，`N = 1,2,3`）：

| N | σ_{−1} | σ_0 | σ_1 | σ_2 |
|---|---|---|---|---|
| 1 | 4.9106195487377 | 0.49588683362984 | 1.2642684753353 | 0.91332695390262 |
| 2 | 5.1322398022826 | 0.8717899578447 | 1.4318860061032 | 0.94567784608147 |
| 3 | 7.5823150996749 | 0.66609528221899 | 1.6414710489398 | 0.88160818912162 |

`σ_n` 明确依赖 `n` 与 `N`，说明**交错半离散系统不是把连续解原样搬到格点上**：
它是**连续 DLW 在参数 `a` 的两个平移版本之间交替**，`h` 只以
`a ↦ a ∓ h/2` 的方式进入。这正是既有报告里"相互作用系数 κ 与 h 无关"的机制来源。

---

## 4. 守恒量在哪里：连续方向 + `h` 的参数重正化

半离散系统在每个格点 `j` 上都是**连续 DLW 的解**（只是 `a` 取 `a∓h/2`），
所以连续 DLW 的无穷守恒律

```
∂_t ρ_k + ∂_x σ_k = 0
```

对每个格点成立；写成格点和即得到半离散系统的守恒量族

```
∂_t Σ_j ρ_k(j) + ∂_x Σ_j σ_k(j) = 0 ,     k = 1, 2, 3, …
```

即：**守恒量族的存在性由连续 (x,y,t) 方向承载，而不是由格点单值矩阵承载**。
`h ↦ a∓h/2` 的参数重正化保证这套守恒律在同一条格点链上同时成立。

---

## 5. 与 (2+1) 维 Toda / sinh-Gordon 的关系

* `τ_n` 的系数依赖 `(−(p_i−a)/(q_j+a))^n`，即 dKP/2DTL 的 `n`-移动；但在本构造中
  它**只缩放系数**，不改变指数部分 `ξ_i+η_j`——这正是第 2 节退化的根源。
* 论文指出：`y↔t, a=0, λ=1` 时双线性 DLW 化为双线性 (2+1) 维 sinh-Gordon。
  Hu & Yu 2007（离散 (2+1) 维 sinh-Gordon, J. Phys. A **40** 12645）是最接近的
  离散类比且含 Lax 对，但为付费文献，未能取得原文逐项比对。

## 6. 判定表

| 问题 | 答案 |
|---|---|
| 存在含谱参数的离散 Lax 对？ | **是**：`L_n(z)=(z+α_{n+1})/(z+α_n)`，`ψ_{n+1}=L_nψ_n`，与 `x/y/t` 流相容（残差 ≤ 8e−82） |
| 波函数在 `z` 中的类型？ | **Möbius**：`ψ_n(z)=1+α_n/z`（80 位精度下精确） |
| 单值矩阵迹随 `z` 变化？ | **否**。`tr T(z)` 恒为常数 ⇒ 谱曲线退化 |
| 离散方向有非平凡守恒量族？ | **否**（`n`、`j` 方向都不产生） |
| 系统整体有可积结构？ | **是**，但由**连续方向 + `h ↦ a∓h/2` 参数重正化**承载 |

**净结论**：这个半离散系统**不是**"一个普通格式"——它有精确的双线性结构、
含谱参数且相容的 Möbius Lax 对、以及 `h`-无关的相互作用系数；
但其**格点方向的谱是退化的**（单值矩阵迹与 `z` 无关），
所以**不能**从格点单值矩阵得到一族新的守恒量。守恒量族必须从连续层次读取。
