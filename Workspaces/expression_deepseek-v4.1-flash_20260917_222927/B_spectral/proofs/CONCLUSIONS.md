## A. 谱离散的结构（乘子、核、逆、零模）

**结论 1.**
乘子在模式空间是**对角**的：`(D_y u)_ℓ = iℓ û_ℓ`，即 `multLin N c` 在槽位 `i` 上的值为 `(modeIdx N i)·c i`。
对象/假设：任意 `N : ℕ`、任意复系数族；周期 `y`；`modeIdx N i = i − N`。
Lean：`DLW.Spectral.multLin`、`multLin_apply`（`proofs/Spectral/Multiplier.lean`）。
等级：**Lean 结构验证**。
说明：这是本方向一切结论的源头 —— `y`-导数没有相容阶误差，误差只能来自投影与非线性求值。

**结论 2.**
`D_y` 在带 `−N..N` 内的核恰为**零模线**：`multLin N c = 0` 当且仅当对一切 `i` 有 `modeIdx N i ≠ 0 → c i = 0`。
对象/假设：任意 `N`；无额外假设。
Lean：`mult_eq_zero_iff`、`kernel_eq_zero_mode_line`。
等级：**Lean 代数验证**。
说明：核维数恒为 1（与 `N` 无关），因此谱离散下不存在"隐藏除以零模"以外的退化；零模是唯一被分离的模。

**结论 3.**
槽位映射是单射，且 `modeIdx N i = 0 ↔ i = zeroIdx N`；`modeIdx N i ≠ 0 ↔ i ≠ zeroIdx N`。
对象/假设：任意 `N`。
Lean：`modeIdx_zeroIdx`、`modeIdx_eq_zero_iff`、`modeIdx_ne_zero_iff`、`modeIdx_injective`。
等级：**Lean 代数验证**。

**结论 4.**
在**零均值子空间** `zeroMean N = {a | a (zeroIdx N) = 0}` 上，乘子与逆乘子 `invMultLin N`
（非零模取 `1/(iℓ)`，零模取 `0`）**互逆**：`invMultLin N (multLin N a) = a`、`multLin N (invMultLin N b) = b`。
对象/假设：`a, b ∈ zeroMean N`；任意 `N`。**零模必须被排除**，否则恒等式为假（零模上乘子为 0）。
Lean：`invMult_mult`、`mult_invMult`、`invMultLin_apply`、`invMultLin_zeroIdx`。
等级：**Lean 代数验证**。
说明：这就是"逆算子障碍"的精确边界 —— 它恰好是零模这一维，而不是格点类 `w(j+1)=w(j−1)` 那样的大假设类。

**结论 5.**
在全集上，乘子与逆乘子的合成等于**零模投影**：`invMultLin ∘ multLin = modeProj = multLin ∘ invMultLin`，
且 `multLin (modeProj a) = multLin a`、`modeProj (multLin a) = 0`；`modeProj` 恰以 `zeroMean` 为像。
对象/假设：任意 `N`、任意系数。
Lean：`mult_comp_modeProj`、`modeProj_comp_mult`、`mult_modeProj_zero`、`zeroMeanEquiv`、`mem_zeroMean_iff`。
等级：**Lean 代数验证**。
说明：这给出**无隐藏除法**的机器可检证据：任何用 `1/(iℓ)` 的推导都自动被投影到零均值子空间。

**结论 6.**
零模在乘法下不变：`mean_mult`（零模分量在 `multLin` 下仍为 0），亦即求导不产生零模。
对象/假设：任意 `N`。
Lean：`mean_mult`、`mult_zero_mode`。
等级：**Lean 代数验证**。

**结论 7（与格点路线的对照，实验）.**
`ℤ/M` 上中心差分 `(Cu)_j = (u_{j+1} − u_{j−1})/(2h)` 的零空间维数为 **1（`M` 奇）**、**2（`M` 偶）**（`M = 3..10` 精确有理算术验证）。
对象/适用范围：格点离散；与共享模块 `Common.Operators` 的 `Common.ctr_kernel` 对照（该定理的假设类
`∀ j, w(j+1) = w(j−1)` 在奇 `M` 下正是常值 + 交错常值，在偶 `M` 下更大）。
证据：`experiments/spectral_diagnostic.py` Sec 7。等级：**实验验证**。
说明：这解释了为何谱槽位取 `2N+1`（奇）个：偶格点数会引入第 2 个伪零模。

## B. 线性化与色散关系

**结论 8.**
常量背景 `(u0,v0)` 上，(1)(2) 的一阶项为
`(iℓσ)U − k²V − (u0+2a)kℓU = 0`、`(σ+i(u0+2a)k)V + i(v0+2λ)kU − ik²ℓU = 0`。
对象/假设：模 `e^{σt+i(kx+ℓy)}`，振幅 `(U,V)`。
证据：`experiments/spectral_diagnostic.py` Sec 1（SymPy 由 PDE 直接微分、取 `ε` 一阶项，逐项比对）。
等级：**实验验证**（并与结论 9 的 Lean 命题一致）。

**结论 9（色散关系）.**
若 `k ≠ 0`、`ℓ ≠ 0`、`U ≠ 0` 且 (1L)(2L) 成立，则
`(σ + i(u0+2a)k)² = k⁴ − (v0+2λ)k³/ℓ`。
对象/假设：常量背景线性化；结论以**无除法**形式陈述（除法只在末步用 `k ≠ 0, ℓ ≠ 0` 消去）。
Lean：`dispersion_relation`、`I_factor`（唯一用到 `i² = −1` 的引理，被显式隔离）。
等级：**Lean 代数验证**。
说明：**陈述中不含截断 `N`**。这是"`y`-离散不改变 `x`-符号"的机器可检版本。

**结论 10.**
`U = 0` 时 (1L) 强制 `V = 0`（`k ≠ 0`），故非平凡模必有 `U ≠ 0`：结论 9 对一切非平凡线性模成立。
Lean：`nontrivial_dispersion_relation`。等级：**Lean 代数验证**。

**结论 11（充分性）.**
色散关系也是充分的：`U = 1`、`V = (iℓs − (u0+2a)kℓ)/k²` 满足 (1L)(2L)。故结论 9 **刻画**全部非平凡线性模。
Lean：`mode_of_dispersion_relation`。等级：**Lean 代数验证**。

## C. 零模 sector（`ℓ = 0`）

**结论 12.**
`ℓ = 0` 时方程 (1) 化为**精确的** `∂_x² v̂_0 = 0`：`∂_t û_0` 项与 `2a∂_x û_0` 项因 `ℓ = 0` 消失，
二次项 `i Σ_{m+n=0} n ∂_x(û_m û_n)` 因反对称配对恒为 0，故 `û_0` 完全不出现。
对象/假设：任意截断 `N`（有限带内的反对称配对仍然成立）。
证据：`experiments/spectral_diagnostic.py` Sec 2（符号精确：`resid1(0) − ∂_x²v̂_0 = 0`）。
等级：**实验验证**（+ 报告中的恒等证明）。
说明：`u` 的零模是 (1) 的**规范自由度**。

**结论 13.**
由此 `v̂_0(x,t) = α(t) + β(t)x`；(2) 的 `ℓ = 0` 分量为
`∂_t v̂_0 + ∂_x[Σ_m û_m v̂_{−m} + 2a v̂_0 + 2λ û_0] = 0`；二者合并给出相容性约束
`∂_x³[Σ_m û_m v̂_{−m} + 2a v̂_0 + 2λ û_0] = 0`。
证据：同结论 12（Sec 2 精确验证第二式）。
等级：**实验验证**（+ 报告证明）。

**结论 14（V7 零模族）.**
`v ≡ −2λ`（即 `v̂_0 = −2λ`，其余 `v̂_ℓ = 0`）、`u = U(x,t)` 任意，是 (1)(2) 的**精确解**，
且在**任意** Fourier–Galerkin 截断下仍逐模精确。
对象/假设：任意 `N`；`λ` 任意。
证据：`experiments/spectral_diagnostic.py` Sec 2/3（`N = 1,2,3`，`ℓ ∈ {−3..3}`，符号恒等于 0）。
等级：**实验验证**。
说明：零模 sector 的退化对投影是**免疫**的；这也是 §7 中"零模对二次非线性无混淆"的物理根源。

**结论 15（`û_0` 的自由度条件）.**
`û_0` 为自由规范自由度当且仅当 `v̂_0 = −2λ`；否则 (2)₀ 决定 `û_0`。
证据：结论 12/13 与 V7 的直接推论。等级：**数学证明，尚未完整形式化**。

## D. 稳定性与增长（核心否定结论）

**结论 16（精确二分）.**
记 `R = k⁴ − ck³/ℓ`。`R ≥ 0` 时存在根 `σ = −i(u0+2a)k + √R`，`Re σ = √R`；
`R < 0` 时两根纯虚（中性），`Re σ = 0`。
对象/假设：`k, ℓ ≠ 0`；无其它假设。
Lean：`mode_of_nonneg_discriminant`、`neutral_mode_of_negative_discriminant`、`I_mul_sq`。
等级：**Lean 分析验证**。

**结论 17（增长下界）.**
`c ≥ 0`、`ℓ > 0`、`k ≥ c/ℓ` 时 `Re σ ≥ k² − (c/ℓ)k`。更一般地 `0 ≤ d ≤ k ⟹ k² − dk ≤ √(k⁴ − dk³)`。
Lean：`sqrt_growth_lower_bound`、`growth_lower_bound`、`discriminant_nonneg`、`exists_growing_mode`。
等级：**Lean 分析验证**。

**结论 18（判别式符号表）.**
`R = k³(k − c/ℓ)`。`c > 0` 时：`kℓ > 0` 且 `|k| < c/|ℓ|` ⟹ `R < 0`（中性）；
`kℓ > 0` 且 `k > c/ℓ` ⟹ `R > 0`（不稳定，`Re σ = √(k⁴−ck³/ℓ)`）；
**`kℓ < 0`（任意 `k ≠ 0`）⟹ `R > 0`（不稳定，`Re σ = √(k⁴+ck³/|ℓ|)`）**。
证据：`experiments/spectral_diagnostic.py` Sec 4（符号精确，含 `k<0`、`ℓ<0` 四种符号组合）。
等级：**实验验证**。

**结论 19（单侧稳定阈值 —— 有范围的正面结论）.**
`c > 0`、`1 ≤ ℓ ≤ N`、`k > 0`：若 `k ≤ c/N` 则 `R ≤ 0`（该单侧扇区中性）；且 `k > c/N` 时
`R(N) > 0`（阈值锋利）。
对象/假设：**仅单侧扇区 `ℓ ≥ 1`**（即 `kℓ > 0` 的一支）。**不能**读作"截断系统在 `k ≤ c/N` 时稳定"。
Lean：`band_stability_threshold`、`band_instability_threshold`。
等级：**Lean 分析验证**。
说明：稳定带 `0 < k ≤ c/N` 随 `1/N` 收缩 —— 但见结论 20：全带根本没有稳定区间。

**结论 20（主要否定结论：`N`-一致的不稳定）.**
对**每一个** `N ≥ 1` 与**每一个** `k ≠ 0`（取 `c > 0`），带 `−N..N` 都包含模 `ℓ = −1`，
且该模有判别式 `k⁴ + ck³ > 0`，对应根满足
`(σ + i(u0+2a)k)² = k⁴ + ck³`、`Re σ = √(k⁴+ck³) ≥ k²`。
**陈述中不含 `N`。**
Lean：`band_unstable_uniform_in_N`、`mode_neg_one_mem_band`。
等级：**Lean 分析验证**。
说明：这形式化了 refutation 项"固定截断稳定冒充网格一致稳定"：加密 `y`-分辨率既不恢复稳定，
也不降低增长率（主项恒为 `k²`）。

**结论 21（较弱但更"物理"的版本）.**
对每个 `N ≥ 1`，带内包含 `ℓ = 1`；`c ≥ 0`、`k ≥ c` 时存在带内模使 `Re σ ≥ k² − ck`。
Lean：`band_contains_growing_mode`、`mode_one_mem_band`。等级：**Lean 分析验证**。

**结论 22（`k²` 率与 `N` 无关，谱诊断）.**
`G(k,N) := max_{1≤|ℓ|≤N} Re σ = √(k⁴+ck³)` 在 `N = 1..32`、`k ≤ 64` 上逐位与 `N` 无关，
且 `G/k² → 1`（`k = 16, 32, 64` 时分别为 1.0308、1.0155、1.0078）。
证据：`experiments/spectral_diagnostic.py` Sec 6(a)(b)。等级：**实验验证**（下界与 `ℓ=−1` 的精确值见结论 20）。

**结论 23（`ℓ → 0⁻` 方向的无界性 vs 截断的正则化）.**
固定 `k > 0`：连续符号在 `ℓ → 0⁻` 时 `Re σ ~ √(c k³/|ℓ|) → ∞`（`k=1`、`ℓ=−10⁻⁶` 时 `Re σ = 1000.0005`，
渐近值 1000）；而带内 `|ℓ| ≥ 1` 的最大值有限（`k = 1` 时 1.4142）。
**故 `y`-截断正则化 `ℓ → 0` 方向，完全不正则化 `k → ∞` 方向（spec §2 的 Hadamard 不适定依旧成立）。**
证据：`experiments/spectral_diagnostic.py` Sec 6(d)。等级：**实验验证**（+ 报告证明）。

## E. 混淆（aliasing）与去混淆

**结论 24（混淆恒等式）.**
`M` 点均匀网格上，频率 `ℓ + Mt` 与频率 `ℓ` 的采样完全相同：`ζ^((ℓ+Mt)j) = ζ^(ℓj)`。
Lean：`sample_alias`。等级：**Lean 代数验证**。

**结论 25（外带折叠）.**
`M = 2N+1` 时，每个频率 `f ∈ (N, 2N]` 与某个带内下标 `i ∈ [−N,−1]` 相差恰好 `M`：
`i = f − M`，`f = i + M`。故**每个** `N ≥ 1` 的带都被污染。
Lean：`out_of_band_folds_into_band`。等级：**Lean 代数验证**。

**结论 26（3 点碰撞）.**
`N = 1`、`M = 3` 时 `ω₃^{2j} = ω₃^{3−j}`（`j = 0,1,2`），即顶模平方（频率 2）与带内模 `−1`
在网格上不可分辨。
Lean：`omega3_primitive`、`omega3_cube`、`three_point_collision`、`alias_offset`。
等级：**Lean 代数验证**。

**结论 27（REFUTATION：混淆破坏投影恒等式）.**
同一二次非线性、同一保留模 `−1`：未去混淆的 3 点伪谱投影为 `3`（归一化后为 `1`），
而去混淆/精确的 4 点（`M = 3N+1 = 4`）投影为 `0`。即
`(Σ_{j<3} ω₃^{2j}ω₃^j) ≠ (Σ_{j<4} I^{2j}I^j)`。
**误差与数据同阶（O(1) 相对误差），不是小量。**
Lean：`aliasing_breaks_projected_identity`、`three_point_sum`、`four_point_sum`、`I_pow_*`。
等级：**Lean 代数验证**。
说明：未去混淆的伪谱格式求解的是**另一个**问题；声称它保持 DLW 的 Galerkin 投影恒等式为假。

**结论 28（去混淆阈值 = 2/3 规则，精确且锋利）.**
配点在带内等于精确 Galerkin ⟺ `M ≥ 3N+1`。实验对 `N = 1..8` 精确验证：
`M = 3N+1` 全部复原；`M = 2N+1` 与 `M = 3N` 均被污染（用顶模见证）。
证据：`experiments/spectral_diagnostic.py` Sec 5（精确整数算术）。等级：**实验验证**。

**结论 29（零模对二次非线性永不混淆）.**
`M > 2N`（特别 `M = 2N+1`）时，`ℓ = 0` 的配点乘积系数与精确 Galerkin 系数**相同**
（`p+q ≡ 0 mod M` 且 `|p+q| ≤ 2N < M` 迫使 `p+q = 0`）。实验对 `N = 1..8` 显式验证。
连同结论 14：**V7 零模族在去混淆前后都是精确解**。
等级：**实验验证**（+ 报告证明）。

**结论 30（`u_xxy` 项无混淆）.**
四项非线性中 `u u_xy`、`u_x u_y`、`(uv)_x` 在 `y`-次数上均为二次，故适用同一 2/3 规则；
`u_xxy` 是**线性**项，乘子 `(ik)²(iℓ)` 精确，**没有混淆**。
等级：**数学证明，尚未完整形式化**（结构性观察；`x`-导数与 `y`-模式分解交换）。

**结论 31（去混淆的效果范围）.**
去混淆 (i) 把伪谱恢复为精确 Galerkin 卷积；(ii) **不改变**线性色散关系/增长率/稳定性区域；
(iii) **不改变**零模 sector（结论 29）；(iv) **不修复**适定性（结论 23）。
等级：**数学证明，尚未完整形式化**（由结论 1、27、28、29 组合）。

## F. 明确未证的缺口

**结论 32（未形式化）.**
带内最大值**上界** `G(k,N) ≤ √(k⁴+ck³)`（即对 `N` 的完全无关性）为初等不等式
（`ℓ ≥ 1`：`R ≤ k⁴`；`ℓ ≤ −1`：`R ≤ k⁴+ck³`），本次**未形式化**；Lean 只给下界与 `ℓ = −1` 的精确值。
等级：**数学证明，尚未完整形式化**。

**结论 33（未形式化）.**
谱投影误差界 `‖u − P_N u‖_{L²} ≲ N^{−s}‖u‖_{H^s}` 与 `N → ∞` 的 Galerkin 收敛率未形式化。
等级：**数学证明，尚未完整形式化**。

**结论 34（未形式化）.**
"对每个 `N`，`M = 2N+1` 时必存在被污染的模"的一般性结论：Lean 给出一般恒等式（结论 24）、
一般算术（结论 25）与 `N = 1` 的显式反例（结论 27），但一般 `N` 的反例族由实验覆盖（结论 28）。
等级：**实验验证**（一般性形式化留作缺口）。

**结论 35（未论证/开放）.**
(a) 非线性与长时间行为：本方向全部结论均为线性化层面 + 单步非线性求值层面；
(b) Chebyshev 情形（非周期有限 `y` 区间）的定量结论：仅作可行性讨论，未形式化；微分矩阵条件数 `O(N²)` 是数值伪影而非适定性问题；
(c) `x`-方向的离散化/有限区间：本方向 `x` 连续；
(d) **不主张**消除 Hadamard 不适定：结论 20/23 表明截断只正则化 `ℓ → 0` 方向。
等级：未论证 / 开放。
