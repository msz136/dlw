## 0. 结论摘要

用户的质疑是对的，而且比"浮点噪声"严重得多。审计发现**两个独立的、叠加的缺陷**：

| 缺陷 | 性质 | 后果 |
|---|---|---|
| **缺陷 1**：`jet3.py` 用 `mpmath.mpf`（60–90 位浮点）存系数 | 表述问题 | 残差 `1e-89` 是浮点噪声地板，不是 0；"精确"这个词用错了 |
| **缺陷 2**：所有判零都在**单个基点** `(x,t,y)=(1/5, 2/7, 0)` 上求值 | **致命** | 该点恰好落在使残差为零的曲面上，于是**非恒等式被误判为恒等式** |

缺陷 2 是根本问题。**先前"精确验证"通过的核心双线性方程 `(7)_h`、`(6)_h` 并不恒成立**，
其残差在一般点上量级为 **O(0.02–2833)**，且随 `h→0` 按 **O(h)** 衰减——它们是离散化误差，
不是恒等式。

## 1. 缺陷 1：浮点噪声

`jet3.py` 第 16–19 行：

```python
import mpmath as mp
mp.mp.dps = 60
ZERO = (mp.mpf(0), mp.mpf(0), mp.mpf(0))
```

所有 τ 的系数都是 `mp.mpf`，所以 `Bs3`、`ev` 全在浮点里算。`1e-89` 就是 90 位十进制的舍入累积，
**恰好等量于** 60 位精度下的 60 位噪声。这不是"数值上的零"，只是"比尺度小得多的数"。

**正确做法**：系数换成 `fractions.Fraction`，则代数部分的零是**字面上的 `Fraction(0)`**
（见 `jet4.py`）。

## 2. 缺陷 2：单点判零 —— 这是真正的错误

`nlfinal.py` 第 46 行：

```python
X0, T0, Y0 = mp.mpf(1) / 5, mp.mpf(2) / 7, mp.mpf(0)
```

`Y0 = 0`，所有判零都在这一个点上做。而 `(7)_h` 的残差恰好**结构化地**正比于 `(e^{433y/385} − 1)`，
于是 `y = 0` 时它**恒为零**，与 `h`、`j`、`a` 全都无关。

`audit_tau.py`（sympy，独立实现）对 `(7)_h` 给出精确结果：

```
B_s(F,G) = (77/12) · E(k_G) · (exp(433y/385) − 1)
```

其中 `E(k_G) = exp((−44/15)x + (2816/225)t + (11/5)y)`。这个残差**不是**恒零，
它只在 `y = 0`（及 `y = (385/433)·2πi·m`）上为零。

`audit_points.py` 在多点上重测，直接给出反例：

```
a=4, h=1/4, j=1:
  (7)_h: 在 (x,t,y)=(1/5, 2/7, 0)    相对残差 ~1e-120   <- 先前用的点
         在 (x,t,y)=(1/5, 2/7, 1/3)  相对残差 1.41e-3    <- 反例
         在 (x,t,y)=(1/3, 1/5, 1/7)  相对残差 0.0177
```

`audit_h.py` 给出量级与标度（同一点、同一参数）：

| h | `(7)_h` 残差 | 比值 | `(6)_h` 残差 | 比值 |
|---|---|---|---|---|
| 1/2 | 2832.76 | — | 12275.3 | — |
| 1/4 | 213.836 | 0.0755 | 408.232 | 0.0333 |
| 1/8 | 58.8094 | 0.2750 | 80.5906 | 0.1974 |
| 1/16 | 22.6280 | 0.3848 | 26.4632 | 0.3284 |
| 1/32 | 9.98847 | 0.4414 | 10.8005 | 0.4081 |
| 1/64 | 4.69875 | 0.4704 | 4.88596 | 0.4524 |

比值 → 0.5，即残差 **= O(h)**。这正是"半离散逼近连续方程"的离散化误差标度，
说明 `(7)_h` 是 `(7)` 的 **O(h) 离散化**，不是有限 `h` 下的恒等式。

**对照**：连续方程 `(7)` 在同一点、同样精度下残差为 `7.7e-117`，是真正的零。
所以问题不在机器，而在 `(7)_h` 本身。`(7)` 在 N=1、N=2 上都精确为零（`audit_cont.py` 确认）。

## 3. 续后缺陷：`(6)` 在连续层也不成立

`audit_gauge.py` 对 N=1 把相位常数 `ξ₀+η₀` 当未知量，同时要求 `(7)` 与 `(6)`：

- `(7)` 的四个基系数（1, F, G, FG）**全部精确为 0**；
- `(6)` 的残差是**单个**项 `−44·E₀·exp((11/5)y + (2816/225)t − (44/15)x)`，
  **与 `E₀` 无关的方程**，对 `E₀` 无解。

即：无论怎么选相位常数，`(6)` 都不能被满足。
`audit_cont.py` 对 N=1、N=2 都确认 `(7)` 精确为零而 `(6)` 不成立
（λ = −2 时 `(6)` 为 `B_a f·g_y − 4 D_x f·g = 0`）。

这意味着论文形态的 `(6)` 与我实现的 τ-函数**不相容**，这一点尚未解决；
在弄清之前，任何以 `(6)` 为前提的推论都不能使用。

## 5. 正确的验证方法（已经实现）

1. **精确算术**（`jet4.py`）：系数用 `Fraction`，代数恒等式的零是字面的 `Fraction(0)`。
2. **指数独立性判定**（`exactexp.py`）：形如 `Σ C_k e^{k·z}` 的和，恒零 ⟺ 按指数向量的
   **有理线性关系**分类后每类系数和为 0。判据：取 `L = {ℓ : ℓ·k_j = 0 ∀j}`（键的零化空间），
   按 `L` 的商坐标分类。
3. **多点/符号判零**：绝不能在单点判零。至少要在多个独立的一般点上测；
   最好用 sympy 把 `(x,t,y)` 保留为符号，化到指数基上读系数（`audit_tau.py` 的做法）。
4. **反例优先**：一个"通过"的检验必须能说明它为什么不是碰巧通过；
   有 `h` 参数时应当扫 `h` 看标度（`audit_h.py` 的做法）。
