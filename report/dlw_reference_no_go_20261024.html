DLW参考解认证：同初值小残差路线的否定结论

2026年10月24日 · 原正弦与周期高斯初值不变 · T=0.01

现有证据框架不能提供全场精度保证。这一判断现在有完整非线性方程的反例支持：精确保持初值和下边界，可以使整个时空区域的PDE残差趋零，而终点v的最大误差保持固定。任意有限批网格的一致性也不能补足这个缺口。

1. 明确被否定的估计

设给定初值确有一个足够正则的目标解(U,V)。若只使用准确初值、准确边界和物理方程的一致残差r，则不存在适用于所有此类近似场的误差模量ω，使

‖vapp(T)−V(T)‖∞ ≤ ω(r)，且 ω(r)→0 当 r→0。

这里r包括两个完整非线性连续方程的残差，不是有限维投影残差，也不是若干采样点的残差。反例不需要改变原初始化。它否定的是没有额外定量正则性或尾界约束的稳定认证。

2. 为什么反例成立

在X=x−4t中取a=uz+v、b=uz−v。a含反扩散主部，而u是(a+b)的横向原函数。把a的高频扰动放在很窄的横向条带内，v可以有固定幅值，u及其引起的非线性耦合却随条带宽度减小。

构造使用一个有零积分的横向形状、一个初始为零的时间因子和高频空间因子。对一般内部条带，空间因子沿背景输运解一个稳定反向的标量抛物问题。初始截断产生的残差由正向热平滑压小；其余项随条带变窄而趋零。所有二次非线性项均保留。

初始差 = 0，边界差 = 0， 完整PDE残差变化 → 0， 终点 ‖δv‖∞ = ε > 0。

条带可放在任何指定开内部区间，包括原评价区域|y|≤1.8。给定任意有限批横向网格，还可以把条带放在采样点之间，使两场在所有这些点、整个时间区间内完全相同。

3. 与当前候选相连的显式核验

从当前两条候选生成时间C¹的明确多项式，再精确补回原初始化，得到两种基准场。192-bit区间运算证明它们所需的六个背景常数均小于1。基准场仅用于反例，不是新认证的真实解。

5. 不能据此声称什么

这里没有构造同初值的两个精确解，也没有排除所有低阶经典解或弱解。反例近似场的残差很小但不恒零。原精确初值是否存在可用特殊结构认证的低阶解，仍是开放问题。

因此，不能把结论写成“永远无法精确估计这个固定初值”。准确结论是：现有小残差与有限加密路线已经被否定；继续同类加密不能成为充分的理论证据。要重新开启全场认证，必须证明新的存在唯一性与定量正则性/尾界，或给出精确的结构性构造。

当前候选可保留为数值探索结果；ηu、ηv仍未知，不应作为已认证连续真解发布精确误差表。
