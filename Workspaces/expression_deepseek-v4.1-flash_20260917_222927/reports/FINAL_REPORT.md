## 0. 一句话总结

**八条路线都在"构造 + 连续极限 + 局部性 + Lean 验证"上取得了实质进展，但没有任何一条

（i）**交错双 tau 半离散系统**被精确验证（`N = 1..5`，2904 个系数全零），且连续极限恰为论文 (6)；

（iii）**唯一干净的正面条件结论**：`v₀ = −2λ`（`λ=−2` 时 `v₀ = 4`）时 `k³` 项恒消失，
离散色散关系对**每一个**格点符号精确等于连续色散关系。

最有价值的**负面**成果是两条**结构性不存在性**结论：
（A）**变分/多辛 `y` 离散买不到适定性**——`x` 符号 `J∂_x²` 是**不定**的（特征值 `±1`），
反对称模 `w−v` 满足**后向热方程**；
（B）**在自然的常核 Poisson 类 𝒞 中根本没有 Hamiltonian 括号**（唯一解 `Q = 0`），
且该障碍 `h → 0` 时不消失。

## 1. 核心科学结论（跨方向，主控亲自验证）

### 1.1 不适定性的结构根：`J` 的不定性

以 `W = (w, v)`（`w = u_y`）写出，DLW 的主部为

```
∂_t W + (u + 2a) ∂_x W + u_x W + J ∂_x² W = 低阶项,      J = [[0,1],[1,0]]
```

`J` 是**对称对合**，特征值 `+1`（模 `w+v`）与 `−1`（模 `w−v`）。因此 `x` 符号 `J∂_x²` 是
**不定**算子：`w+v` 上为 `−k²`（前向热，良定），`w−v` 上为 `+k²`（**后向热，不适定**）。
**一个可对称化的强良定系统不可能有不定主符号。**

> 这是"把时间花在数学上"得到的最有用的一个视角：它把"为什么各种好性质都救不了"
> 变成了一句可检验的代数事实。**等级：Lean 代数验证**（`DLWF.xSymbol_antisymmetric_branch` 等）。

### 1.2 为什么 `y` 离散救不了：约束是唯一的 `y` 导数

`w = u_y` 改写后：

```
(1')  w_t + ∂_x[ v_x + (u+2a) w ]         = 0
(2')  v_t + ∂_x[ (u+2a) v + w_x + 2λ u ]  = 0
(3')  u_y = w                              ← 全系统唯一的 y 导数
```

`y` 离散的**全部影响**就是用某个离散算子替换 (3')。`x` 符号 `J∂_x²` 来自 (1')(2')，**不含任何 `y` 导数**。
于是对任意一致符号 `Λ_h(ℓ) → ℓ`：

```
[ σ + i (u₀+2a) k ]² = k⁴ − (v₀ + 2λ) k³ / Λ_h(ℓ)
```

`k⁴` 系数**恒为 1**。六个符号（中心、前向、后向、交错、P1 一致质量 FEM、谱）全部验证。
**隐式性、守恒性、SBP 耗散、FEM/DG 质量矩阵、辛/多辛结构——没有任何一种能消除它。**

> **等级：Lean 代数验证 + Lean 分析验证 + 实验验证。** 未形式化的桥接：
> "线性化模增长 ⇒ 非线性 Hadamard 不适定"（全项目通病，见 §6）。

### 1.3 精确零模（唯一豁免点）

`v ≡ −2λ`、`u = U(x,t)` 任意（`u_y = 0`）是 (1)(2) 的**精确**解；`λ = −2` 时为 `v₀ = 4`。
这是真正的无穷维零模。**任何求逆 `d/dy` 的格式必须说明该核如何处置。**
在方向 E 中这也是**唯一**存在 Poisson 括号的点（`Θ = 0`、`E = 0`，可取 `Q = diag(q,−q)`）；
在方向 B 中该族在**任意** Fourier–Galerkin 截断下逐模精确，且 `ℓ = 0` 对二次非线性**永不混淆**。

### 1.4 唯一干净的正面条件结论

`v₀ = −2λ` 时 `k³` 项系数恒为零 ⇒ 离散色散关系 = 连续色散关系（`D² = k⁴`），
**对每一个格点符号、每一个模、每一个 `h`**。这是"离散不比连续更坏"的最强陈述。
**但它不是稳定性定理**——连续问题本身仍不适定。

### 1.5 一处必须钉死的约定（本次运行中修正）

方向 C 的 `(σ+iAk)² = k⁴ − i(v₀+2λ)k³/μ_h` 与主控的 `… − (v₀+2λ)k³/Λ_h` **不矛盾**，
只是 `μ_h := iΛ_h` 的定义差异。已在 `common/SHARED_MATH_SPEC.md` §2.0 固定三种等价写法。
**任何下游结论不得混用。**

### 2.D 守恒 / SBP —— **`条件可行` ｜ `Lean 代数验证` + `Lean 结构验证` + `实验验证`**

**构造**：单侧**前向**差分 `D` + **平均通量**：
`D_t u_j + D_x F_j = 0`，`F_j = v_{x,j} + (avg(u)_j + 2a) D u_j`，整体是一个 `x`-散度。
主控**独立重跑确认** `PASSED: 2 local module(s).`。

**证明了什么**（8 条定理）：
* 守恒**来自通量形式而非事后拼凑**：因 `D` 只作用于格点指标 `j` 而 `x` 连续，
  `D_t(Du)_j = D(D_t u_j) = −D_x(DF)_j` ⇒ 约束 `w = Du` **精确保持**
  （`constraint_sbp_balance`、`D_shift_comm`）；
* 前向差分**强制平均乘积法则** `D(xy)_j = (avg x)_j(Dy)_j + (avg y)_j(Dx)_j`，
  由此 `Σ_j (u_j+u_{j+1})(u_{j+1}−u_j) = u_N² − u_0²`：**纯边界项**，周期下非线性项净通量为 0；

**否定了什么**：
* **朴素离散化破坏守恒**：`2u_j(u_{j+1}−u_j)` 取 `u=(1,3), h=1` 得 `4` 而非 `8` ⇒

* **守恒蕴含不了稳定（Lean 支持）**：`(E1)` 守恒的泛函 `Σ_j D u_j` 关于 `u` 是**线性**的；

  ⇒ 该守恒量**不能控制任何范数**。D 把所有守恒主张写成**条件性**的。
* **密度加倍使病态更严重**：格点最大模 `α = 2/h` 处 `Re σ ~ O(1/h)` 发散，

  **"假设 4：离散化规避病态"判为失败，且给出的是明确机制而非"很难"。**
* **不用中心差分**：前向差分符号 `μ = (e^{iαh}−1)/h` 仅在零模处为零，Nyquist 处 `|μ| = 2/h ≠ 0`

### 2.E Hamiltonian / Poisson —— **`候选被否定` ｜ `Lean 代数验证`**

**受检类 𝒞**：`P = ∂_x·Q`，`Q` 场无关、`x`-平移不变、可逆的常对称 `2n×2n` 核（KP 型"第一括号"）。

**否定了什么**：
* 障碍算子 `Θ := A − Aᵀ = diag(w)C − Cᵀ diag(w)`，`Θ_ij = w_i C_ij − w_j C_ji`，
  **自动反对称**却**依赖场**。Helmholtz 条件 ⇒ **`Q = 0`（奇异）**。
  `n = 2`、一般反对称 `C`、`w,v,a,λ` 全符号 ⇒ **唯一解 `Q = 0`**；`n = 3,4` 同结论。
* **为什么是结构性的**：`h → 0` 时 `Θ_h → w∂_y^{-1} + ∂_y^{-1}w ≠ 0`。
  障碍**不随网格加密消失** ⇒ **相容阶越高也不能保 Poisson**。
* 标准 Dirac 配对 `{u,v} = c∂_x` **失败**（要求 `c = 0` 或 `u ≡ −2a`）——**如实报告而非宣称存在**。
* **唯一豁免点**：`v ≡ −2λ`、`u = U(x,t)`（`w ≡ 0`）处 `Θ = 0` 且 `E = 0`，可取 `Q = diag(q,−q)`，
  且离散格式**精确保持**该零模。注意 `w ≡ c ≠ 0`（`u` 常斜率）**不豁免**。

**局部性（对 G、H 独立可用）**：`w, v` **局域**（3 点模板），`u = Cw` **非局域**，`Θ` 就是该非局域性的度量。

**明确不主张**任何结构消除 `|Re σ| ~ k²`。本方向结论**更强**：在 𝒞 中连括号都没有。

**尚缺（最有价值的下一步）**：真正的 mKP 型括号若存在，必在 𝒞 **之外**——
场相关核 `Q(w,v,…)`，或含 `∂_x^{-1}` 的 `x`-非局域核。
**未形式化桥接**：变分学（Hamiltonian 存在 ⇒ 三条 Helmholtz 系数方程）作为假设取入。

### 2.F 变分 / 多辛 —— **`条件可行` ｜ `Lean 代数验证`（主）+ `Lean 分析验证`**

  特征多项式**回文（自伴）**`A r² + B r + A` ⇒ 根成**互反对** `r₁r₂ = 1`（`Lean 代数验证`）。

**否定了什么**：

* **必须说清的一点**：`r₁r₂ = 1` 只约束**乘积**不约束**模**（`A=1, B=−3` 时一根 `≈2.618 > 1`）
  ⇒ **保辛 ⇏ 稳定**。

**尚缺**：（i）**未**为 (1')(2') 显式构造 `(x,t)` 的 Lagrange 密度（需 Clebsch/守恒律势；

（iii）非线性离散 Lagrange 函数下保辛性的严格陈述未形式化；（iv）有限格点 + 边界条件的边界通量项未处理。

## 3. 推荐排序（回答用户的五个问题）

### 3.1 哪条路线**最好地保持可积结构**？

**G（Hirota / Bäcklund / 层级离散化）**，且**只有 G**。**H（Toda 型嵌入）已被否定。**

理由：可积结构在本系统中**就是**双线性/tau 结构。只有 G 直接离散化**双 tau 函数对**
`(F_j, G_j)` 并把 `∂_y` 换成相邻格点关系，因此它保留了（i）两条双线性方程、
（ii）Cauchy 相互作用因子、（iii）任意 `N` 的**行列式**表述。
主控已验证其连续极限恰为论文 (6)、形式二阶相容、`N = 1..5` 精确成立（2904 系数全零）、
且二孤子 tau 对在 20 组可容许参数 × 16 mode 对 × 6 个 `δ` 值上残差**恰为 0**。
**没有任何其他路线能产出"精确解族"这种东西。**

> **但必须同时说**：保留可积结构**不改善适定性**。G 的价值在于**精确解与结构**，
> 不在于数值稳定性。G 自己已确认 `|Re σ| ~ k²` 障碍成立且不作任何稳定性主张。

**H 的否定是这条排名的重要限定**：Toda 型嵌入**可以形式上构造**，
但在使其自洽的扇区 **`W_n ≡ 1`**（Lean 已验证 `T(n+1)T(n−1) = T(n)²`）
⇒ 链指标上**无非线性动力学**，且**不改进局域非线性闭合**。
把链指标 `n` 当作 `y`-格点被 H-9/H-10 直接阻断（两个自洽条件互相排斥）。
**因此"用 Toda 层级生成 `y`-格点动力学"这条路已在常核类内闭合为否定。**

### 3.2 哪条路线**最容易给出局部非线性 VT**？

**C（混合 FEM/DG）的连续极限层**，或更准确地说：**没有任何离散层能给出局部非线性 VT**。

理由（C 的结论）：离散层不可行——`ln∘插值 ∉ V_h`、P1 的 `Aᵀ` 在 Nyquist 使约束不可解、
双线性恒等式**非投影不变量**。VT 只在**连续极限层**成立。

**若必须在离散层工作，则推荐"保留 `u` 为独立变量 + 约束 `u_y = w`"的表述**：
这样 `w, v` 是**局域**的（3 点模板，方向 E 证明），只有 `u = Cw` 非局域——
而 `Θ` 正是该非局域性的精确度量。**把 `u` 消去会使整个格式在 `y` 上非局部（累加和）。**

### 3.3 哪条路线**最适合守恒 / 几何分析**？

**D（守恒 / SBP）用于"守恒律"，F（变分 / 多辛）用于"几何结构"**，
且**都必须限定在条件性陈述**。

* F 已给出最清晰的**几何**图景：`y` 格点映射保辛（`det M = 1`、回文特征多项式、`r₁r₂ = 1`），
  并且**明确划定了它的能力边界**（`J∂_x²` 不定 ⇒ 保辛救不了适定性）。
* D 的 SBP 给出离散分部积分/能量恒等式，这是**离散守恒律**的正确工具。
* **E（Hamiltonian/Poisson）应视为已在该自然类中被否定**——这正是它最有价值的地方：
  它排除了整类可能性，把搜索引向场相关核或 `x`-非局域核。

**关键警示**：几何结构**不等于**稳定性。`r₁r₂ = 1` 允许 `|r₁| > 1`；能量恒等式允许无界增长
（因为能量不可能是正定的——§1.1 的不定性）。

### 3.4 哪条路线**最适合实际数值计算**？

**A、C、D 三条路线的结论在此*独立收敛*到同一个建议：放弃中心差分。**
这是本项目 cross-direction 证据一致性最强的一点（三条路线的工具、表述、目标各不相同）：

| 路线 | 采用的 `y`-离散 | 为何不用中心差分 |
|---|---|---|
| **A** | **交错** `f = 2sin(ξ/2)/h` | 中心 `f = sin(ξ)/h` 在 `ξ = π` **精确为零**；交错符号在**整个带**上非零 |
| **C** | **P0 DG 迎风** `M = hI` | P1 一致质量与中心差分符号同在 `ℓh = π` 为零（**Lean 已证**）；DG 迎风无零且 `Re μ ≥ 0` |
| **D** | **单侧前向** `μ = (e^{iαh}−1)/h` | 中心差分的 Nyquist 零点引入伪核；前向仅在零模处为零，`|μ| = 2/h ≠ 0` |

**推荐（实用数值）**：
* **首选 A 的交错格式**（无伪核 + 最高阶相容性：`f = 2sin(ξ/2)/h = ℓ(1 − ξ²/24 + …)`）或
  **D 的前向差分 + 平均通量**（无伪核 + **约束 `w = Du` 精确保持** + Lean 验证的 SBP 守恒律）。
  两者取舍：A 的交错符号精度更高；D 的通量形式给出**可证明的**离散守恒律。
* **需局部闭合时选 C 的 P0 DG 迎风**（`M = hI` **完全局部**、约束精确可解、无 Nyquist 零），代价 1 阶精度。
* **需高精度/诊断时选 B 的谱方法**，但**必须去混淆**（`M ≥ 3N+1`，阈值锋利），否则 O(1) 误差。
* **不使用中心差分**——除非显式处理棋盘分量并带限（A 已给出带限界）。

**所有数值使用都必须附带条件**：频带限制、或指定精确解族（如 §1.3 的零模族）、或固定截断。
**密度加倍不会改善、反而恶化病态**：D 测得 `h·Re σ → |sin 2|/2 ≈ 0.4546487`。

### 3.5 哪些路线应当**暂停**，以及**确切原因**？

## 7. 本项目"构造了什么、证明了什么、否定了什么、尚缺什么"

### 构造了什么
1. **约束改写 `u_y = w`**：把 `y` 离散的全部影响压缩为一对 `(M_h, D_h)`，
   使八条路线可在同一框架下比较（全系统唯一的 `y` 导数就是这条约束）。
2. **交错双 tau 半离散系统** `(B ∓ hD_x)F_j·G_{j,·} = 0`，连续极限恰为论文 (6)。
3. **四个 FEM/DG 变体**及其完整符号表（P1 一致质量、P1 集中质量、P0 DG 迎风、P1 DG 迎风）。
4. **A 的交错差分格式**、**D 的前向差分 + 平均通量格式**（约束精确保持 + Lean 验证的 SBP 守恒律）。
5. **F 的 `(x,t)` 多辛框架**：`J = [[0,1],[1,0]]` 对合、保辛条件 `det M = 1`、回文特征多项式。
6. **E 的障碍算子** `Θ := diag(w)C − Cᵀ diag(w)`（自动反对称、场依赖）。
7. **H 的几何族** `T(n+1)T(n−1) = T(n)²`。

### 证明了什么（Lean，全部由主控独立重跑确认）
* **消元恒等式** `E2 = (iμu_h/k²)·charFun` + **增长下界与无界性**（`MainNoGo`）；
* **交错连续极限** = 论文 (6)；**形式二阶相容**（无 `h¹` 项）；
* **`y` 离散不改变 `k⁴` 系数**（六个符号）；**增长率与截断 `N` 无关**；
* **A**：`ctrL f = 0 ⟺ f` 2-周期 ⇒ 离散约束核多一维；
* **C**：P1 一致质量符号在 Nyquist **为零**（否面）；DG 迎风无零；
* **D**：约束精确保持；平均乘积法则；守恒泛函线性 ⇒ **守恒蕴含不了稳定**；
* **E**：常核 Poisson 类中**唯一解 `Q = 0`**；
* **F**：`J` 对合、`xSymbol` 两支反号、增长二分、`r₁r₂ = 1`；
* **G**：平移分解 `eigen(a+δ) = eigen a + 2δ(k_μ−k_ν)`（任意域、任意 `N`）；
* **H**：`W_n ≡ 1`、`det(R·M) = R₁R₂ det M`、`logDeriv ≡ 0`。

### 否定了什么
1. **`y` 离散化不能消除 `|Re σ| ~ k²`**（六个符号 + 一般格点符号；机制明确：由 `∂_x²v` 承载）；
2. **"用结构换稳定性"**：隐式、守恒、SBP、FEM、DG、辛/多辛**全都不行**（F5 给出结构根：`J` 不定）；
3. **常核 Poisson 类中不存在 Hamiltonian 括号**（E），且障碍 `h→0` 不消失；
4. **Toda 型嵌入在自洽扇区退化** `W_n ≡ 1`，且链指标不能当作 `y`-格点（H）；
5. **中心差分与 P1 一致质量在 Nyquist 有虚假核**（C、F 独立一致；A、D 因此都不用中心差分）；
6. **未去混淆的伪谱给出 O(1) 误差**（B）；
7. **"棋盘模是演化系统的额外对称"为假**——它活在约束里而非演化里（A）；
8. **朴素离散化破坏守恒**（D 的反例 `4` vs `8`）；
9. **逐点 mode 对消失、强闭式 `(1+2δ)(k_μ−k_ν)`、笔记 §5 矩阵元恒等式**均为假（G 的三项更正 + 反例）。

### 尚缺什么
见 §6 的九条。**最关键的三条**：
（i）线性化 ⇒ 非线性不适定的桥接；
（ii）**任意 `N`** 的交错构造（仅 `N ≤ 5` 精确验证 + mode 对条件以 `hpair` 假设引入）；
（iii）**场依赖核 / `x`-非局域核**下的 Poisson 结构尚未尝试——这是 E 与 H 共同指向的**唯一**剩余结构性方向。
