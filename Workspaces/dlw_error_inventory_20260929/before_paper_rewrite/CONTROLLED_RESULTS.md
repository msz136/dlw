# DLW 误差对照：统一物理初值后的结论

2026-09-29 更新。直接采用交接报告；本次只整理实验结论，不复核求解器、不新增演化。以原文参数为固定算例，只讨论离散化、时间算法、网格和单／二孤子。

## 结论先行

**初值和物理边界对齐后，SD2 的误差明显降低，但尚无普遍精度优势。SD／FD 的相对表现依赖算例；时间算法可以改变 SD／SD2 的排名；动网格收益依赖方案和物理场。** 当前已测清 Euler 的一阶时间行为，尚未建立三种空间实现的一般误差常数或统一收敛界。

这次最有价值的实验，是在保持内部 Q/R 方程不变的前提下，统一初始离散 u/v 和最低 y 层物理边界。它排除了此前最明显的对照干扰。两项同时改变，所以前后改善应归于这次联合对齐，不能全部归因于初始化。

本次只复算原文图3/4/5的二孤子。**单孤子的SD2尚未做同样对齐，旧单孤子SD2不并入新版三方案排名。** SD与SD2在连续x层面等价，但完全差分后的变量形式、乘积／商法则和配套闭合仍可能产生不同误差。

## 3．对照一：固定RK4与均匀网格，只换离散化

下表为相对同一行FD的总误差比，每格u / v，小于1较好。新版SD2只列已对齐的二孤子。

| 原文算例 | SD / FD | SD2 / FD |
|---|---|---|
| 单孤子图1(a) | 0.703 / 0.841 | 未做对齐复算 |
| 单孤子图1(b) | 1.75 / 1.91 | 未做对齐复算 |
| 二孤子图3 | 1.16 / 1.77 | 1.54 / 3.02 |

**SD与FD没有普遍赢家，这个结论不受本次SD2修正影响。** 图3对齐后，SD2仍比SD和FD误差大，但差距已远小于旧表；不能继续用旧的27.5倍v误差作结论，新值约3.02倍FD。

图4动格在T=.01给出另一个有用观察：RK4下SD2/FD约0.988 / 0.905，两场主配置略小，但仍不及SD。这足以说明“SD2总是最差”也不是合适的概括；u的差距很小，不据此声称跨分辨率稳健优势。

## 4．对照二：固定图3与均匀网格，只换时间算法

下表为Euler / RK4总误差比，T=.01，Δt相同。

| 离散化 | u比值 | v比值 |
|---|---:|---:|
| SD | 2.04 | 4.11 |
| SD2 | 1.19 | 11.3 |
| FD | 1.47 | 7.21 |

**在这组对齐后的对照中，RK4的两场总误差对三种方案均更小。** SD2的v对时间算法尤其敏感，Euler误差约为RK4的11.3倍。此前该行0.584 / 1.25已被新数据替代，不能再说图3固定格的SD2用Euler反而更准。

但排名交互依然存在：图3固定格的u，RK4时SD=9.9385e−6、SD2=1.3192e−5，SD较好；Euler时SD=2.0238e−5、SD2=1.5693e−5，SD2较好。**一种离散化的表现仍须连同时间算法一起报告。**

新SD2的三档Euler时间步自收敛阶为0.9903–1.0001，支持一阶时间行为。不同变量实现没有改变Euler的阶数，却会改变给定步长下的误差表现。上表是总误差比，不是时间误差系数比；估计时间阶应继续使用同空间配置下数值场之间的差。

本结论限于所列算例与配置。总误差含不同来源的抵消，不能据此推广为RK4在所有总误差指标上必然优于Euler；宽波图5的FD之v仍可见Euler总误差略小。

## 5．对照三：固定图3与RK4，只换网格策略

下表为moving / fixed总误差比，T=.01。

| 离散化 | u比值 | v比值 |
|---|---:|---:|
| SD | 0.98 | 1.07 |
| SD2 | 0.828 | 0.761 |
| FD | 0.676 | 1.1 |

**双场取舍仍在，SD2的网格收益需要下调。** 新SD2的u/v改善约17%/24%，不再是旧表的40%/49%；FD的u改善约32%，v却变差约10%；SD变化较小且方向相反。

此处比较的是“均匀固定”与“初始自适应布点＋持续移动”两套网格策略。它回答哪套策略更准；若要进一步区分初始布点和后续移动的贡献，才补相同自适应初始节点、随后冻结的一组。不同方案采用相同监测规则，但由各自解驱动的节点轨迹可以不同。

## 6．我们现在可以讨论的结论

1. **最重要的新增信息是对照已改善。** SD2与其余两种方案的初始物理场、最低层物理边界已对齐；旧SD2误差幅度和旧排名反例被替换。新旧对比并非只改初值的单因素实验。
2. **三种差异仍须配对研究。** 图3中，时间法改变SD/SD2的u排名，网格策略对u/v产生不同收益；这支持研究误差来源与交互，而非按可积性或时间阶直接排序。
3. **目前证据支持具体配置的误差比较和Euler时间阶，尚未给出空间误差常数的一般结论。** 相容的半离散结构不保证完全离散实现有相同误差；当前结果也不能单独把差异归因于某一条离散乘积法则。

下一项最有信息量的实验，是选图3固定网格、RK4，以现有对齐初边值为基准，只改变y格距，研究三种空间实现的误差变化；时间误差和x误差作为控制。只有发现x误差主导时，才单独增加x控制。不再扩展物理参数或时间算法清单。

若要问时间法结论是否迁移到单孤子，应先补该算例的同样物理初边值对齐，再配对Euler与现成RK4；不能把旧单孤子SD2或短域Euler混入新版矩阵。
