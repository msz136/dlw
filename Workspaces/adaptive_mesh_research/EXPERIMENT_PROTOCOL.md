# 2HS / DLW 网格密度比较：数值实验协议 v1

2026-09-25。状态：实验设计与候选登记；尚未实施本协议的新交叉扫描。已有实验用于开发和估算窗口，不计作独立验证集。目标是分别选出两个系统的默认网格方案，并给出可复核、限定范围的数值结论。相关密度与守恒律见 [调研建议](RECOMMENDATIONS.md)。

## 1. 要回答的三个问题，以及允许给出的结论

H1（密度选择）：相同方程、空间格式、节点数、网格更新机制及足够小时间误差下，改变监测密度是否稳定降低两场误差？

H2（完整算法）：将密度配上相应的守恒通量或普通网格控制器，在相同准确度下是否减少实际耗时，或在相同计算预算下是否提高准确度？

H3（机制与交互）：收益来自初始布点、持续跟踪、强度调节，还是只存在于某个时间积分器或分辨率？

H1 与 H2 必须分开。原生守恒速度通常为 Q/R；换 R 会同时改变 Q/R。直接比较两条原生轨道，可以比较完整算法，但不能将差异全部归因于密度的形状。把曲率监测与常格距可积模型相比，也会混入空间模型差。

拟支持的句式：在预先指定的光滑单孤子参数域、观察时间窗、节点数范围和边界条件下，A 相对 B 的双场最大归一化误差中位比为……，失败数为……，且在同精度成本比较中……。只在有限样本有优势时称“本测试集内的数值优势”；不写“任意解最优”“可积所以更准确”或“数值证明全局稳定”。

## 2. 因素表与候选资格

| 因素 | 设置 | 控制原则 |
|---|---|---|
| 密度/监测量 M | 各系统先 5 类 | 本项目新增主因素 |
| 空间模型 S | 原结构半离散；直接连续方程离散 | 同 S 内先比较 M；跨 S 只比较完整算法 |
| 网格机制 P | 初始重分布后冻结 F；统一定期重分布 Z；原生守恒移动 C | M×P 不一定全交叉；没有通量的候选不伪造 C |
| 时间积分 I | Euler、Heun、经典 RK4、DOP853 八阶主公式 | 先固定 RK4 筛选；决赛交叉验证 |
| 空间分辨率 | 2HS 100/200/400 单元；DLW x 64/128/256 点 | DLW 初筛固定 h=1/8，决赛另扫 1/4、1/8、1/16 |
| 网格强度/刷新 | 小范围开发集调参 | 不为每个最终验证算例事后挑最优参数 |
| 测试问题 | 光滑孤子、相互作用、扰动、近退化压力测试 | 分层报告，压力测试不与普通单孤子平均抵消 |

第一轮候选：

| ID | 2HS | DLW |
|---|---|---|
| M0 | M=1，均匀物理网格基线 | M=1，均匀物理 x 网格基线 |
| M1 | rho，原质量密度 | 固定 y 权重聚合 1−(v−delta0 u)/4 |
| M2 | 双场梯度监测 | 固定 y 权重聚合 1−v/4 |
| M3 | 双场曲率监测 | 双场梯度监测 |
| M4 | 被动标签曲率加权质量 rho mu(X) | 双场曲率监测 |

HS 的 M4 初始使用 M_curv/rho0 权重，故 M4(x,0)=M3(x,0)；后续 mu 被动输运而 M3 根据当前场重算。这是特意设置的机制对照，不是初始几何层的两个独立候选。

第一轮不纳入带符号能量和 DLW 正号支：它们的资格取决于正性窗口和有限 h 通量实现。它们保留在候选登记中，不能事后因为看到了好结果才插入已封存的主验证排名。

所有场尺度、长度尺度在每个算例起点计算并冻结，使用同一公式。梯度监测为 sqrt(1+alpha*u_xbar^2+beta*z_xbar^2)；曲率为 (eps^2+alpha*u_xxbar^2+beta*z_xxbar^2)^(1/5)，z 为 rho−1 或 v。两场无量纲归一后默认 alpha=beta。L2 插值动机只作为设计依据，主要排名仍用下文两场 L-infinity 指标。

比较强度分两份报告：(a) 事先规定范围内、等额调参预算下的最佳完整方案；(b) 初态相同密度对比度的消融。第二份以 max M/min M=2 为首选目标，用正仿射背景混合调节；若在保持正性、非负混合系数等约束下不可达，则标记不可匹配，不强行截断密度。纯原生 M1 另保留未经调强度的结构基准。等对比度不意味着网格完全一样，但可排除“仅仅加密更激进”这一解释。

以 M/mean(M) 作布点归一化不改变等分节点；它若随时间变化，不能直接当作原守恒密度并沿用旧通量。任何平滑、限幅或正性修复都要记录；若破坏原守恒关系，归入普通监测方案。

## 3. 公平比较的共同框架

H1 使用同一数值场离散与统一定期重分布 Z。所有候选在相同物理时刻重分布，使用同一重构/重映射方法、边界、场尺度、导数计算和停止规则。M0 在固定端点下保持均匀，仍计其实际所需成本，不能人为让基线承担无用密度计算。

H1 的守恒密度在这里仅作为监测函数使用，不宣称 Z 精确保持其原守恒坐标。H2 再比较 Z 与真正的 C。HS 的原可积常 a 系统单列为结构基线，不能把 a 逐格替成 a_k 后继续称其可积。

初始物理场、物理区域、边界问题相同；不同节点位置必然得到不同采样向量，这不是“不公平初值”。保持节点数、总区域、可比的安全网格约束，密度导致的位置差是受研究的因素。固定物理区间下若原生 C 不能满足同一端点条件，先推质量归一化和边界规范；否则仅放入明确标注不同边界的补充实验。

所有动力学主试验只在 t0 用精确场设初值，之后网格来自当前数值场或被动标签；精确解只用于事先规定的边界和独立误差评估。禁止未来精确孤子轨道驱动网格，禁止每一步用真解纠正内点。现有 DLW balanced=True 的精确背景扰动推进不用于原 PDE 主排名，可作为单独的扰动实验。

## 4. 分六步实施

### E0：入场检查，而非性能排名

检查守恒恒等式、正性、网格有序、常值保持、每个 RK 阶段的坐标/场/边界更新。核对 ALE 变换与几何守恒；若用不同 y 层共同 x 网格，y 权重保持固定。重映射用代表性非均匀网格验证准确度和守恒误差，节点值与单元平均值分别处理。

时间推进的形式阶、空间一致性和边界/积分常数在简单光滑制造解或短时精确解上验证。制造解有附加源，只检验程序实现，不能代替原方程的优势实验。

E0 未通过的候选记为实现不合格，不把其巨大误差当成密度本身不好的证据。

### E1：静态及精确轨道几何诊断

在相同真实场和相同 N 上按各 M 布点，以同一重构算子比较表示误差，测每个波宽的节点数与峰/坡处点间距。另沿精确轨道采样，只回答“该密度会把点放在哪里”。

M3/M4 的 HS 初态节点必须相同，这是有价值的实现断言。几何诊断可以解释收益/失败，但不参与最终算法胜负票数，不把它写成数值演化。

### E2：密度主效应筛选

每系统 6 个开发算例 × 5 个候选 × 3 档 N × 统一 Z × RK4，共 180 条计划轨道。时间步由开发控制实验确定，需满足时间误差检查；这不是先验保证可稳定跑到目标时刻。另预留全部 60 个“系统×算例×候选”在中档 N 的 dt/2 对照，共 60 条。失败和未达精度的结果保留。

原始开发参数（只是起点，不冒充独立验证）：

- HS：c=1，单孤子 p=3、4、5、6、8、12。先 t0=0，观察 T=.1、.25、.5。同域须覆盖最窄/最快波，边界扩域检查后统一冻结；不能因某个候选失败而单独缩短其 T。
- DLW：单孤子 (a,p,q)=(4,1,2)、(4,2,3)、(6,1,3)、(4,2,1)、(2,1.5,2)、(3.5,.75,1.5)。相位中心 x_c=0，Gram 振幅=(p+q)exp(−(p+q)x_c)，h=1/8。先观察 .005、.01、.02、.04。旧记录提示后两个时刻可能无法通过精度门槛，失败本身是结果。

以上精确参照的适用性按 S 区分：原半离散解可用于同半离散模型求解误差；它不是直接连续 FD 的精确解。跨模型比较必须用共同连续参照并明确模型误差，或各用自己的高精度参照只做模型内网格比较。

E2 之前的开发调参预算：每系统 2 个代表算例、中档 N，至多 3 个强度 × 2 个刷新间隔；各方法预算相同。刷新以初态波宽/速度定义 t_char，候选 Delta t_refresh=t_char/4、t_char/8；近静止或开发短窗没有内部事件时，共同加做 T/4、T/8 事件对照，并冻结所选物理日程。自然常数方案不强加无意义参数。所有试过的配置存档。

用短窗共同观察值和后续失败表分别判定：不能只选择每种方法自己最好的时刻，也不能只报成功轨道的误差中位数。

### E3：机制消融与高阶交互

选基线及至多 2 个开发入选方案，在同一初始节点下比较 F、Z、C（C 仅限已构造通量的候选）。F 和 Z 区分持续重分布的作用；Z 和 C 比较完整网格控制方式；M3 与 M4 检查当前曲率跟踪和被动标签的差异。

随后每系统 3 个代表算例 × 3 个方案（含基线）× 4 个时间积分器 × 3 个步长，共 216 条计划轨道，固定中档 N。四种时间法是一阶 Euler、二阶 Heun、RK4、DOP853 八阶主公式；隐式梯形可作为刚性/成本补充，不与 Heun 混称同一个实现。

步长相邻减半，每个积分器可以有自己的起始步长，但所有网格候选使用该积分器同一套步长。变步重试必须记录；测固定步形式阶时有重试即标记该配置不是固定步试验。重分布事件固定物理时刻，允许最后一小步落到事件上。DOP853 在步端比较，不用其较低阶密集输出宣称八阶。

记录 error(M,I) 的完整表。若 A/B 的误差比随 I 反转，应写明交互，不能仅用 RK4 的结果声称 A 普遍更好。同样要检查时间误差足够小时的排序；高阶配更小误差不等于更低成本。

### E4：分辨率与独立确认

开发集选好全部公式、超参数、时间法、失败门槛后，封存版本和文件哈希，再生成每系统 30 个独立抽样单孤子参数块（固定随机种子）。验证结果不得用于返调；若改算法，原验证集转为开发数据，并另生成一批。

建议的确认分布，须在实际生成前完成精确解正则性/区域相容预检并冻结：HS 取 c=1，log(p−2) 在 log(1) 到 log(10) 均匀，即 p∈[3,12]；DLW 取 S=p+q∈[2,5] 均匀、nu=(p−q)/S∈[−.5,.5] 均匀、g∈[.5,3] 均匀，p=S(1+nu)/2、q=S(1−nu)/2、a=p+g。这一分布描述的是该光滑分支，不能代表所有孤子。

每个参数块另做 3 个相对网格平移（0、1/3、2/3 个粗网格间距），先在块内汇总最坏值；这些平移是相关子实验，不当作 90 个独立样本。三档 N 也是重复测量。验证以开发入选的一套方案对预定 M1 和 M0 基线比较，不在 30 个结果中再次挑新冠军。

在决赛中同时检查 x 加密与 DLW 的 h 加密，固定物理 y 区间、采样位置与边界含义。HS 常 a 半离散模型改变 a 时，节点数/物理覆盖需要单独设计，不能将 a 的模型误差与普通网格的空间误差混淆。

### E5：泛化、压力与误差—成本

除单孤子主确认，分开增加：

1. 双孤子：相近幅度和强弱悬殊两类，碰撞前/中/后。先独立确认参照和域；未完成全程就报告失败，不将短时接近称作已验证散射。
2. 受扰初值：两场分别和同时施加低频/局域扰动，幅度按初态场尺度取 10^−4、10^−3、10^−2；冻结随机种子，使用同模型加密参照。无扰精确孤子不能充当受扰真解。
3. 高曲率/近退化：接近预定正性下界的合法参数，记录精度失效和网格失效时间。它是适用边界测试，不因所有方法失败就无限缩短时间再宣布优势。
4. 实际成本：目标归一化误差 10^−2、10^−3、10^−4，给每方案同样的 N/dt 搜索预算，记录最便宜的已测达标配置。超出预算的为未达标，不插值编造达标成本。单独计网格、场推进、重映射及隐式迭代；剔除精确参照评估/绘图耗时。预热后随机化方法执行顺序，至少 5 次计时，报中位数和离散范围。

## 5. 主要终点、参照与误差控制

主指标取共同物理域上两场的最坏归一化误差：

\[
E(T)=\max_{t\in\mathcal T,\ t\le T}\max\left\{
\frac{\|u_h(t)-u_*(t)\|_\infty}{A_u},
\frac{\|z_h(t)-z_*(t)\|_\infty}{A_z}\right\},
\]

其中 HS 的 z=rho，DLW 的 z=v；A_z 用初态 rho−1 或 v 的幅度。非退化孤子取初始峰值幅度；允许零幅场的压力例使用预先冻结的正尺度下限，不能用当前误差或当前衰减峰值改变分母。给出两个场各自误差，避免较好的一场掩盖另一场。

所有比较使用同一组物理评价点及同一重构阶。密度为单元平均时用相容重构，而不是把边平均直接当边中点精确值。输出物理加权 L2、峰高误差、相位误差作为次指标；不得通过事后平移对齐去掉相位误差后只报“形状误差”。

精度维持时间是预定观察时刻中首次超过阈值的区间记录：若在 t_k 首次失败，记失效发生于 (t_{k−1},t_k]，不是精确首穿时刻。NaN、密度非正、网格交叉、求解失败、精度超限分别记录。

参照优先级：同方程精确解 > 已核对的同模型独立高精度解 > 加密自收敛差异。只有最后一项时明确叫参照差异。时间步再减半、空间再加密和更大区域/不同合理边界闭合的变化均应远小于被报告优势。

操作性门槛：每项时间、参照、边界及评价网格敏感度各不超过较小被比较误差的 5%，并不超过方法误差差额的 1/4；否则继续控制实验或标“不可分辨”。这些是数值可靠性检查，不是严格误差上界。接近舍入或参照地板时不报告误差比，也不因机器噪声判胜。

守恒诊断必须包含边界通量：I(t)−I(0)+integral(Q_R−Q_L)dt。rho_k*d_k=a_k 等由重构自动成立的量不作为独立准确性证据。报告正性余量、最小间距、邻接间距比、网格变形和每次重映射前后误差跳变。

## 6. 预先规定怎样判“更好”

每个确认参数块 c，在同 N/同时间控制精度下计算配对比 r_c=E_A/E_B，按预定相位子实验取最坏误差后再求比。两个方法都通过可靠性控制时才给准确度比；失败数必须以全部 30 块为分母另列。不得删除失败后只算胜率。

建议以下作为本项目的实际选型标准（人为设定的研究门槛，不是自然常数）：

- 相对原生基线 M1：30 个主确认块均完成预定任务和质量控制，无新增方法失败；若未全部完成则不作全域默认优越结论，改为给适用子域或受限结论。
- 同 N 主指标中位误差比 ≤0.80，至少 24/30 块有 r_c<1，最差比 ≤1.10；并且两个场各自的中位比均 ≤1。三档 N 分别报告，至少中/细两档满足，不能将分辨率结果混为 90 票。
- 在开发预选的主误差目标 10^−3 下，同精度成本中位比 ≤0.90，且可靠完成率不下降。若只有等 N 精度优势而无成本优势，就只称精度优势，不称高效算法。
- 相对 M0 同时报结果；不能仅击败一个很弱的基线。更严格意义上的两场逐例同时支配若未发生，不宣称 Pareto 支配。

若主确认参数块按上文独立抽样，可用参数块级配对 bootstrap 给几何平均误差比的 95% 区间（取 log r 后重采样）；这只描述指定抽样分布下的样本不确定性。开发集确定性扫描不套独立样本显著性，平移/分辨率不重复计票。没有明确抽样总体时以中位、分位、最差值和胜出计数为主。

原则上只对一套已冻结方案与预定主基线作确认性比较。若同时把多套候选在确认集上检验并选择，必须调整多重比较或另作最终独立确认，不能挑最好的 p 值。

标准未满足时允许没有唯一赢家。可发布“默认曲率加权；某类波形使用质量网格”等限定规则，但切换规则本身必须先在开发集冻结，再独立验证，不能逐例使用真解选最优方案。

## 8. 当前实现差距与实际工作顺序

已可复用：HS 精确单/双孤子、六种时间法、非均匀质量拉格朗日推进；DLW 原生减号密度共同 x 网格、固定/移动/刷新对照及既有非均匀导数。旧结果不等于本协议已执行。

必须先补：HS 统一物理边界下的通用重分布/ALE 框架、被动标签的相容重映射、单元平均密度的统一评价；DLW 可切换监测量接口、候选有限 h 通量资格、原始场推进与精确背景扰动推进的记录区分；两系统共同的配对评价和失败登记。

推荐顺序：E0 → E1 → 小开发调参 → E2（180+60）→ 入选 → E3（216，另计机制消融）→ 冻结算法/确认域/时间窗 → E4 → E5。180+60+216=456 只是固定骨架的计划轨道数，不包含调参、几何诊断、机制消融、独立确认、扩域和压力实验；不是已完成数量或总工时承诺。
