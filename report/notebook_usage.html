在 VS Code 中使用

  1. 打开所需的 .ipynb，在右上角选择 Python 内核：
    C:/Users/msz/aca/Workspaces/report_colab_20261006/.venv/Scripts/python.exe。
  2. 从第一段代码开始，按正文顺序点击 ▶，或按 Shift+Enter。

在 Colab 中使用

  1. 在 Colab 上传并打开所需的笔记本。
  2. 2HS 和 DLW 数值笔记本直接点击“连接”，使用 Colab 云端 Python 即可。非线性化与刘维尔可积性笔记本则双击 启动Colab本地运行时.pyw，在“连接”菜单选择“连接到本地运行时”，粘贴启动窗口给出的地址。
  3. 连接后，按正文顺序运行代码单元。编辑完成后，通过“文件 → 下载 → 下载 .ipynb”保存本地版本。
