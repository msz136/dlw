已核对的大文件在做什么

共享孤子轨迹：dlw_three_tracks_20261013/shared/*.npz 保存21个实际时刻的 u、v、精确 u、精确 v；数组轴为时间×y×x。Fourier、小波、误差演化动画和半步长对照使用这些数据。三个约216 MB的C算例文件代表不同算法或时间步，不能视为三份相同副本。依据：该项目 README、generate_shared.py 和 spectrum/analyze_error_fields.py。

误差传播与分源：transport/frame_*.npz 除实际误差外，还存交叉传播、未传播源项累加和三个误差来源分量。字段多、网格大、时刻多，体积自然增长；summarize_transport.py 与 figures/error_fields.py 会读取这些帧。final_common.npz 保存完整终态；independent_source_cache/ 是可重算的五节点源项插值缓存。依据：run_transport.py、source_cache.py。

论文数值文件：buffered_run/ 的原生状态与物理场缓存用于结果剖面、场图和比较。boundary_run/、physd_domains_run/、unified_run/ 的数组属于较早计算域版本；finish_buffered.py 明确记录“旧域结果仅保留为历史，不再作为当前论文结论”。旧数据仍可支持对照与追溯，宜归档；该判断不扩展到同目录的源代码或说明。

Lean 与 Mathlib：.lake/build/、.olean 和各证明运行副本是编译／执行产物。Mathlib 源码与包属于依赖，自己的 .lean 属于研究源码；二者和编译结果分别分类。编译产物可重建，但重建需要时间，首次恢复依赖也可能需要网络。不能整包搬走仍在使用的共享环境。

旧 Git 快照：Trash/git_snapshot_20261010_212349/.git 是10月10日仓库瘦身前保存的恢复副本，原记录大小2.845 GB。archive_result.json 记录了归档分支与提交，当前根目录另有活动 .git。它承担恢复用途，不参与普通数值计算；内部 pack 应随完整备份一同保留或归档，不能拆散。
