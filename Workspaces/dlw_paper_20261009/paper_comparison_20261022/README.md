# 附件 DLW 格点与 FD/PE 的统一参数比较

日期：2026-10-22。用户要求将附件非线性半离散方法代入本稿参数，比较 FD 与半离散误差。本支线不改原论文及 Notebook。

## 实验协议

- 原文：`../../../Paper/sources/dlw_y_lattice_20261018/DLW_y_lattice_and_2HS.pdf` 的式 (4)–(5)，取 lambda=-2。a=2 固定；不作 a→a+h/2 的对称重参数化。
- A: p=(1), q=(2)；B: p=(4), q=(-3)；C: p=(6,4), q=(-5,-3)；D: p=(1,4), q=(2,-3)。rho=1，初始相位=0。
- 计算半宽 A/B/C/D=10/20/40/40；评价半宽=5/10/30/30。dx=h=0.1，RK4，dt=0.0001，T=0.01。x 为周期中心二阶差分。沿 x 用三次样条采样到 0.01 间距，y 保留原生层，不作 y 插值。
- 全部方法使用连续精确初值及随时间变化的连续精确下侧 u 边界。附件格式的下侧后向模板另取连续精确 ghost u；该最低行的 v 不进入其上方各行的方程。无内部解析值覆盖、滤波或人工粘性。
- FD、PE 直接调用现有 Notebook 对应单元；各次运行保存相同来源的 SHA256。已将这些单元保存为 solver_snapshot.py；compare.py 此后读取该冻结副本，避免 Notebook 后续修改影响复现。
- 附件 endpoint：U,V 均按同一层 y=(j+1/2)h 初始化和与连续解比较，对应其定理6.1的同点解释，整体 y 原点平移不改变方程。这是与现有 FD/PE 共点评价的主表。
- 附件 midpoint：U 位置不变，V 在 y_U-h/2 初始化及比较，符合原文的边中点解释；改变的是采样/初值而不是代数 RHS。此表属于补充实验，v 的 y 点与 FD/PE 不同，不能冒称共点评价。
- 误差为 T 时刻评价区域内连续物理场最大绝对误差，并非原文相对半离散精确解的误差。

## 附件方法实现

状态 P_k=(U_k-U_{k-1})/h 与 V_k。下侧 U 固定，累加 P 恢复 U。记 D1,D2 为 x 中心差分，avgU=(U_k+U_{k-1})/2：

```
P_t = -delta_- D1(U^2/2+2*a*U) - D2(V)
V_t = -D1((avgU+2*a-2*h)*V + h*V^2/4 - 4*avgU
          + D1(delta_-U) - h*(delta_-U)^2/4)
```

P 只储存内部相邻层差；P_t 的 V 对应右端 k 层。该实现与原文对第一式沿 y 累加后推进 U 精确等价（独立数值核验）。

## 精确格点解与误差解释

沿用连续 Gram 子集展开的系数、c_i=-(p_i-a)/(q_i+a)、x/t 相位与二孤子相互作用系数，将 y 相位率替换为

```
lattice_ell_i = [log(1+h/(p_i-a))-log(1-h/(q_i+a))]/h.
U=2(log f-log g)_x
V=2/h [(log f+log g)_x(y)-(log f+log g)_x(y-h)]
```

所得 N=1,2 正则 τ 族满足原文两条双线性式；本支线逐算例核验双线性和非线性残差。independent_checks.json 的 model_gap_refinement 在固定物理坐标采样，h=.1,.05,.025；只检验解析解族模型差，不是时间演化的网格收敛实验。

各运行 JSON 的 paper_exact_gap 是该固定谱参数格点解与连续解之差，distance_to_paper_exact 是数值解到该格点解之差。这两项在函数层面可相加为总误差，但两个最大范数不能相加解释总误差。由于本轮从共同连续初值出发，distance_to_paper_exact 已包含初边值不匹配，不能称为纯数值积分误差；两项可以明显抵消。

`compare.py` 生成主表 16 次计算和附件两种位置解释的 8 次 dt/2 复算；NPZ 保存原生场、状态及沿 y 最大误差剖面，JSON 保存参数、终点误差、初始误差和精确模型差。

## 边中点解释的首项残差

若 U 在点上、V 在边中点，则 delta_-U 与平均 U 在边中点均二阶。附件第一式在边中点的局部残差为 O(h²)，但第二式仍有显式首项

`h * d_x[-2 v + v²/4 - u_y²/4] + O(h²)`

（lambda=-2，固定 a）。因此只把 V 改放边中点并不能把整个系统提高到二阶；这与补充实验中 u 改善较明显而 v 仍偏大的观察相符。此表达是光滑连续场代入后的局部展开，不是全局误差或稳定性定理。
