# 原初值匹配的紧性判据

2026-10-24。条件性证明稿，本会话自查；不构成原初值存在证明或最终否定。沿用 MIXED_BVP_EXISTENCE.md 的 T=.01、rho=.1、R=.7 和固定精确 h=b0。

## 1. 有限匹配如何才能推出精确匹配

终点范数记为 ||g||_r=Σ exp(r|ξ_n|) sup_z |g_n(z)|。取 0<r<rho，B+||h||_rho≤.15。固定有限 L，定义 K：实值终点 g 满足

    ||g||_rho≤B,
    Σ exp(rho|ξ_n|) Lip_z(g_n)≤L,
    g_0=(a0)_0.

可以进一步加上正弦的周期24约束。这里 L 是需要证明的先验约束，不能从有限网格上的斜率自动获得。K 允许有限横向正则性，不要求高阶光滑。

**定理。** K 在 ||·||_r 中紧。令 F(g)=a_g(0)，则：

1. F 在 K 上连续且单射；
2. 若有 g_j∈K，使 ||F(g_j)−a0||_r→0，则存在唯一 g*∈K，F(g*)=a0；整个 g_j 在 ||·||_r 中收敛到 g*；
3. 若 K 中无匹配，则 min_(g∈K)||F(g)−a0||_r>0。

结论3只排除这个指定 K，不能排除 K 外的原问题解。

证明紧性：截断 |n|≤N，余项统一不超过 B exp(−(rho−r)ξ_(N+1))。有限个系数有统一有界性和 Lipschitz 模，由 Arzela–Ascoli 取收敛子列，再用尾界提升到 ||·||_r 收敛。极限的 rho 范数与加权 Lipschitz 和不超过 B,L：逐项极限及有限部分和取上确界即可。实值性、均值和周期约束闭合。因此极限仍属 K。

由混合收缩证明，对 g,k∈K，完整轨迹满足

    ||Z_g−Z_k||_r ≤ C ||g−k||_r,
    C=E/(1−q), E=exp(16 sqrt(T/2)), q=4 sqrt(T/2) E R <1.

256-bit Arb 求值得 C≈8.025628660，因此物理界系数可向上取16.051258和4.012815。这仅核验常数，不核验紧性论证的全部假设。

在较弱 r 范数中沿用相同常数是合法的：两轨迹仍在半径 R 内，代数、积分及热算子的界不变。故 F 连续。单射来自 INITIAL_VALUE_UNIQUENESS.md。紧性给出第2条的子列极限；任意子列的极限都相同，故整列收敛。连续函数在紧集取到最小值，证明第3条。

## 2. 怎样从覆盖检验得到严格排除或误差

设 {g_i}⊂K 是经过证明的 epsilon 网，m_i=||F(g_i)−a0||_r，且已严格包围 m_i。则

    inf_K ||F(g)−a0||_r ≥ min_i m_i − C epsilon.

因此所有中心的下界都超过 C epsilon，就严格排除整个 K。这里“存在有限网”不等于“已计算并验证有限网”；中心的可构造性、覆盖和全模态求值都仍须证明。

若已另外证明匹配存在，任意匹配只能位于满足 m_i≤C epsilon 的中心所对应的 epsilon 球内。只要这些球的并集在终点范数中足够小，即能给出参考误差。具体地，若已证明 ||g*−g_c||_r≤delta，混合解 Z_gc 可作参考，且全闭柱上

    ||u*−u_gc||∞≤2 C delta,
    ||v*−v_gc||∞≤(C/2) delta.

如果参考本身只被数值求值到误差 e_u,e_v，还须分别加上这些经过包围的误差。只有最终上界小于各场待比较误差的1%，才满足 goal。候选初值失配很小，单独不能充当 delta。

紧性加单射也给出逆映射的一致连续性，但不提供可用数值模量。必须执行覆盖排除或取得其他定量估计，不能从“逆连续”直接填写 eta。

## 3. 为什么已有加密结果还不满足判据

已有候选尚未被证明有统一的无限 Fourier rho 范数界、统一 L，也没有经过包围且趋零的精确初值匹配误差。11条有限离散轨迹的相互一致不能替代任一条件。

单独的解析 x 范数上界没有横向紧性。例如 c cos(ξ_1 X) sin(jπz/2) 的该范数统一有界、零均值，却在连续 z 的一致范数中没有收敛子列。原问题包含沿 z 的原函数，并不能仅据这个结构就假设终点的横向振荡受控。

固定 L 只是一个可研究的解类。即使逐一排除了若干 L，也不能排除更大的 L 或仅连续而非 Lipschitz 的终点。当前也未证明原解必在 B 的小数据范围内。

## 4. 本轮实际结论

已有混合存在定理与原初值唯一性，现在可接成一条完整的条件性极限论证：统一尾部与横向变化界 + 初值匹配趋零 ⇒ 原初值精确解存在。指定紧类中的严格正失配下界则给出该类无解。

尚未建立这两种检验所需的实际界；没有原问题存在证书、物理 eta 或全解类否定。目标保持 active。下一步的实质任务是对原初值建立这些界或寻找不依赖它们的值域论证，而非再积累普通浮点加密。
