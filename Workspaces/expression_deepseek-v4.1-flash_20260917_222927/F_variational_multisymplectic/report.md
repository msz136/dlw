## 0. 结论先行

1. **正面积累（已 Lean 代数验证）**：把 DLW 写成 `W = (w, v)`（`w = u_y`）的形式后，其主部为

   ```
   ∂_t W + (u + 2a) ∂_x W + u_x W + J ∂_x² W = 低阶项 ,     J = [[0,1],[1,0]]
   ```

   `J` 是**对称对合**，特征值 `+1` 与 `−1`。于是 `x` 符号 `J ∂_x²` 在对称模 `w + v` 上是
   `−k²`（前向热算子），在反对称模 `w − v` 上是 `+k²`（**后向热算子**）。后者就是不适定性的
   **结构根**。

2. **变分 `y` 离散确实买到了东西（已 Lean 代数验证）**：由离散 Lagrange 函数产生的 `y` 格点映射
   是**辛的**——`Mᵀ Ω M` 的四分量恒为 `(0, ±det M, ∓det M, 0)`，故保辛当且仅当 `det M = 1`；
   其特征多项式是**自伴（回文）的** `A r² + B r + A`，故特征根成**互反对** `r₁ r₂ = 1`。

3. **关键否面结果（本方向最重要）**：`y` 方向的变分原理作用在 `y` 格点上，而 `y` 在这里是**空间方向**。
   故它只能产生 `y` 上的离散多辛结构与相应的 `y` 方向守恒律，
   **完全无法触碰 `x` 符号 `J ∂_x²`**——因为该符号中根本不含 `y` 导数。
   因此 §0.1 的不适定性在**任何**变分/多辛 `y` 离散下保持不变，与有限差分、谱方法、SBP、
   FEM/DG、Poisson 离散化完全一致。

4. **一个附带的正向条件性结论**：当 `v₀ = −2λ`（即 `λ = −2` 时的 `v₀ = 4`）时，`k³` 项系数
   `v₀ + 2λ` **恒为零**，于是半离散色散关系对**每一个** `y` 符号、**每一个** 模都精确等于连续色散关系
   （`D² = k⁴`）。这是"离散化不比连续问题更坏"的最强干净陈述——但**它不是稳定性定理**。

5. **一个诚实的范围限制（已数值验证）**：纯 `y` 的 Lagrange 函数**产生不出 `(x,t)` 演化方程**。
   对 `L_d = (u_{j+1} − u_j) w − (h/2) w²`，对辅助场 `w` 变分**恰好**给出差分约束
   `w = (u_{j+1} − u_j)/h`，而对 `u_j` 变分只给出 `w_{j+1/2} = w_{j−1/2}`（无演化）。
   故 `(x,t)` 动力学必须来自 `t` 方向，`y` 变分原理无法生成它。

## 1. 起点：只离散 `y` 时 `y` 导数出现在哪里

主控智能体已验证的 `w = u_y` 改写（见 `common/SHARED_MATH_SPEC.md`，V5）：

```
(1')  w_t + ∂_x[ v_x + (u + 2a) w ]              = 0
(2')  v_t + ∂_x[ (u + 2a) v + w_x + 2λ u ]       = 0
(3')  u_y = w                                      ← 唯一的 y 导数
```

**结构性观察（本方向全部结论的来源）**：在 (1')–(3') 中，`y` 导数**只**通过约束 (3') 出现；
(1')(2') 中的导数全是 `x` 与 `t` 的。因此：

* `y` 离散的全部影响 = 用某个离散算子替换 (3') 中的 `∂_y`；
* 该替换**只能**经由系数 `u = ∂_y^{-1} w`（或其离散类比）进入 (1')(2')；
* `x` 与 `t` 的微分结构、从而 `x` 符号，**逐字不变**。

这就是为什么"变分/辛/多辛"这类几何结构在本问题中**不可能**改善适定性：
它们约束的是离散化自身的结构，而不适定性是**连续 `x` 符号**的性质。

### 1.1 主部与 `J` 分解

在常数背景 `u ≡ u₀`、`w ≡ 0`、`v ≡ v₀` 处线性化（用 `w = u_y` 使 `u_x = ∂_x ∂_y^{-1} w`）：

```
σ w_hat − k² v_hat + i k (u₀ + 2a) w_hat                     = 0
σ v_hat − k² w_hat + i k (u₀ + 2a) v_hat + (k/Λ) (v₀ + 2λ) w_hat = 0
```

其中 `Λ = Λ_h(ℓ)` 是离散 `d/dy` 的**完整符号**（见 §4 约定）。取 `v₀ = λ = 0`、`Λ = 1` 并把两式
相加、相减，令 `D = σ + i k (u₀+2a)`：

```
w + v :   D (w_hat + v_hat) = + k² (w_hat + v_hat)        ← 前向热（良定支）
w − v :   D (w_hat − v_hat) = − k² (w_hat − v_hat)        ← 后向热（不适定支）
```

符号翻转正是 `J` 的两个特征值 `±1`。`J` 对称、`J² = I`、特征值 `±1`，故 `J ∂_x²` 是
**不定**算子；一个可对称化（强良定）的一阶时间系统不可能有不定主符号。

> **Lean 对应**：`DLWF.Jpair_involution`、`DLWF.xSymbol_symmetric_branch`、
> `DLWF.xSymbol_antisymmetric_branch`、`DLWF.xSymbol_branches_opposite_sign`。
> **证据级别：Lean 代数验证。**

## 2. 变分 `y` 离散能得到什么

设 `y` 方向由离散 Lagrange 函数族产生（标准离散变分原理，`z_j = (u_j, w_j, v_j, …)`）。
其线性化给出的格点映射由**伴随矩阵（transfer matrix）** `T` 承载。对自伴二阶递推
`A z_{j+2} + B z_{j+1} + A z_j = 0`（Bloch 拟设 `z_j = r^j`）：

```
T = [[2 cos θ, −1], [1, 0]],      Ω = [[0,1],[−1,0]]
det T = 1,                        Tᵀ Ω T = Ω
特征多项式：A r² + B r + A   （回文 / 自伴）
特征根：r₁ r₂ = 1                （互反对）
```

一般 `2×2` 矩阵的辛结构是精确的：

```
Mᵀ Ω M = [[0, det M], [−det M, 0]]
```

即**对角元恒为零**（反对称性自动保持），只有行列式起作用；`Mᵀ Ω M = Ω ⟺ det M = 1`。

> **Lean 对应**：`DLWF.symplectic_form_components`、`DLWF.variational_reciprocal_roots`。
> **证据级别：Lean 代数验证。**

### 2.1 但辛性**不是**稳定性——这一点必须说清楚

`r₁ r₂ = 1` 只约束**乘积**，不约束**模**：取 `A = 1, B = −3`，根为
`(3 ± √5)/2`，积为 1，但一个根 `≈ 2.618 > 1`。
**保辛 ⇒ 保面积 ⇒ 不蕴含 `|r| ≤ 1`。**

对本问题而言这个区分格外关键：不适定性表现为 **`x` 方向的模增长 `|Re σ| ~ k²`**，
而不是 `y` 方向格点模的增长。因此"`y` 方向保辛"与"整体稳定性"之间没有任何蕴含关系。
本方向不提供、也不可能提供任何稳定性或收敛定理。

## 3. 核心否面结果：变分 `y` 离散无法改变 `x` 符号

**命题（本方向主结论，数学论证 + 数值验证）**

> 设 `∂_y` 被任意一致离散算子替换，其符号为 `Λ_h(ℓ)`（`Λ_h(ℓ) → ℓ` 当 `h → 0`）。
> 则常数背景线性化系统的 `x` 主符号仍是 `J ∂_x²`，与 `Λ_h` 的选择**无关**。

**论证**：§1 已指出 `x` 符号 `J ∂_x²` 来自 (1')(2') 中的 `v_xx` 与 `w_xx`，而这两项不含任何
`y` 导数。`Λ_h` 只通过 `u = ∂_y^{-1} w` 进入**低阶（`x` 的一阶）**项
`(k/Λ_h)(v₀ + 2λ) w_hat`。因此：

* `k⁴` 项系数**恒为 1**，与 `Λ_h` 无关；对固定 `Λ_h ≠ 0` 与 `|k| → ∞`，`|Re σ|/k² → 1`；
* 六个具体一致符号（中心、前向、后向、交错、P1 一致质量 FEM、谱）全部通过该检验；
* 当 `v₀ + 2λ = 0` 时低阶项**恒消失**，此时离散色散关系与连续完全一致。

**因此**：隐式格式、守恒格式、SBP 耗散、FEM/DG 质量矩阵、辛/多辛结构——**没有任何一种**
能消除该障碍。声称能消除的做法必须给出反例，而本方向的结构分析表明不存在。

### 3.1 附带发现（独立复现了方向 C 的结论）

* 中心差分符号与 **P1 一致质量 FEM** 符号在 Nyquist（`ℓh = π`）**都为零**；
* P1 的零点**不来自质量矩阵**（`2 + cos θ ∈ [1,3]` 处处非零，`det = h²/12 ≠ 0`），
  而来自分子中的中心差分三对角模板 `sin θ`；
* 该零点是**约定无关**的（`Λ_h = 0 ⟺ r_h = 0`），并使半离散系统在该模退化（需独立的 DAE 分析）；
* 前向/后向/交错/谱符号在 Nyquist **不为零**，故不存在这个额外的零模。

> 这与方向 C 的 `muP1_nyquist_zero`（Lean）与 `dg_symbol_no_nyquist_zero`（Lean）**独立一致**。
> 主控智能体在本次运行中亲自用 SymPy 与手算分别复算了 P1 符号
> `i·3 sin θ/(h(2+cos θ))`，确认无误。

## 4. 色散关系与符号约定（本次运行中修正的一处约定混淆）

**修正记录（重要）**：方向 C 的报告使用 `(σ + iAk)² = k⁴ − i(v₀+2λ)k³/μ_h(ℓ)` 的形式，
主控的 `D2` 检查使用 `(σ + iAk)² = k⁴ − (v₀+2λ)k³/Λ_h(ℓ)`。**两者不矛盾，只是 `μ_h` 的
归一化约定不同**，现已在 `common/SHARED_MATH_SPEC.md` §2.0 中钉死：

| 记号 | 定义 | `h → 0` |
|---|---|---|
| `Λ_h(ℓ)` | 离散 `d/dy` 的**完整符号**（模 `e^{iℓy_j}` 上作用为 `i Λ_h`） | `→ ℓ` |
| `r_h(ℓ) = Λ_h(ℓ)/ℓ` | **归一化**符号 | `→ 1` |
| `μ_h(ℓ) = i Λ_h(ℓ)` | 方向 C 使用的**复**符号 | `→ i ℓ` |

三种写法描述同一事实：

```
(σ + i(u₀+2a)k)² = k⁴ − (v₀+2λ) k³ / Λ_h(ℓ)
                 = k⁴ − (v₀+2λ) k³ / (ℓ r_h(ℓ))
                 = k⁴ − i (v₀+2λ) k³ / μ_h(ℓ)          [μ_h := i Λ_h]
```

**任何下游结论不得混用两种约定。** 与约定无关的事实是：`k⁴` 系数恒为 1；`v₀ = −2λ` 时
`k³` 项对一切符号恒消失；`Λ_h = 0`（`⟺ r_h = 0`）是退化波数，需独立 DAE 分析。

## 6. 未形式化 / 未解决的缺口（诚实清单）

1. **没有为本系统显式构造出 `(x,t)` 的 Lagrange 密度。** §0.5 表明纯 `y` 的 Lagrange 函数
   产生不出演化方程；而 `(1')(2')` 的通量含 `∂_x W`，故它不是标准一阶守恒律，
   需要对势（Clebsch）变量才能进入多辛形式。**这一步目前只有定性论证，没有显式构造。**
2. **从"线性化模增长 `~ k²`"到"非线性初值问题 Hadamard 不适定"的桥接未形式化**
   （本次运行中所有方向均未形式化，见 `COMMON` 规范 §6 的证据分级）。
3. `growth_dichotomy` 证明了 `Re σ = 0` **或** `(Re σ)² = R`；**未**证明存在 `k` 使第一支不成立
   （即"增长支确实被取到"）。对一般初值这需要额外论证。
4. §5 中 `variational_reciprocal_roots` 假设了因式分解恒等式；对非线性离散 Lagrange 函数，
   格点映射保辛性的严格陈述（隐函数定理 + 导数的通量形式）未形式化。
5. 有限格点 + 边界条件（而非周期/Bloch）下的多辛性、边界通量项未处理。

## 7. 路线状态与证明覆盖度

**路线状态：`条件可行`**

理由：存在显式、可复现、连续极限正确的变分/多辛 `y` 离散构造（离散 Legendre 变换 +
保辛格点映射），但——

* 必须**限定**在"离散色散关系""`y` 格点辛结构"这类**结构性**陈述上；
* 若 `v₀ + 2λ ≠ 0`，离散色散关系与连续不一致（低阶项 `~ k³/Λ_h`），且 `Λ_h = 0` 处退化；
  唯一干净的条件性一致结论是 `v₀ = −2λ`（`λ=−2` 时 `v₀ = 4`）；
* **无任何**无条件稳定性/收敛定理，且由 §3 该障碍在原则上不可由变分结构消除。

**证明覆盖度：`Lean 代数验证`（主）+ `Lean 分析验证`（`growth_dichotomy_quantitative`）**

明确不是：`Lean 结构验证`（未证明任何定理的完整陈述链）、`数学证明，尚未完整形式化`
（§6.1 的 Lagrange 构造缺失）。

## 8. 最有价值的下一步

具体：由 (1') 引入势 `φ`（`φ_x = w`，`φ_t = −[v_x + (u+2a)w]`），由 (2') 引入势 `ψ`
（`ψ_x = v`，`ψ_t = −[(u+2a)v + w_x + 2λu]`），写出一阶系统并检验其是否落入
`K z_t + M z_x = ∇S(z)`（`K, M` 常值反对称）。若能，则可对 `y` 做真正的多辛离散并

（"DLW 不容许常值系数多辛形式"），这本身是高价值负结果，且适合作为 Lean 目标
（矩阵对称性/反对称性的有限代数判定）。
