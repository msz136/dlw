## 1. 问题

对 (2+1) 维色散长波（DLW）系统
$$u_{yt} + v_{xx} + u\,u_{xy} + u_x u_y + 2a\,u_{xy} = 0,\qquad
v_t + (uv)_x + u_{xxy} + 2a\,v_x + 2\lambda\,u_x = 0$$
我只离散 **`y`**，保持 `x`、`t` 连续（`y`-半离散化）。第一轮取 `λ = −2`、`a` 任意。

核心问题：**能否设计一个离散化，使其精确保持某一守恒律，并满足离散的分部求和（SBP）关系？** 若能，该守恒量是否正定、是否控制所需的范数（即能否给出稳定性）？

## 3. 候选方程与推导

### 3.1 连续出发点是真正的守恒律

令 `w := u_y`，方程 (1) 与 (2) 可以精确改写为
$$w_t + \partial_x\bigl[v_x + (u+2a)w\bigr] = 0, \qquad
v_t + \partial_x\bigl[(u+2a)v + w_x + 2\lambda u\bigr] = 0.$$
（主 agent 已验证 V5。）两式右端都**整体是一个 `x`-散度**。因此在周期 `x`-域上
$$W(t) = \int_x\!\!\int_y w\,dy\,dx,\qquad V(t) = \int_x\!\!\int_y v\,dy\,dx$$
都守恒。这是本方向的**起点**，不是事后拼凑。

### 3.2 离散化与约束

取格点指标 `j ∈ ℤ`，算子
$$D f_j = \frac{f_{j+1}-f_j}{h},\qquad \mathrm{avg}\,f_j = \frac{f_j+f_{j+1}}{2},$$
符号分别为 `μ = (e^{iαh}−1)/h`、`ν = (1+e^{iαh})/2 = e^{iαh/2}\cos(αh/2)`。当 `h → 0`（`α` 固定）时 `μ → iα`、`ν → 1`，格式相容。

把约束 `w = D u` **代入两个方程**（这一点是关键，见 §7 的错误记录），候选半离散对为
$$
\begin{aligned}
\text{(E1)}\quad & D_t u_j + D_x F_j = 0,\qquad F_j = v_{x,j} + \bigl(\mathrm{avg}(u)_j + 2a\bigr) D u_j,\\[2pt]
\text{(E2)}\quad & D_t v_j + D_x\bigl[(\mathrm{avg}(u)_j + 2a) v_j + D_x(D u_j) + 2\lambda\, u_j\bigr] = 0 .
\end{aligned}
$$

`(E1)` 写成**通量形式** `D_t u_j + D_x F_j = 0`，其中 `F_j` 只含一次 `D`（`u_y`），这是全部守恒性的来源。

### 3.3 离散守恒律

因为 `D` 只作用于格点指标 `j`，而 `x`、`t` 连续，所以
$$D_t(Du)_j = D(D_t u_j) = -D_x (D F)_j,$$
即 `D` 与 `∂_x` 交换（Lean：`DLW.DirD.D_shift_comm`、`avg_shift_comm`）。于是在周期 `y`-边界下，格点通量差求和 telescoping：
$$\sum_{j<N} (F_{j+1} - F_j) = 0 \quad\Longrightarrow\quad \frac{d}{dt}\int_x \sum_{j<N} (D u_j)\,dx = 0 .$$
一般边界下（Lean：`constraint_sbp_balance`，边界项**显式保留**）：
$$\Bigl(\sum_{j<N} s_j\Bigr) h = F_0 - F_N .$$

### 3.4 离散乘积的处理（朴素乘积为什么不行）

前向差分**强制**的乘积法则是**对称形式**
$$D(xy)_j = (\mathrm{avg}\,x)_j (Dy)_j + (\mathrm{avg}\,y)_j (Dx)_j$$
（Lean：`d_avg_mul`）。平均算子 `avg` 不是恒等，而是被乘积法则逼出来的。

由此得到非线性项的 SBP 边界恒等式
$$\sum_{j<N} (u_j + u_{j+1})(u_{j+1}-u_j) = u_N^2 - u_0^2$$
（Lean：`avg_sbp`）。右端是**纯边界项**，故周期条件下非线性项净通量为 **0**。

**关键对比**：把非线性项写成朴素的 `2u_j(u_{j+1}-u_j)` 会得到 `4` 而不是 `8`（取 `u=(1,3)`、`h=1`）。也就是说，**朴素乘积破坏离散守恒**，只有平均形式 `avg(u)·D u` 才给出精确边界项。这正是 `(E1)` 中通量必须写成 `(avg(u)+2a)D u` 的原因——不是装饰，而是守恒性的必要条件。

### 3.5 边界条件

| 守恒量 | 需要的 `y`-边界条件 | 残余边界项 |
|---|---|---|
| `Σ_j D u_j`（`W`） | 周期 `u_0 = u_N`，或 SBP 型齐次边界 | `(F_0 − F_N)/h` |
| `Σ_j v_j`（`V`） | 同上 | 保留 |

`x`-方向恒为周期（所有项都是 `x`-散度）。**边界项一律保留在陈述中，从不丢弃。**

## 5. 与方向 C 的接口：Nyquist 伪核

中心差分符号与 P1 一致质量有限元符号**都在 Nyquist 点 `ℓh = π` 处为零**（方向 C 已 Lean 验证）。若把 `D` 换成中心差分型 SBP 算子，会引入一个在连续意义下不存在的**伪核**。

**处理方式**：本方向**不使用**中心差分。`D` 取单侧前向差分，符号 `μ = (e^{iαh}−1)/h` 仅在 `αh ≡ 0 (mod 2π)` 时为零，即仅零模；Nyquist 处 `|μ| = 2/h ≠ 0`。因此**无伪核**。这是"前向差分 + 平均通量"相对"中心差分"的一个具体好处，也是 D-9 的结论（标签 `实验验证`）。

## 6. 障碍（必须如实报告）

**(a) 守恒蕴含不了稳定。**
`(E1)` 所守恒的泛函是 `Σ_j D u_j`，它关于 `u` 是**线性**的。常数列属于 `D` 的核（Lean：`constraint_kernel`）：把 `u` 平移任意常数 `c` 会任意改变 `L²` 范数，却不改变守恒量。因此该守恒量**不能控制任何范数**，**守恒不蕴含稳定**。我把所有守恒主张都写成**条件性**的。

**(b) 线性化病态性不由离散化移除。**
常背景线性化给出
$$[\sigma + i(u_0+2a)k]^2 = k^4 - (v_0+2\lambda)\frac{k^3}{\Lambda_h(\ell)} .$$
对**每一个**相容符号，`k⁴` 的系数都**恰为 1**（已核验六种：中心、前向、后向、交错、P1 一致质量有限元、谱）。因此
$$|\mathrm{Re}\,\sigma| \sim k^2$$
即 Hadamard 病态。

**机制**：`k²` 增长率由 `(1)` 中的 `∂_x² v` 承载，而 `∂_x² v` **不含 `y`-导数**。任何 `y`-离散化都无法触及它。SBP 耗散、守恒性与能量恒等式**都不能**移除它——它们是**离散化**的性质，而该阻断是**连续 `x`-符号**的性质。

数值上，格点最大可分辨模 `α = 2/h` 处的增长率随加密而**发散**：

| `h` | `Re σ` | `h · Re σ` |
|---|---|---|
| 1/10 | 3.834 | 0.3834 |
| 1/20 | 5.257 | 0.2629 |
| 1/50 | 8.155 | 0.1631 |
| 1/100 | 11.459 | 0.1146 |
| 1/1000 | 36.025 | 0.0360 |

`h·Re σ → |sin 2|/2 ≈ 0.45465`，故 `Re σ ~ O(1/h)`：**加密使病态更严重**。这与主 agent 的结论一致。

**(c) 因此"假设 4：离散化能规避病态"被判为失败。** 证据支持失败，且有明确机制。

## 7. 诚实记录：我犯过的错误

推导过程中有两个实质性错误，均已纠正，且**没有**用 `sorry`/`admit`/新 `axiom` 掩盖：

1. **约束代入漏了一次 `μ`**。最初我把 `u_{xxy}` 写成 `D_x w`（其中 `w` 当作独立格点场），这丢掉一个 `μ` 因子，导致色散关系与连续极限不符。正确做法是**先代约束** `w = D u`，得 `D_x(D u)`（两次 `μ`）。
2. **两条假命题**。
   * `d_mul_left`（初版）：`D(xy)_j = (Dx)_j(y_j + \mathrm{avg}\,y_j) + x_j(Dy)_j`。反例 `x_j=1, x_{j+1}=3, y_j=2, y_{j+1}=5, h=1` 给出左端 `19`、右端 `10`。
   * `flux_gauge_identity`（初版）：`D(xy)_j = x_j(Dy)_j + (\mathrm{avg}\,x_j)(Dy)_j + (Dx)_j(\mathrm{avg}\,y_j)`。同一反例下右端含多余项 `x_j(Dy)_j`。
   两条均**已删除**。正确的单边形式是 `D(xy)_j = x_{j+1}(Dy)_j + \mathrm{avg}(y)_j(Dx)_j`（同一反例两端同为 `19`），但预算内未完成其 Lean 证明，故**不纳入已证清单**。这不影响任何守恒结论：D-1 的对称形式已足够。

另有一处工具层面的教训：在**抽象域** `[Field K]` 上，Lean 的 `ring` **不能**规范化 `2⁻¹`（它不认识 `2⁻¹·2 = 1`），导致 `field_simp` 后仍残留 `2⁻¹`。解决方案是把系数域取为 `ℚ`（数值实验也在 `ℚ` 上），此时 `ring` 正常，全部证明通过。这是**工具阻塞**，不是数学障碍，已在文件头注释中说明。

## 9. 最有价值的下一步

**下一步不是继续调整 `y`-离散化，而是对 `∂_x² v` 这一项本身做处理。**

具体建议：把 `(1)` 中的 `∂_x² v`（即 `v_{xx}`）改成**同一格点上的隐式/滤波形式**，或者对 `x`-方向引入带谱滤波的时间积分，使得在格点最大模 `α = 2/h` 处 `Re σ` 不再发散。因为 §6(b) 已证明病态由连续 `x`-符号承载，唯一可能奏效的方向是**同时**离散 `x`（即放弃 `x`-连续假设），并在 `x` 方向也施加 SBP + 滤波。

立即可做且代价小的验证：在 `experiments/e2_linear_symbol.py` 的基础上，扫描**同时**离散 `x`（步长 `Δx`）后的离散色散关系，检查 `Re σ` 在 `Δx, h → 0` 时是否仍有 `k²` 支。预期结论仍是失败，但那次失败将是**完全离散**情形下的，比现在的结论更强。
