# 路线二：可预测的误差预算与位置目标误差

2026-09-23。这里只研究固定网格的误差分解、短时预测和分辨率决策；不分析移动网格或完整散射。SD 指保留有限格距 Gram 解的结构半离散模型，FD 指直接交错有限差分模型。两者都在数值推进时离散了 x 与时间。本文数字来自 `out/route2/budget.json`、`adjoint.json`，图 18–19 由这两份数据直接生成。源码和上游库的 SHA-256 保存在 JSON 中；`experiments/route2_validate.py` 检查这些哈希与逐点恒等式。

## 1. 把一个总误差拆成两个不同的问题

在相同交错物理点、相同时间，对 SD 的有限 h 精确解 \(z_h^*=(u_h^*,v_h^*)\)、连续 DLW 精确解的采样 \(z_0^*\)、实际数值解 \(z_{h,\Delta x,\Delta t}^{\rm num}\)，逐点恒有

\[
z^{\rm num}_{h,\Delta x,\Delta t}-z_0^*
=\underbrace{z_h^*-z_0^*}_{e_{\rm model}}
+\underbrace{z^{\rm num}_{h,\Delta x,\Delta t}-z_h^*}_{e_{\rm solver}}.
\]

这个等式同时用于 u 和 v，但 **\(\|e_{\rm total}\|_\infty\) 不是两个分量范数之和**；方向抵消可使总误差更小。SD 的 \(e_{\rm solver}\) 又含 x 空间实现、时间推进、边界闭合和浮点误差。要继续分辨其来源，需要下面的离散一步缺陷和伴随。FD 没有同一个有限 h Gram 精确解作自身的有限格距真值；把 FD 与 SD 的 Gram 解之差称为“FD 纯求解误差”会偷换对象。因此 FD 在本文使用共同连续初边值的总误差，以及同 h 的细 x FD 数值参照。

所有预算试跑采用 \(L_x=20\)、\(y\) 半宽 1.5、二次外推的背景相对开链闭合、\(T=0.01\)、RK4、\(\Delta t=0.000125\)。P1=(a,p,q,ρ)=(4,1,2,3)，P6=(4,1,3,4)，P10=(2,1.5,2,3.5)。不同 h 的比较固定物理区域，连续参照按 \(y=(j+1/2)h\) 取样。二次外推是新的边界问题，不能把结论套回原固定右幽灵闭合。短时间窗不等于长期传播验收。

## 2. 用一次试跑预测先细化 h 还是 x

只用每组参数的 \(h=1/4,n_x=256\) 试跑，分别估计每个场的 \(C_f=\|e_{\rm model,f}\|_\infty/h^2\) 与求解误差地板 \(S_f=\|e_{\rm solver,f}\|_\infty\)。暂以 \(C_fh^2/S_f\) 预测主导比，平衡尺度为 \(h_{\rm bal,f}=\sqrt{S_f/C_f}\)。**这个式子是由有限 h 精确解族的已测二阶行为启发的试跑决策器，不是固定 x 求解误差严格不随 h 变化的定理。** \(h=1/8,1/16\) 没参与拟合，只用于检验。图 18 展示总误差与两分项。

| 参数 | 场 | 试跑预测 \(h_{\rm bal}\) | \(h=1/8\)：预测/实测模型:求解 | \(h=1/16\)：预测/实测模型:求解 |
|---|---|---:|---:|---:|
| P1 | u | 0.0497 | 6.32 / 6.10 | 1.58 / 1.50 |
| P1 | v | 0.0398 | 9.88 / 9.84 | 2.47 / 2.46 |
| P6 | u | 0.1227 | 1.04 / 1.01 | 0.260 / 0.248 |
| P6 | v | 0.1109 | 1.27 / 1.22 | 0.317 / 0.300 |
| P10 | u | 0.00894 | 195 / 187 | 48.9 / 45.8 |
| P10 | v | 0.0129 | 94.0 / 115 | 23.5 / 30.2 |

P6 的两个场在 \(h=1/16,n_x=256\) 由求解误差主导。固定 h 将 x 节点从 256 增到 512，u/v 对连续参照的最大误差分别由 0.000339/0.000149 降到 0.0000937/0.0000477。P10 此时仍由模型误差主导；同样加密 x，u/v 总误差仅由 0.007164/0.013663 变成 0.007139/0.013592，改 h 更有针对性。P1 在两者之间。这个决策由 **分量预算** 作出，而非凭总误差的单一斜率猜测。观察到的 P10 v 比值偏离试跑预测约 28%，说明试跑系数只能定位量级和主导区域，不能视为精确误差公式。

上表本身没有参数外推验证：P1/P6/P10 各自都有一次试跑，留出的是 h。表中也未证明 \(h_{\rm bal}\) 是计算成本意义上的最优点。记录的单次耗时随 x 节点数增加，但它不是受控的成本基准；可以据此制定下一批测试，不能给出普适成本最优定理。

### 2.1 真正留出参数：用初始缺陷预测求解误差地板

为使参数外推可证伪，另外只用 P2/P3/P4/P5/P7/P8/P9 的 \(h=1/4,n_x=256\) 轨道校准一个无量纲因子
\(k_f=\operatorname{median}_{\theta\in\mathrm{train}}
[\|e_{\rm solver,f}(T)\|_\infty/(T\|O_fr_\theta(0)\|_\infty)]\)。
这里 \(r_\theta(0)=F(0,\bar Z)-\dot{\bar Z}\) 是初始状态缺陷，\(O_f\) 是状态误差到 u 或 v 的**线性重构输出算子**。实测中位数为 \(k_u=1.1696,k_v=0.9459\)。对完全留出的 P1/P6/P10，仅计算初始缺陷和有限 h/连续精确解的模型系数 \(C_f\)，不使用它们的数值轨道来预测：

\[
\widehat S_f=k_fT\|O_fr_\theta(0)\|_\infty,\qquad
\widehat R_f(h)=C_fh^2/\widehat S_f.
\]

预测锁定后才用它们在 \(h=1/16\) 的实际推进检查。原始校准和留出结果在 `out/route2/crossparam.json`。

| 留出参数 | 场 | 预测 \(h=1/16\) 模型:求解 | 实测模型:求解 | 预测/实测 |
|---|---|---:|---:|---:|
| P1 | u | 1.478 | 1.501 | 0.985 |
| P1 | v | 2.317 | 2.462 | 0.941 |
| P6 | u | 0.284 | 0.248 | 1.147 |
| P6 | v | 0.363 | 0.300 | 1.208 |
| P10 | u | 61.14 | 45.78 | 1.336 |
| P10 | v | 33.57 | 30.15 | 1.113 |

六个留出判断均正确区分模型误差与求解误差的主导侧，数量预测最差约差 34%。这个结果比按每个目标参数分别试跑更强，但 P8/P9 与留出 P1 共用 \((a,p,q)\)，只改变 \(\rho\)，因此 P1 不是全新谱参数族的检验；P6/P10 则提供不同的谱参数组合。训练组内部的比例 \(\|e_{\rm solver}\|/(T\|O_fr(0)\|)\) 变化很大：u 从约 1.04 到 4.15，v 从约 0.81 到 8.02。中位数恰好对三组留出参数有效，**不能据此断言初始缺陷普遍预言长时间误差**。尤其 P5 的小缺陷与较大放大因子提醒我们，时间传播算子仍然重要。此处的 \(C_f\) 来自解析精确解的有限 h 取值；对没有精确解族的任意初值，不能直接照用这一便宜特征。

## 3. 在共同连续问题上对照 FD

两模型从相同连续初值出发，采用相同格点、时间步、连续时变边界和二次外推规则。在 \(h=1/8,n_x=256,T=0.01\) 的最大场误差为：

| 参数 | SD u / v | FD u / v |
|---|---:|---:|
| P1 | 0.00002797 / 0.00001282 | 0.00004144 / 0.00001403 |
| P6 | 0.00030224 / 0.00013285 | 0.00033676 / 0.00013977 |
| P10 | 0.00341195 / 0.00308210 | 0.00101871 / 0.00477104 |

结果没有统一胜者，P10 甚至出现 SD 的 u 较大而 v 较小。FD 的同 h、\(n_x=256\) 与 512 轨道在粗 x 点的 u/v 差异分别为 P6 的 0.000300/0.000122、P10 的 0.000124/0.000343；512 点时间步减半的差异不超过 \(2.0\times10^{-10}\)。这支持这些 FD 对照主要受空间实现而非所选时间步影响，但细 x FD 轨道仍是数值参照，**不是 FD 模型的解析解**。SD 的可积结构在这张通用场误差表中没有自动转化为逐场优势。

## 4. 把求解误差继续拆到“何时注入、如何影响位置”

对一条连续精确背景的采样状态 \(\bar Z_n\)，实际一步 RK4 映射记为 \(\Psi_n\)，数值误差 \(e_n=Z_n-\bar Z_n\)。在固定网格上定义

\[
b_n=\Psi_n(\bar Z_n)-\bar Z_{n+1},\quad
M_n=D\Psi_n(\bar Z_n),\quad
q_n=\Psi_n(\bar Z_n+e_n)-\Psi_n(\bar Z_n)-M_ne_n.
\]

于是 **逐步精确** 有 \(e_{n+1}=M_ne_n+b_n+q_n\)。这里 \(b_n\) 是对连续背景的一步缺陷，既包括模型差异，也包括 x 实现和时间积分；\(q_n\) 是实际误差上的非线性余项。再令

\[
c_n=\bar Z_n+\frac{\Delta t}{6}
[\dot{\bar Z}_n+4\dot{\bar Z}_{n+1/2}+\dot{\bar Z}_{n+1}]-\bar Z_{n+1},
\qquad s_n=b_n-c_n.
\]

\(c_n\) 是参照时间导数的 Simpson 余项；\(s_n\) 是剩余的一步动力学缺陷，**不能进一步自动称为“纯空间”或“纯模型”误差**，因为 RK4 的内部级也依赖离散 RHS。脚本 JSON 中的键 `spatial` 历史命名应按此定义解读。若要再拆模型与 x，需分别构造可比的半离散一步映射。本文不把三点采样的 RHS 缺陷最大值称为连续时间严格上界。

为研究位置而不是全场最大误差，在最接近 \(y=0\) 的 u 剖面上取精确背景平移切向 \(u_x^*\)，定义光滑线性位置目标

\[
J(e)=-\langle e_u,u_x^*\rangle/\langle u_x^*,u_x^*\rangle.
\]

实际位置另用非线性全剖面最小二乘平移拟合，二者不能混称。设 \(\lambda_N=\nabla J\)，\(\lambda_n=M_n^T\lambda_{n+1}\)。这里的 \(M_n\) **精确微分实际 RK4 的四个内部级及其时变边界**，不是连续 PDE 的伴随。初始误差为零时，

\[
J(e_N)=\sum_n\lambda_{n+1}^{T}(s_n+c_n+q_n).
\]

对 P1/P6 使用 \(h=1/2,n_x=32,T=0.01\) 以计算完整离散雅可比；P6 同时比较 SD 与 FD，另将 SD 时间步减半。这个小网格诊断与上一节的 256 点预算不是同一分辨率，不能直接拼接两表作误差大小比较。

| 背景/模型 | 线性位置预测 | 实际线性位置 | 非线性剖面平移拟合 | 逐格绝对和上界 |
|---|---:|---:|---:|---:|
| P1 / SD | 0.00000041666 | 0.00000041507 | 0.00000041619 | 0.00077477 |
| P6 / SD | 0.000462339 | 0.000462326 | 0.000466571 | 0.00174420 |
| P6 / FD | 0.000466884 | 0.000466871 | 0.000471171 | 0.00173277 |

P6 的 SD/FD 位置误差也很接近。线性位置的预测偏差在 P6 SD 约 \(1.27\times10^{-8}\)，其中后验算出的非线性余项有符号贡献约 \(-1.27\times10^{-8}\)；参照 Simpson 贡献约 \(10^{-15}\)。SD 时间步减半后，实际拟合由 0.00046657119 变成 0.00046657134，结论不依赖当前时间步的最后几位。实际剖面拟合与线性目标的差异（P6 约 \(4.2\times10^{-6}\)）明显大于线性动力学预测误差，故不能用线性目标的极高吻合度宣称“真实位置预测精确到八位”。P1 的位置量远小于移位后形状 RMS \(3.14\times10^{-4}\)，应特别避免把微小平移当作高置信度的独立物理信号。

“逐格绝对和”是 \(\sum_{n,k}|\lambda_{n+1,k}s_{n,k}|\) 加对应 \(c\) 项，它**代数上界定了离散线性目标预测的绝对值**，但比有符号预测保守：P1 约 1860 倍，P6 SD 约 3.77 倍。再加入实测 \(q_n\) 的绝对贡献得到的是后验分解界，不是预测型先验上界，更不是原 PDE 长时误差界。图 19 显示逐步有符号贡献与逐格绝对量如何抵消。

## 5. 证据边界与下一次可证伪检验

完成的证据是：25 次预算推进、7 条仅用于校准的额外参数轨道、4 次完整 RK4 伴随诊断；76 项存档一致性检查通过，包括逐点 u/v 分解、FD 同 h 细网格比较、源哈希、伴随转置与 RK4 切向有限差分。线性位置递推的代数重构残差低于 \(5\times10^{-11}\)，转置检查在 \(10^{-15}\) 量级。上述是有限网格、有限时间、所选正则参数上的计算事实。此前理论文件的 \(K,C\) 是局部保守常数；它们在 \(t=0\) 算出，不能与有限时刻采样的缺陷直接拼成严格连续时间上界。

下一次最有信息量的检验是扩大真正留出的参数区，特别纳入训练中 P5 一类初始缺陷与后期误差比例异常的区域；再把目标换成两个场的位置和波形指标，检查平移切向的拟合条件数与伴随敏感性。若这些检验失败，应报告适用区域，而不是继续将 h 平衡公式包装成普遍优化法。本轮已完成的结论限于“误差主导项可以在所测三组参数的留出 h 与留出参数检验中预测，且离散伴随能把短时位置误差按注入时间和格点归因”。

复现：在本目录运行 `python -u experiments/route2_budget.py`、`python -u experiments/route2_crossparam.py`、`python -u experiments/route2_adjoint.py`、`python experiments/route2_validate.py`、`python experiments/route2_figures.py`。环境需已安装本目录现有的 NumPy、SciPy、Matplotlib。图像为 `figures/fig18_route2_budget.png` 与 `figures/fig19_route2_adjoint.png`，逐配置场数组在 `out/route2/fields_*.npz`。
