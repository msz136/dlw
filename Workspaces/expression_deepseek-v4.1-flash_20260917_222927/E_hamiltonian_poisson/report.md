# 方向 E：`y`-离散化下的 Hamiltonian / Poisson 结构

**对象**：DLW 系统（Sheng–Yu, Physica D **432** (2022) 133140），本轮取 `λ = -2`，`a` 任意。
**离散化范围**：**只离散 `y`**（格点 `j`），`x, t` 保持连续。以下简称"半离散"。
**共享约定**：`w := u_y`；约束一阶系统
`u_y = w`，`w_t + ∂_x[v_x + (u+2a)w] = 0`，`v_t + ∂_x[(u+2a)v + w_x + 2λu] = 0`（spec §1.1，MAIN-VERIFIED V5）。

---

## 1. 构造

### 1.1 半离散系统

在 `y` 格点 `j ∈ ℤ`（或 `j = 0..n-1`）上，`x, t` 连续：

```
∂_t w_j + ∂_x[ (∂_x v)_j + (u_j + 2a) w_j ]                    = 0
∂_t v_j + ∂_x[ (u_j + 2a) v_j + (∂_x w)_j + 2λ u_j ]            = 0
```

其中离散约束由所选 `∂_y^{-1}` 的矩阵 `C` 给出：

```
u = C w            (即 u_j = Σ_k C_{jk} w_k )
```

后者即"算 `u` 需要累加和"的那一步，是本方向全部困难的来源。记 `Z = (w, v)`，`Φ = (M, N)`：

```
M_j = (∂_x v)_j + (u_j + 2a) w_j ,      N_j = (u_j + 2a) v_j + (∂_x w)_j + 2λ u_j ,
∂_t Z = - ∂_x Φ .
```

两条方程都仍是**精确的 `x`-散度**（与连续情形一致，逐系数相同）。

### 1.2 受检类 𝒞

```
P = ∂_x · Q ,   Q = Qᵀ 可逆，Q 与 x 无关、与场无关（常矩阵），Q ∈ Mat_{2n}(K)。
```

这是 KP 型积分系统"第一括号"的自然类（`∂_x` 前置 + 常系数对称核）。其 `y`-平移不变子类即
`Q = q ⊗ I_n`（`q` 为常 `2×2` 对称可逆阵），也是"离散化 `P` 在 `y` 上的最自然方式"。

要求 `∂_t Z = P · (δH/δw, δH/δv)ᵀ`，即 `Q · δH/δZ = -Φ`，故

```
δH/δZ = - Q^{-1} Φ .
```

由形式变分学（Helmholtz 条件），`H` 存在的**必要**条件为 `Q^{-1} DΦ` 形式自伴，等价于

```
DΦ · Q 对称 ,      DΦ := Φ 的 Fréchet 导数 .
```

`DΦ` 的分块形式（`D_x` 为 `∂_x` 的象征，`I` 为单位阵，`diag` 表示逐格点对角）：

```
        ⎛      A            D_x I  ⎞
DΦ  =   ⎜                         ⎟ ,   A = diag(u+2a) + diag(w) C ,
        ⎝ D_x I + E       B       ⎠      B = diag(u+2a) ,  E = diag(v+2λ) C .
```

### 1.3 障碍算子与主要否定结果

定义

```
Θ := A - Aᵀ = diag(w) C - Cᵀ diag(w) ,        Θ_{ij} = w_i C_{ij} - w_j C_{ji} .
```

`Θ` **自动反对称**（`Θᵀ = -Θ`），即与 `∂_x` 完全同型；其元素显式依赖场 `w`。当 `Cᵀ = -C`（周期/零均值约定，见 §1.4）时 `Θ = diag(w) C + C diag(w)`。

对 `Q = q ⊗ I_n`，分块系数匹配给出三条 Helmholtz 方程：

| 来源 | 方程 |
|---|---|
| `(1,1)` 分块，`D_x^0` | `q₁₁ · Θ = 0` |
| `(1,1)` 分块，`D_x^1` | `q₁₂ = 0` |
| `(1,2)` 分块，`D_x^1` | `q₂₂ + q₁₁ = 0` |

（`(2,2)` 分块在 `q₁₂ = 0` 后自动满足。）取测试函数 `φ ≡ 1` 于第一条得 `q₁₁ Θ = 0`；再取 `φ = x` 得 `q₁₂ = 0`。于是对一般场（`Θ ≠ 0`）有 `q₁₁ = q₂₂ = 0`。

> **命题 E1（否定，类 𝒞）.** 对一般场值（`w` 非 `y`-常数且耦合开启，即 `Θ ≠ 0`），类 𝒞 中
> **不存在** Hamiltonian `H` 使 `∂_t(w,v) = ∂_x Q (δH/δw, δH/δv)ᵀ`；Helmholtz 方程的唯一解是
> `Q = 0`（不可逆，因而不是 Poisson/辛算子）。
> 对被否定的范围必须说清楚：这是**常系数、`x`-平移不变、场无关**的 $2n\times2n$ 对称核类。

进一步（不假设 `Q = q ⊗ I`，允许任意常 `2n×2n` 对称块矩阵），五条分块方程

```
(S1) A Q₁₁ = Q₁₁ Aᵀ          (S2) Q₁₂ᵀ = -Q₁₂        (S3) Q₂₂ = Q₁₁
(S4) A Q₁₂ = Q₁₁ Eᵀ + Q₁₂ B   (S5) E Q₁₂ + B Q₁₁ + Q₁₂ Eᵀ = Q₁₁ B
```

在 `n = 2`、一般反对称 `C`（自由符号元素）、`w,v,a,λ` 全符号下**唯一解为 `Q = 0`**（SymPy 全符号）；`n = 3,4` 循环反对称 `C` 与 `n = 2,3,4` 单侧累加和下，精确有理采样均只给出零解或奇异解（见 §6 与 `experiments/`）。

**为什么"没有括号"是结构性的而非法艺问题**：`Θ` 是**场相关**的反对称算子，而 `Q` 是**场无关**的；唯一能抵消反对称性的常系数算子是 `∂_x` 的倍数，而 `Θ` 不是。取连续极限 `C → ∂_y^{-1}`（`(∂_y^{-1})^* = -∂_y^{-1}`）得

```
Θ_h  →  Θ_∞ = w ∂_y^{-1} + ∂_y^{-1} w  ≠  0    (w 非 y-常数)
```

即**障碍在连续极限中并不消失**。因此不可能通过"更好的离散化"获得保 Poisson 的 `y`-离散化：连续对象本身在类 𝒞 中就没有括号。

### 1.4 两种离散 `∂_y^{-1}` 约定

* **(a) 中心差 + 零均值（推荐）**：`δ_y` 为中心差，`C` 为它在零均值子空间上的伪逆。此时
  `Cᵀ = -C` 严格成立，与连续 `(∂_y^{-1})^* = -∂_y^{-1}` 一致，`Θ = diag(w)C + C diag(w)`。周期格点上 `C` 为循环阵，理想地"像 Hilbert 变换"。
* **(b) 单侧累加和**：`u_j = Σ_{i<j} h w_i`，`C` 严格下三角，`Cᵀ ≠ -C`。此时 `w_{n-1}` 根本不出现在 `Φ` 中，`Θ` 只依赖 `w_j (j ≥ 1)`，且 Helmholtz 系统留下**唯一残解**
  `Q₁₁ = p·E_{n-1,n-1}`、`Q₁₂ = 0`，其中 `E` 为矩阵单位 —— 仍**奇异**，仍不是括号。

### 1.5 约束处理：为什么没有采用 Dirac 括号

任务书提示"若自然表述需要 `u` 独立，则把约束 `u_y = w` 放进括号（Dirac/约束括号）"。我们做了该尝试并报告结果：

* 在扩展相空间 `(u,w,v)` 上保留约束 `u_y = w`、并以标准配对 `{u,v} = c ∂_x` 构造括号时，约束传播给出的 Helmholtz 条件要求 `(u+2a)/c = -(u+2a)/c`，即 `c = 0` 或 `u ≡ -2a`（**手算推导，未形式化**）。故该标准配对**不能**给出约束括号。
* 因此本方向采用的是"消去 `u`、以 `u = Cw` 代入"的路线，并如实报告类 𝒞 中的否定结论，而不是宣称存在 Dirac 括号。

## 2. 连续极限与相容阶

* **`u_y` 的离散逼近阶**：中心差 `O(h²)`；单侧差 `O(h)`。
* **`u = C w` 的重构阶**：约定 (a)（伪逆，零均值）为 `O(h²)`；约定 (b)（累加和）为 `O(h)`。
* **半离散系统的相容阶**：约定 (a) 二阶；约定 (b) 一阶。这与共享模块 `Common/Operators.lean` 中已验证的 `ctr`/`bwd`/`fwd` 及 `sbp_fwd` 相容。
* **障碍的相容阶（关键）**：`Θ_h = Θ_∞ + O(h²)`（中心差）。由于 `Θ_∞ ≠ 0`，**任何阶的相容性都不能使障碍消失**；相反，相容性把障碍精确地传给了连续极限。这正是"保 Poisson 离散化不存在"的严格原因 —— 不是离散化坏，而是连续对象在类 𝒞 中无括号。

注意：以上是**形式 Taylor / 象征层面的相容性**，不是余项估计；本文不含任何收敛定理。

## 3. 变量变换可行性（VT）

`u = 2(ln(f/g))_x`，`v = 2(ln(fg))_{xy}`。

1. **类 𝒞 中不存在括号**，故"括号是否在 VT 下存活"在类 𝒞 内是空问题（没有东西可搬运）。这是本节最重要的诚实结论。
2. **假设存在局域括号**：`(f,g) → w = δ_y u` 是**局域**的（3 点 `y`-模板上的对数导数），`v = 2(ln(fg))_{xy}` 亦局域，故 `(w,v)`-括号推前到 `(f,g)` 后**仍局域**，模板宽度 3。
3. **但 `u = C w` 破坏局域性**：`C` 是累加和/伪逆，作用在 `2(ln(f/g))_x` 上得到 `y`-方向的累积和 —— 在 `(f,g)` 上**非局域**。即：`w, v` 局域，`u` 非局域（见 §4）。
4. **规范退化阻断推前**：`(f,g) ↦ (f e^{p}, g e^{-p})`（`p` 任意）保持 `(u,v)` 不变，故 VT 的 Jacobi 在规范方向退化；括号**不能**直接推前为 `(f,g)` 上的 Poisson 括号，除非固定规范（例如 `fg` 或 `f/g` 的某一均值条件）。这一条是结构性论断，**未形式化**。
5. **零模的 tau 表示**：`v ≡ -2λ = 4` 等价于 `(ln fg)_{xy} = 2`，即 `fg = e^{2xy} α(x) β(y)`，落在 tau 函数类内。故**精确零模不被 VT 排除**。

## 4. 局部性与闭合性

* **模板宽度**：`Φ_j` 只依赖 `{w_j, v_j, u_j, w_{j±1}, v_{j±1}}`，`y`-模板宽度 **3**；`x` 方向只出现 `∂_x`（`Φ` 为精确 `x`-散度）。整个半离散系统是 `y` 上的最近邻格式。
* **非局域性来源**（必须点名）：
  1. `u = C w` 中 `C` 是 `y` 上的**稠密**线性算子（单侧累加和，或周期格点上的循环伪逆）。因此 **`u` 对 `w` 非局域**；`w`、`v` 本身局域。
  2. 障碍算子 `Θ = diag(w)C - Cᵀ diag(w)` **正是这一非局域性的精确度量**：它把"常数核 `Q`"与"场相关的 `y`-非局域耦合"放在同一个 `D_x^0` 系数层级上，二者不相容。
* **`x` 方向**：类 𝒞 只用 `∂_x`。手算表明把 `Q` 放宽为常系数伪微分算子 `Q(∂_x)`（含 `∂_x^{-1}`）也不能补救：障碍 `Θ` 依赖场而 `Q(∂_x)` 不依赖场，二者无法抵消（**手算，未形式化**）。
* **边界/闭合性**：单侧累加和约定下 `w_{n-1}` 不可见（`C` 的最后一行为 `(1,…,1,0)`），且 `w` 的均值不受约束；因此约束 `u_y = w` 只能解到 `y`-常数。这是离散 `∂_y` 的核，必须用一个规范（取 `u` 的格点均值为 0）固定。共享模块已验证的 `ctr_kernel` 正是同一现象。

## 5. 零模与稳定性

### 5.1 精确零模

`v ≡ -2λ = 4`，`u = U(x,t)`（即 `u_y = 0`、`w ≡ 0`）是 (1)–(2) 的**精确**解（spec §2, V7）。离散版逐点验证：所有 `y`-导数项消失，`w_j ≡ 0`，`v_j ≡ -2λ`，两条方程成为恒等式。故

> **离散格式精确保持该零模**，且这是障碍消失的**唯一**位置：此处 `Θ = 0` 且 `E = 0`，Helmholtz 方程退化为 `q₂₂ + q₁₁ = 0`，可取 `Q = diag(q, -q)`。

这在逻辑上是自洽的：零模正是"`u`–`w` 耦合关闭、系统退化为 `v` 的线性 `x`-输运方程"的位置，此时 Hamiltonian 结构当然可以存在（但已不含非线性内容）。

### 5.2 `∂_y` 的核（`u` 为 `y`-常数）

* `w ≡ 0`（`u` 不依赖 `y`）：`Θ = 0`，障碍消失 —— 但约束 `u_y = w` 不再含信息，`u` 成为参数。
* `w ≡ c ≠ 0`（`u` 为 `y` 的非常数线性函数）：`Θ = 2c·C ≠ 0`（`Cᵀ = -C` 时），**障碍不消失**。即"`u` 在 `y` 上取常斜率"**不是**安全情形。
* 一般核：见 §4 的零均值规范。

### 5.3 标准阻碍（spec §2）——本方向**不**主张消除它

半离散线性化在常数背景 `(u₀,v₀)` 上的色散为

```
(σ + i (u₀ + 2a) k)²  =  k⁴ − (v₀ + 2λ) k³ / μ_h(ℓ) ,      μ_h(ℓ) → 1 ,
```

故对**每一个**相容格式、`|k| → ∞` 时 `|Re σ| ~ k²`。这是 Hadamard 不适定，是**连续象征**的性质。

* **本方向明确不主张**（也不允许主张）Hamiltonian / Poisson / 辛结构能消除该阻碍。恰恰相反：本方向的结论比"结构无效"更强 —— 在类 𝒞 中**连括号都不存在**，因此不存在"用结构换来一致稳定性"的可能。
* **结构买到什么**（若在更大的类中存在）：精确守恒量、结构保持、离散零模的精确保持、以及把"哪一种非局域性阻止了括号"精确识别出来（本报告的核心产出 `Θ`）。
* **结构买不到什么**：一致适定、网格一致稳定、`k²` 增长的消除、任意初值的收敛定理。
* 一切稳定性陈述都是**条件的**：带限 `|k| ≤ K`、解析/带限初值、固定截断维数 `n`。线性化稳定 / 有限带稳定 / 非线性稳定三者互不蕴含；本报告**不**给出其中任何一个的证明。

## 7. 明确未证的缺口

### 7.1 已 Lean 验证

§6 表中全部条目（`DLW.E.theta_entry`、`theta_antisym`、`theta_eq_of_skew`、`Theta3_*`、`no_invertible_constant_poisson_bracket`、`no_nontrivial_constant_poisson_Q`）。

### 7.2 已实验验证（SymPy，精确有理/符号）

1. 一般常对称 `Q`（`2n×2n`，带 `y`-块结构）的五条 Helmholtz 分块方程：`n = 2` 一般反对称 `C`、`w,v,a,λ` **全符号** ⟹ 唯一解 `Q = 0`。
2. 同上，`n = 3,4` 循环反对称 `C`：两组独立的有理采样 ⟹ 唯一解 `Q = 0`。
3. 单侧累加和约定 `n = 3,4`：唯一解 `Q₁₁ = p·E_{n-1,n-1}`、`Q₁₂ = 0` ⟹ **奇异**。
4. `Θ = A − Aᵀ`、`Θ` 反对称、`Θ_{ij} = w_i C_{ij} − w_j C_{ji}`（`n = 2,3,4`）。
5. 零模处 `E − Eᵀ = 0`；`w ≡ 0` 处 `Θ = 0`；零模但 `w` 非常数处 `Θ ≠ 0`。

### 7.3 数学证明，尚未完整形式化

1. 连续极限 `Θ_h → w∂_y^{-1} + ∂_y^{-1}w ≠ 0`，以及 `Θ_h − Θ_∞ = O(h²)`（中心差）。
2. 常系数伪微分核 `Q(∂_x)`（含 `∂_x^{-1}`）不能补救（手算）。
3. 标准 `(u,v)` 配对 `{u,v} = c∂_x` 的约束括号失败（手算：要求 `(u+2a)/c = −(u+2a)/c`）。
4. VT 的规范退化阻断括号推前；`u` 在 `(f,g)` 上非局域、`w,v` 局域。
5. 离散格式精确保持精确零模。

### 7.4 完全未论证 / 开放

1. **场相关核 `Q = Q(w,v,…)`** 的一般分类。仅证明（手算）0 阶场相关 `Q` 的 `(2,2)` 分块方程迫使 `Q₁₂ = 0`，`(1,1)` 分块化为泛函方程 `w S(aφ) + a S(wφ) = 0`（一般场下无解）；含 `∂_x` 且场相关的核**未分类**。
2. **`x` 方向非局域但场相关的括号**（含 `∂_x^{-1}` 且系数依赖场）未分类 —— 这是最可能藏有真正 mKP 型结构的地方，本方向未触及。
3. **无**稳定性、适定性、收敛定理。§5.3 的一切均为条件性陈述。
4. 离散系统的非线性闭式（对数变量）**未处理**（属方向 G）。
5. 未做独立文献检索；**不主张任何新颖性**。

## 路线状态

**`候选被否定`** —— 被否定的精确范围：类 𝒞（`P = ∂_x Q`，`Q` 为 `x`-平移不变、场无关、可逆的常对称 `2n×2n` 核）。在该类中，对一般场值不存在 Hamiltonian 表述；Helmholtz 方程的唯一解是奇异的 `Q = 0`。障碍 `Θ = diag(w)C − Cᵀdiag(w)` 在连续极限中非零，故该否定**不是**离散化造成的，也不能通过加密网格回避。
类 𝒞 之外的更大类（场相关核、`x`-非局域核、约束 Dirac 括号）**尚未解决**，见 §7.4。

## 证明覆盖度

**`Lean 代数验证`** —— 一般代数关系（`Θ` 的反对称性、元素公式、斜伴随下的反对称换位子形式）与 `Fin 3` 具体格点上的否定定理均已形式化；**变分学桥接（Helmholtz ⟹ 三条系数方程）未形式化**，故不主张 `Lean 结构验证`，更不主张 `Lean 分析验证`。无任何分析层面（余项/稳定性/收敛）的形式化。
