# 方向 C — DLW 系统在 `y` 方向的混合有限元 / 间断 Galerkin 离散

**范围**：只离散 `y`；`x`、`t` 保持连续。第一轮参数 `λ = -2`，`a` 任意。
**依据方程**（精确改写，`w = u_y`；SHARED_MATH_SPEC §1.1，[MAIN-VERIFIED — V5]）：

```
(1')  w_t + ∂_x[ v_x + (u + 2a) w ] = 0
(2')  v_t + ∂_x[ (u + 2a) v + w_x + 2λ u ] = 0        w = u_y
```

**关键结构观察（本方向的出发点）**：在 (1')–(2') 中，`y` 导数**只**通过约束 `w = u_y` 出现，
`x`、`t` 方向不含 `y` 导数。因此「在 `y` 上用什么离散」这件事，对半离散系统的影响**恰好**是
一对对象：

* 质量矩阵 `M_h`（出现于所有 `y` 积分与时间导数项），
* 离散 `y` 导数算子 `D_h`（把 `w_h = ∂_y u_h` 换成 `W = D_h U`）。

下面三个变体都是同一个半离散框架下不同的 `(M_h, D_h)`。这一点使 FEM/DG 的分析非常干净，
也是后面所有结论（局部性、Nyquist 零模、VT 可行性）的唯一来源。

## 1. 构造

网格：`y_j = jh`（`j ∈ ℤ` 双无限，或 `j = 0..N` 有限区间；周期情形 `y_{j+N} = y_j`）。
未知量：`u_h(x,t,y) = Σ_j U_j(x,t) φ_j(y)`，同理 `w_h = Σ_j W_j(x,t) φ_j(y)`，`v_h = Σ_j V_j(x,t) φ_j(y)`。
**离散未知向量**是三个节点值向量 `U, W, V ∈ ℝ^N(x,t)`（每层 `x,t` 取值不同）。

### 1.1 P1（线性元）一致质量 FEM（S1）

单元 `I_j = [y_j, y_{j+1}]`，`φ_j` 为标准 hat 函数。一致质量矩阵与刚度矩阵的**单元**形式为

```
M_e = (h/6) [[2,1],[1,2]]          det M_e = h²/12
K_e = (1/h) [[1,-1],[-1,1]]        K_e (1,1)ᵀ = 0
```

全局组装（周期、均匀网格）：`M_{jj} = 2h/3`，`M_{j,j±1} = h/6`（三对角）；
`K_{jj} = 2/h`，`K_{j,j±1} = -1/h`。**迁移矩阵** `A_{ij} = ∫ φ_i' φ_j dy` 满足

```
A_{j,j+1} = -1/2 ,  A_{j,j-1} = +1/2 ,  A_{jj} = 0 ,   A = -Aᵀ = -h · (中心差分)
```

一致质量的 Galerkin 离散把 `∂/∂y` 换成 **L² 投影导数**

```
D_h := M_h^{-1} A_hᵀ ,      (即 M_h W = A_hᵀ U  ⇔  ∫ w_h φ_i = ∫ ∂_y u_h φ_i )
```

半离散格式（`T(P)_{ik} = Σ_j P_j ∫φ_iφ_jφ_k` 为单元内三乘积张量，`T(U+2a) := T(U) + 2a M`）：

```
(S1a)  M Ẇ + M V_xx + ∂_x[ T(U+2a) W ]                        = 0
(S1b)  M V̇ + ∂_x[ T(U+2a) V ] + ∂_x[ M W ] + 2a ∂_x[ M V ] + 2λ ∂_x[ M U ] = 0
(S1c)  M W = Aᵀ U
```

`T` 是三对角（单元内）**局部**张量：`∫φ_0³ = h/4`，`∫φ_0²φ_1 = ∫φ_0φ_1² = h/12`，`∫φ_1³ = h/4`。
非线性项因此是带状的；**唯一的非局部性来源是 `M^{-1}`**（见 §4）。

### 1.2 P0 DG-upwind（S2）

未知量取单元平均 `U_j = (1/h)∫_{I_j} u_h`，`φ_j = 1_{I_j}`，故 `M = h·I`（对角、精确可逆）。
约束用 DG 弱形式加**迎风（左迹）数值通量**：

```
∫(w_h - ∂_y u_h) φ_i = 0   ⇔   h W_j = -∫_{I_j} u_h φ_i' + [ û φ_i ]_{∂I_j} ,  û = 左迹
  ⇒  W_j = (U_j - U_{j-1})/h ,  D_h U|_j = (U_j - U_{j-1})/h
```

半离散格式仍为 (S1a)–(S1c)，只是 `M = hI`、`D_h` 换成上式。注意 `D_h` **不是**反对称的
（无 SBP）：它只满足单侧耗散恒等式（§3、§6 定理 `dg_upwind_dissipation_identity`）。

### 1.3 P1 DG-upwind（S2′，对照）

每单元 2 自由度 `(a_j, b_j)`，单元质量 `M_e = (h/6)[[2,1],[1,2]]`（块对角），
弱形式同上、迎风通量取左迹；Bloch 因子 `z = e^{iθ}` 下 `2×2` 符号本征值：

```
物理支:     μ_h = iθ/h + θ⁴/(72h) + O(θ⁵)      （即 O(h³) 相容，超收敛）
寄生支:     μ_h = 6/h - 3iθ/h - θ²/h + ...
Nyquist:    μ_h(π/h) = (1 ± i√11)/h  ≠ 0
```

（数值见 `experiments` 输出 B1；符号推导见 `VERIFY.md`。寄生支的实部 `-θ²/h < 0` 被强阻尼，
是 DG 已知的寄生模。）

### 1.4 三个变体与半离散符号 `μ_h(ℓ)`

在 `y` 方向取 Fourier 模态 `U_j = e^{iℓ y_j}`，`θ = ℓh`。`μ_h(ℓ)` 定义为 `D_h` 在该模态上的
本征值（即 (S1c) 中 `W = μ_h U`）：

| 变体 | `M_h` 符号 | `D_h` 符号 `μ_h(ℓ)` | 精度 | `Re μ_h` | `μ_h(π/h)` |
|---|---|---|---|---|---|
| (S1) P1 一致质量 | `(h/3)(2+cosθ)` | `i·3 sinθ /(h(2+cosθ))` | `O(h⁴)` | `= 0` | `0` ← **Nyquist 零** |
| (S1-L) P1 集中质量 = 中心差分 | `h` | `i sinθ/h` | `O(h²)` | `= 0` | `0` ← **Nyquist 零** |
| (S2) P0 DG 迎风 | `h` | `(1-e^{-iθ})/h` | `O(h)` | `(1-cosθ)/h ≥ 0` | `2/h ≠ 0` |
| (S2′) P1 DG 迎风 | 块 `(h/6)[[2,1],[1,2]]` | 见 §1.3 | `O(h³)` | 小（`θ⁴/(72h)`） | `(1±i√13` 前系 `)≠0` |

**(S1) 的显式推导（自行推导，未采信提示中的公式）**：由 `(Mv)_j/v_j = (h/6)(e^{-iθ}+4+e^{iθ}) = (h/3)(2+cosθ)`、
`(Aᵀv)_j/v_j = (1/2)(e^{iθ}-e^{-iθ}) = i sinθ`，得 `μ_h = (i sinθ)/((h/3)(2+cosθ))`，与提示一致；
其归一化因子为

```
R(θ) := 3 sinθ /(θ(2+cosθ)) ,     μ_h(ℓ) = i ℓ · R(ℓh)
```

## 2. 连续极限与相容阶

### 2.1 `μ_h(ℓ) → iℓ` 及其阶

```
R(θ) = 3 (sinθ/θ) · 1/(2+cosθ)  ⟶  3 · 1 · 1/3 = 1        (θ → 0)
R(θ) = 1 - θ⁴/180 - θ⁶/1512 - θ⁸/25920 + O(θ¹⁰)
μ_h(ℓ) - iℓ = -i ℓ⁵ h⁴/180 + O(h⁶)
```

即 **(S1) 的符号在固定 `ℓ` 下是 4 阶相容**（节点导数超收敛）；数值验证：`ℓ=1.7`，
`h = 0.4,0.2,0.1,0.05` 时误差 `2.133e-3 → 1.280e-4 → 7.915e-6 → 4.934e-7`，
误差比 `16.67 / 16.17 / 16.04 → 16`（4 阶）✔。
对照：`(S1-L)` 为 2 阶；`(S2)` `μ_h - iℓ = hℓ²/2 + O(h²)`，**1 阶**（误差比 → 2 ✔）；
`(S2′)` 为 3 阶。

**Lean 已证（代数层）**：`p1_symbol_normalisation`（`R(θ)·θ(2+cosθ) = 3 sinθ`，`θ ≠ 0`），
`p1_symbol_deviation`（`R-1` 的精确商式，分子 `= -θ⁵/60 + O(θ⁷)`）。
`lim R = 1` 这一**极限陈述本身未形式化**（见 §7 缺口 G1）。注意 Lean 中 `R1 0 = 0`
（`0/0 = 0` 的除零约定），所以 `R(0)=1` 的唯一正确含义是极限。

### 2.2 连续极限是否给出论文的 (6)–(7)

**是（在符号/相容意义下）**。因为 `x,t` 未离散，半离散系统对 `h` 的形式极限逐项就是
(1')–(2')，而 (1')–(2') 与 (1)–(2) 是逐系数恒等的精确改写（spec V5）；再经 VT
`u = 2(ln f/g)_x`、`v = 2(ln fg)_{xy}` 即得论文 (6)–(7)（`λ=-2`；spec V4 已验证
`a=2, λ=-2, N=1,2,3` 的 tau 对确实解 (6)–(7) 且诱导 `(u,v)` 解 (1)–(2)）。
`h→0` 时 `μ_h → iℓ` 保证 (S1a)–(S1c) 的符号逐点收敛到连续符号。

**必须同时说清的否面**：
* 这**不是**收敛定理。由于 §5 的 standing obstruction（`|Re σ| ~ k²`），
  对一般初值既无一致适定，也无网格一致稳定性，更无收敛定理可言；上面的"极限"只是
  逐模态符号意义下的相容性。
* **离散层面没有双线性结构**。Galerkin 投影把乘积换成三乘积张量 `T` 与 `M^{-1}` 的复合，
  Hirota 的 `D` 算子恒等式不是投影的不变量。因此 FE/DG 方案**不存在**类同 spec §3 交错
  two-tau 方案那样的"离散 tau 函数精确解族"；双线性只存在于连续极限。

### 2.3 对提示中离散色散关系的一处更正（重要）

提示给出 `(σ + i(u₀+2a)k)² = k⁴ − (v₀+2λ)k³/μ_h(ℓ)`。由 `iℓ → μ_h` 的替换规则自行推导
（`u₀ u_xy → ik μ_h u₀` 等），正确形式带一个因子 `i`：

```
(σ + i(u₀+2a)k)² = k⁴ − i (v₀+2λ) k³ / μ_h(ℓ)
```

一致性自检：代入 `μ_h = iℓ` 立即还原 spec §2 [MAIN-VERIFIED — V6] 的
`(σ+i(u₀+2a)k)² = k⁴ − (v₀+2λ)k³/ℓ` ✔。该修正不是记号问题：它决定 Nyquist 退化模的
符号与结构（§5）。数值验证见 §5：组装矩阵 → 逐模 `2×2` 铅笔的本征值与上式在
`k = 0.7, 1.3, 2.5` 上分别吻合到 `1.490e-15 / 1.110e-15 / 3.972e-15` ✔。

## 3. 变量变换（VT）可行性

VT 需要 `u = 2(ln(f/g))_x`。因为只离散 `y`，`ln` 逐点作用。设节点值 `F_j = f(x,y_j,t) > 0`、
`G_j = g(x,y_j,t) > 0`，插值 `f_h = Σ F_j φ_j`，`g_h = Σ G_j φ_j`。

1. **`ln ∘ 插值 ∉ V_h`（核心障碍）**。`ln(f_h/g_h)` 是分段线性函数的对数，**不是**分段线性
   函数。Galerkin 方程要求的是 `u_h = P_h(2∂_x ln(f_h/g_h))`（L² 投影），其节点值为
   `M U = b`，`b_i = ∫ 2∂_x ln(f_h/g_h) φ_i dy`，**一般不等于** `2∂_x ln(F_i/G_i)`。
   二者之差恰由质量矩阵耦合（邻近节点）产生；把 `U_j := 2∂_x ln(F_j/G_j)`（节点对数导数）
   代入格式 (S1)，与真正的 Galerkin 解在 `O(h²)` 意义下不同，且由于 `b` 含 `∫ln(线性函数)`
   而无闭式表达。**结论：VT 在离散层面不精确成立，只在 `h→0` 极限成立。**
2. **正性是 P1 的唯一真优势**。P1 插值保持正性（两个正节点值的线性插值在单元上为正），
   故 `f_h/g_h > 0` 逐点成立、`ln` 良定义（离散极值原理）。若用高阶元或谱方法，插值可能变号，
   `ln` 直接失效。这一点 P1 FEM 严格优于高阶/谱 `y` 离散。
3. **约束 `w = u_y` 与 VT 的冲突**。(S1) 中 `Aᵀ` 在 Nyquist（`sinθ = 0`）退化（§5），
   故 `M W = Aᵀ U` 中交错分量 `U` 不受约束：由 VT 逐点生成的 `u_h` 一般不满足离散约束。
   (S2)/(S2′) 的 `D_h` 可逆，约束精确可解，但 `D_h` 单侧、非反对称、只有 `O(h)`（或 `O(h³)`）
   相容——于是 `u = 2(ln f/g)_x` 与 `w = u_y` **不能同时在离散层成立**（迎风导数是单向偏置的）。
4. **双线性结构被破坏**（同 §2.2）：Galerkin 投影下的非线性是有理/多项式项配 `M^{-1}` 与 `T`，
   不存在离散的 `D_y B + 2λ D_x` 恒等式。

**VT 结论**：本方向只在**连续极限层面**与 VT 相容；离散层面不可行，原因按重要性排序为
(1) `ln∘插值 ∉ V_h` 导致质量矩阵耦合、(2) P1 的 `Aᵀ` Nyquist 退化使约束不可解、
(3) 双线性恒等式不是 Galerkin 投影的不变量。唯一正面结论：P1 保正性使逐点 `ln` 有意义。

## 4. 局部性与闭合性（FEM 特有的关键发现）

* **单元层是局部的**：`M`、`A`、`K` 三对角，`T` 单元内带状 → 非线性项本身不引入非局部性。
* **算子层是非局部的**：格式 (S1a)–(S1c) 必须对 `M` 求逆才能得到节点时间导数，而均匀周期网格上
  `M^{-1}` 有**精确闭式**

```
(M_h^{-1})_{jk} = (√3/h) Σ_{w∈ℤ} r^{|j-k+wN|} ,      r = √3 - 2 = -0.267949...
```

  数值验证：与 `np.linalg.inv(M)` 的最大偏差 `5.551e-16`（`N=12, h=2π/12`）；
  衰减比实测 `0.2679497` / `0.2680412`，与 `|r| = 0.267949` 一致 ✔。
  即 `M^{-1}` 是**稠密**矩阵：每个节点与所有节点耦合。这是 FEM 相对差分/DG 的**独有代价**。
* **两种定量闭合方式（条件性）**：
  (a) *精确指数衰减截断*：`|(M^{-1})_{jk}| ≲ (√3/h)·0.268^{|j-k|}`，故截断 `|j-k| > m`
      的相对误差约 `0.268^{m+1}`（`m ≈ 27` 即达 `1e-16`）。
  (b) *算子级 Neumann 级数*：由符号恒等式 `(h/3)(2+cosθ) = h(1 + (h²/6)λ_Δ)` 得
      `M = h(I + (h²/6)Δ)`（`Δ` 为三点 Laplacian），于是
      `M^{-1} = (1/h) Σ_{m≥0} (-1)^m (h²Δ/6)^m`；截断到 `M` 项给出 **(2M+1)-带状局部算子**，
      算子范数误差 `≤ (3/h)(2/3)^M`，局部截断缺陷 `O(h^{2M+2})`。
      这是一个**有名字、有假设的闭合**：`h` 固定、（半）带截断、误差有界。
* **对照**：(S1-L) 集中质量（行和）使 `M = hI` 严格局部，但 `D_h` 退化为中心差分
  （Nyquist 零、`O(h²)`）；(S2) P0 DG 的 `M = hI` 严格对角，**`y` 方向完全局部**
  （只有最近邻耦合）。于是取舍是清晰的：**DG 用 `O(h)` 精度换局部性；一致质量 FEM 用非局部
  `M^{-1}` 换 `O(h⁴)` 符号精度**（`M^{-1}` 的稠密性在计算上仍可用三对角求解在 `O(N)` 内完成，
  但**代数闭合**仍是非局部的：任何能量/熵恒等式都含完整 `M^{-1}`）。

## 5. 初边值、零模、稳定性

### 5.1 standing 精确零模（`v ≡ -2λ = 4`, `u = U(x,t)` 任意, `u_y = 0`）

两个方案都精确保持该族：`1 ∈ V_h`，`D_h` 与 P1 刚度矩阵都精确湮灭常数
（Lean: `p1_stiffness_kills_constant`、`p1_stiffness_symbol_at_zero`；DG 迎风对常数给 `(c-c)/h = 0`）。
代入 (S1a)–(S1c)：`w_h ≡ 0`，`v_h ≡ 4` ⇒ `∂_x[(U+2a)·4 - 4U] = ∂_x[8a] = 0` ✔。
**处理约定**：约束 `M W = Aᵀ U` 只在常数模的正交补上求逆；常数模由均值/零模约定固定，
或干脆保留 `U, W` 为独立未知量、从不除以 `D_h`。

### 5.2 虚假核（否面结论，FEM 特有）

`μ_h(π/h) = 0` 对 **(S1) 一致质量 P1** 与 **(S1-L) 中心差分**都成立
（Lean: `muP1_nyquist_zero`、`ctr_symbol_nyquist_zero`；SymPy A6 给出恰为 `0`）。
关键判断：**这不是质量矩阵造成的**——质量符号 `2+cosθ ∈ [1,3]` 处处非零
（Lean: `mass_symbol_bounds`、`mass_symbol_ne_zero`、`mass_symbol_at_nyquist`），
零来自刚度/迁移符号 `sinθ`，与中心差分同源。因此：

* `D_h = M^{-1}Aᵀ` 有一个**虚假核**，由交错（sawtooth）向量 `(-1)^j` 张成；连续情形
  `iℓ ≠ 0 (ℓ≠0)` 无此现象。半离散系统因此退化为 **DAE**（`MD = Aᵀ` 奇异），
  交错分量在演化方程中不出现，可自由漂移。
* 退化模上的离散色散不是"`1/μ_h = ∞`"，而是约束整体掉出后的**另一个**二次方程
  `σ² + iAkσ + i(v₀+2λ)k³ = 0`，给出与连续色散无关的**虚假 `O(1)` 增长模**：
  取 `u₀=0.4, a=0.7, λ=-2, v₀=1.1, k=1.3`（`A=1.8`）得
  `σ = -1.6043 - 3.1556i` 与 `+1.6043 + 0.8156i`，即 `Re σ = ±1.6043`：**Nyquist 模上有
  虚假的线性不稳定**（与 `k²` 增长无关，也不是真解）。这是本方向最主要的否面发现。
* **(S2) P0 DG 迎风没有 Nyquist 零**（Lean: `dg_symbol_no_nyquist_zero`、
  `dg_symbol_re_at_nyquist`；SymPy A10 `μ_h(π/h) = 2/h`），故无虚假核、约束精确可解；
  代价是 `O(h)` 相容性与非反对称性。**(S2′) P1 DG 迎风同样无 Nyquist 零**
  （`(1±i√11)/h`），且符号精度 `O(h³)`，但有寄生支 `≈ 6/h`。
* 若必须用一致质量 FEM，规避 Nyquist 退化的唯一干净办法是**加谱/带限制**或**质量集中**。

### 5.3 稳定性：只能条件成立，且 standing obstruction 不受影响

standing obstruction（spec §2 [MAIN-VERIFIED — V6]）的 `k⁴` 项来自 `x` 结构
（`u_yt ⇄ v_xx` 的耦合），其中**没有** `y` 导数，因此**任何** `y` 离散都不能改变它：
对实 `k`、`k→∞`，`(σ+i(u₀+2a)k)² ≈ k⁴` ⇒ `|Re σ| ~ k²`。
本方案的隐式性/质量矩阵/DG 耗散/零模精确保留/离散守恒**都不能**消除它。
诚实的稳定性陈述只有下列条件形式：

* **(C1) 固定截断 + 有限频带**：固定 `h`、`|k| ≤ K`，且只在非退化 `y` 模（`θ ∉ {0,π}`）上考虑，
  则 `σ` 有限且可计算，增长率 `sup Re σ ≳ K²` 仍随 `K` 增长——**没有任何关于 `K` 一致的界**。
* **(C2) 具名精确解族**：`v ≡ 4`、`u = U(x,t)`、`u_y = 0`（§5.1）被精确保持。
* **(C3) 具名背景 + 全模精确色散**：在 `v₀ = -2λ = 4`（即 `v₀+2λ = 0`）时 `k³/μ_h` 项整体消失，
  离散色散对**每个 `y` 模、每个 `h`** 都等于连续色散（含 Nyquist 模），退化模方程退化为
  `σ² + iAkσ = 0`，根为 `σ = 0`（即零模）与 `σ = -iAk`——数值 C7 给出 `-2.34i` 与 `0` ✔，
  与 spec V6/V7 一致。这是唯一一个"离散与连续完全一致"的干净条件性结论。
* **(C4) DG 迎风耗散**：`y` 迁移算子单侧耗散（Lean: `dg_upwind_dissipation_nonneg`，
  SymPy A8 `Re μ_h = (1-cosθ)/h ≥ 0`），但 `Re μ_h > 0` 只把 `k³/μ_h` 项平移 `O(h)`
  （A11: `μ_h - iℓ = hℓ²/2 + O(h²)`），**对 `k⁴` 项毫无作用**。故它**不**给出整体稳定性。
* **(C5) 一致质量 P1 的虚假增长**：§5.2 的 Nyquist 模 `O(1)` 增长是方案自带的，
  与 obstruction 无关，属于**必须修掉的设计缺陷**。

## 7. 明确未证的缺口

* **G1（分析桥接）**：`lim_{θ→0} R(θ) = 1` 与 `R = 1 - θ⁴/180 + O(θ⁶)` 的**余项估计**未形式化。
  Lean 只有代数恒等式 `p1_symbol_normalisation` / `p1_symbol_deviation`；阶数是 SymPy 精确
  Taylor 级数（实验验证）。因此"4 阶相容"目前是 `实验验证`，不是 `Lean 分析验证`。
* **G2（`M^{-1}` 闭式）**：`(M_h^{-1})_{jk} = (√3/h)Σ_w r^{|j-k+wN|}` 只有数值验证
  （偏差 `5.6e-16`）与符号恒等式推导，**未形式化**；由此得到的"指数衰减截断"结论
  （§4(a)）是 `实验验证`。
* **G3（Neumann 级数闭合）**：`M = h(I+(h²/6)Δ)` 与截断误差 `(3/h)(2/3)^M` 是形式推导 +
  符号验证，**未形式化**。
* **G4（离散色散关系的确认）**：`(σ+iAk)² = k⁴ - i(v₀+2λ)k³/μ_h` 通过"组装矩阵 → 逐模符号
  （C3）→ 逐模 `2×2` 铅笔（C5, 误差 `~1e-15`）"链条确认，属**逐模精确数值验证**；
  完整汇编 `2N×2N` 铅笔在退化模上奇异（`P = [[MD,0],[0,M]]` 奇异），我**没有**做全矩阵
  广义本征值计算，也没有形式化。
* **G5（收敛/稳定性定理）**：**不存在也不可能有**对一般初值的无条件结论（§5.3）。
  进一步，即使条件性结论（C1）也只是"符号有限、可计算"，**没有**证明任何收敛率或
  Lax–Richtmyer 型稳定性；本方向不声称任何收敛阶。
* **G6（VT 的离散化）**：`ln∘插值 ∉ V_h` 的量化误差、投影误差的 `O(h²)` 估计、

* **G7（P1 DG 迎风符号）**：§1.3 的分支来自 Bloch `2×2` 铅笔的 SymPy 解；物理支/寄生支的
