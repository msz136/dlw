37方块：Cantrell构造与条件下界的Lean验证

全局最优性尚未证明。原始目录将37块问题标为 open，报告区间为 6.44 ≤ s(37) ≤ 6.59861960924437。本项目严格核验已知构造，并从其接触链建立可形式化的必要下界；尚未排除全部其他布局。

已核验的构造

在边长

Lrat = 659861960924437 / 1014

的正方形内存在37个实数单位正方形。每块可独立平移和旋转；闭方块两两不相交。

Lean 逐项证明37项单位性、148条容器约束和666对严格分离。另以 Python 有理数重算666对多边形交集，全部为空。

这是 Cantrell 已知构造的认证，不是新纪录。源证书还给出更紧的有理边长 6.598619609244360116244356658771；本次 Lean 采用目录公开上取整值。

由接触链得到的两条必要下界

设两组倾角为 ±θ，c = cos θ、s = sin θ，0 ≤ s ≤ c，中央块为精确45°。在明确列出的有向分离与外围轴向链条件下，得到

(c+s)L ≥ 3+4c+5s,
2(1+s(c−s))L ≥ 6+8c+10s(c−s)+√2.

第一条来自13条支撑与墙条件的加权求和；第二条来自左右两条支撑链及中央对角线间距。两者已在 CantrellSupports.lean 中证明，全部假设显式保留。右半部通过坐标反射表达所需条件，并不假定整个布局镜面对称。

记两个商分别为 F₁(θ)、F₂(θ)。令 q = tan(θ/2)，其交点满足

(4−√2)q4 + (12−2√2)q2 − √2 = 0.

交点约为 θ = 42.0866074742°。有理区间计算严格隔离该交点；正系数 Bernstein 恒等式证明相关区间内 F₂ 下降，F₁ 在交点右侧上升。因此，在 q ∈ [0,√2−1]，即 θ ∈ [0,π/4] 的支持模型内，交点是两支撑函数最大值的全局最小点。形式化状态：已通过 Lean。

最终整合定理 conditional_branch_lower_bound 证明：对任意满足 0 ≤ s ≤ c、c²+s²=1 的共同方向，以及满足上述明确支撑条件的坐标数组，必有 L ≥ L*。证明覆盖整个允许方向区间，未把方向固定为数值优化所得角度。

当前精确有理37块见证略高于理想代数端点，其中央角也只是极接近45°。因此，支撑模型的最小值与完整37块在端点处的可行性仍须区分。

精确代数端点

两条支撑等式消元得到 Q(L,√2)=0，其中

Q(L,r)=6L⁴−(208+64r)L³+(2058+850r)L²
−(7936+3658r)L+11163+5502r.

其共轭乘积是目录给出的八次多项式：

P(L)=36L⁸−2496L⁷+59768L⁶−733760L⁵+5289248L⁴
−23462672L³+63458276L²−96673872L+64068561.

Lean 证明 P 在下列区间内有唯一根 L*，排除了共轭因子，并证明 Q(L*,√2)=0：

6.59861960924436 < L* < 6.59861960924437.

在该区间内，只要共同方向满足单位性及两条支撑取等，其 L 就等于 L*。独立有理区间程序进一步定位到 6.5986196092443601161783704626783488043909 与末位增加1之间；这段更细夹逼属于精确程序记录，不冒称已在 Lean 中逐位重放。

从17块证明可复用什么

17块页面包含两条不同证据：T-153 是仍带义务的候选证明；T-154 的 sq17-lean 声称完整证明，并明确使用13,343项 native_decide 事实。本项目审核了可获得源码的覆盖、重编号与最终装配接口；未下载约1.963 GB的全部生成证书，也未独立重建其完整证明。

已为任意块数重写并核验六个有限覆盖引理：完整性需要“每行有效、无重复、计数正确”共同成立；容量为一给出单射分配；占用集相等给出真实重编号置换。37块尚未实例化这些条件。

全局证明尚缺的核心

ResearchTarget.lean 将目标明确写为所有实数 L 上的等价式：存在37块合法布局，当且仅当 L* ≤ L。该命题只被定义，没有被当作已证定理或公理使用。

一个具体的下一步是先核验容量覆盖：以 U = 6.59861960924437 为搜索上界，将中心所在的 [1/2,U−1/2]² 分为8×8格，格宽 w = (U−1)/8 满足 2w² < 1。每块含半径1/2的内圆，因此每格至多一个中心。但占用集数 C(64,37) = 846636978475316672，即使按正方形的8个对称约去，仍至少有105829622309414584个轨道。这一基线的几何解释尚未接入 Lean；它表明需要更强容量单元与自适应区间剪枝，而非直接列出全部组合。

全局搜索还必须为每块保留独立方向，包括正、负倾角。当前支撑模型的共同倾角和第一八分区参数化，不能充当任意37块布局的方向覆盖。

  1. 为任意小于 L* 的布局建立几何容量覆盖与完整占用分类；若用对称性缩减，需证明恢复全部原布局。
  2. 生成并形式核验各类排除证书，将剩余布局完整归约到端点附近的可分析分支。
  3. 把局部支撑结论接到该全局归约，并给出 L* 处完整37块的精确可行构造。

因此，本轮所得是构造认证、代数识别与条件下界的证明基础。全局37块最优性的关键内容仍是对所有其他布局的完备排除。
