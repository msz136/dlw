########## soliton_analysis.py ##########
============================================================================================
1.  lattice phase / dispersion
============================================================================================
   Lam_h(z) = (1/h) ln[(z+h/2)/(z-h/2)]
      h^0: 1/z
      h^2: 1/(12*z**3)
      h^4: 1/(80*z**5)
   =>  Lam_h(z) = 1/z + h^2/(12 z^3) + h^4/(80 z^5) + O(h^6)
   lattice soliton phase:  theta_i(j) = (p_i+q_i) x + (q_i^2-p_i^2) t + j*ln(lam_i) + const
   with   ln(lam_i)/h = Lam_h(P_i) + Lam_h(Q_i) ,   lam_i = ((P_i+d)/(P_i-d))((Q_i+d)/(Q_i-d))

============================================================================================
2.  one-soliton on the lattice  (N = 1)
============================================================================================
   G_j = 1 + E_j ,   F_j = 1 + r E_j
   r = (2*a - h - 2*p)/(2*a - h + 2*q)
   lam = -(-2*a + h + 2*p)*(2*a + h + 2*q)/((2*a - h + 2*q)*(2*a + h - 2*p))
   E_j = (1/(p+q)) exp[ (p+q)x + (q^2-p^2)t + j ln(lam) ]
   u_j = 2 d_x ln(F_j/G_j) = 4*E*(p + q)**2/((E + 1)*(-2*E*a + E*h + 2*E*p - 2*a + h - 2*q))
   continuum (h=0): u = 2*E0*(p + q)**2/((E0 + 1)*(-E0*a + E0*p - a - q))
   u_j = 2 d_x ln(F_j/G_j) = -2 E (p+q)^2 / [ (1+E) ( (Q-d) - (P+d) E ) ]
   d u_j / d E_j = 0  at  E = [-sqrt(-(2*a - h + 2*q)/(-2*a + h + 2*p)), sqrt((-2*a + h - 2*q)/(-2*a + h + 2*p))]
   h=0: no positive critical point
   h=1/4: no positive critical point
   h=1/2: no positive critical point
   h=1: no positive critical point

============================================================================================
3.  two-soliton:  the interaction coefficient Gamma is h-independent
============================================================================================
   G_j = 1 + E_1 + E_2 + Gamma E_1 E_2  with
   Gamma = (coeff of E_1E_2)/(coeff of E_1)/(coeff of E_2)  = -23/415
   Cauchy-determinant value  ((p1-p2)(q1-q2))/((p1+q2)(p2+q1)) = (p1 - p2)*(q1 - q2)/((p1 + q2)*(p2 + q1))
   (numerically)  engine: -0.0554216867469879    closed form: (p1 - p2)*(q1 - q2)/((p1 + q2)*(p2 + q1))
   => Gamma carries NO h and NO j: the two-soliton phase shift is untouched by the lattice.

============================================================================================
4.  continuum limit of the lattice phase
============================================================================================
   theta_i(j) - theta_i^{cont}(y=jh) = j [ ln(lam_i)/h - (1/P_i + 1/Q_i) ] h
   with ln(lam_i)/h - (1/P_i+1/Q_i) = h^2/12 (1/P_i^3 + 1/Q_i^3) + O(h^4)
   => an O(h^2) phase error, i.e. the scheme is second-order accurate for the soliton phase.

============================================================================================
5.  continuum-limit check of the O(h^2) constants in section F
============================================================================================
   (E_+ + E_-)/2 = M_0 + (h^2/8) [B_a f.g_YY + 4 D_x f.g_Y] + O(h^4)
   (E_+ - E_-)/h = M_1 + (h^2/24) [B_a f.g_YYY + 6 D_x f.g_YY] + O(h^4)
