## D-1 离散乘积法则（对称形式）

1. **数学陈述**
   设 `D f j = (f(j+1) − f j)/h`，`avg f j = (f j + f(j+1))/2`，则对任意数列 `x,y`、任意 `h ≠ 0`：
   $$ D(xy)_j = (\mathrm{avg}\,x)_j\,(Dy)_j + (\mathrm{avg}\,y)_j\,(Dx)_j . $$
   无修正项。此为前向差分的 Leibniz 法则。
2. **对象与适用范围**：`x, y : ℤ → ℚ`；系数域 `ℚ`（特征 ≠ 2 的任意域同样成立）。
3. **假设与边界条件**：`h ≠ 0`；无边界条件要求（点态恒等式）。
4. **Lean 定理名称**：`DLW.DirD.d_avg_mul`

7. **构建结果**：exit code 0；`PASSED: 2 local module(s).`

## D-2 非线性项的 SBP 边界恒等式

1. **数学陈述**
   $$ \sum_{j=0}^{N-1} (u_j + u_{j+1})(u_{j+1} - u_j) = u_N^2 - u_0^2 . $$
   即 `sum_j (avg u_j)(D u_j) · 2h = u_N² − u_0²`。
   右端是**纯边界项**，故在周期条件 `u_0 = u_N` 下非线性项净通量为 **0**。
2. **对象与适用范围**：`u : ℕ → ℚ`，`N : ℕ`（区间 `j = 0..N−1`）。
3. **假设与边界条件**：**保留**边界项 `u_N² − u_0²`；不假设周期。周期化时该边界项为零。
4. **Lean 定理名称**：`DLW.DirD.avg_sbp`（未除形式）、`DLW.DirD.avg_sbp_divided`（除形式，含因子 `2h`）
5. **文件位置**：`proofs/DirD.lean`
6. **验证命令**：同上
7. **构建结果**：exit code 0；`PASSED: 2 local module(s).`
8. **未形式化的桥接步骤**：把该恒等式组装成 `∫_x` 之上的连续守恒律需要 `x`-积分与 `j`-求和的交换（在周期 `x`-域上平凡），未在 Lean 中形式化。

## D-3 前向差分算子的 SBP / 反对称性

1. **数学陈述**
   $$ \sum_{j<N} (x_{j+1}-x_j)y_j + \sum_{j<N} x_{j+1}(y_{j+1}-y_j) = x_N y_N - x_0 y_0 , $$
   在周期条件 `x_N = x_0`、`y_N = y_0` 下右端为 0：`D` 与序列配对反对称，即
   `Σ (D f) g = − Σ f₊ (D g)` 的离散模拟。除形式对应乘以 `h`。

## D-4 离散守恒律 / 精确边界平衡

1. **数学陈述**
   若格点通量满足 `F_{j+1} − F_j = −(h · s_j)`（`j < N`），则
   $$ \Bigl(\sum_{j<N} s_j\Bigr) h = F_0 - F_N . $$
   取 `w_j := D u_j`（离散约束）且 `s_j := (D_t w)_j`，即得守恒量 `Σ_j w_j` 的变化率恰为边界通量
   `(F_0 − F_N)/h`：**当且仅当边界通量消失时守恒**。
2. **对象与适用范围**：`F, s : ℕ → ℚ`，`h : ℚ`，`N : ℕ`。
3. **假设与边界条件**：通量形式假设 `hflow`；边界项 `F_0 − F_N` **显式保留，从不丢弃**。
4. **Lean 定理名称**：`DLW.DirD.constraint_sbp_balance`

## D-5 守恒量无正定性（守恒 ≠ 稳定）

1. **数学陈述**
   常数列属于 `D` 的核：`(∀j, w_j = c) ⟹ ∀j, D w_j = 0`。故把 `u` 平移任意常数 `c` 会任意改变 `L²` 范数，却不改变每个格点导数 `D u_j`，因而也不改变 (E1) 所守恒的泛函 `Σ_j D u_j`。
   **结论：该守恒泛函不能控制 `Σ_j u_j²`，守恒不蕴含稳定。**
2. **对象与适用范围**：`w : ℤ → ℚ`，`h : ℚ`，`c : ℚ`；另有 `u`-版本 `conserved_density_trivial_on_constants`。

## D-6 位移交换性（约束 `w = D u` 的精确保持）

1. **数学陈述**
   $$ D x_h(j+1) = \frac{x(j+2)-x(j+1)}{h},\qquad \mathrm{avg}\,x(j+1) = \frac{x(j+1)+x(j+2)}{2} . $$
   因 `D`、`avg` 只作用于格点指标 `j`，而 `x`、`t` 连续，故 `D` 与任何 `x`-运算交换；这正是

## D-7 守恒性可由"通量形式"得到——朴素乘积会破坏它

1. **数学陈述（被否证的候选）**
   朴素的离散化把非线性项写成 `u_j · (D u)_j`（或 `avg(u)_j·(D u)_j` 之外的任意单边形式），并声称它保持同样的守恒律。
   **该候选为假。** 数值反例（`experiments/e1_exact_identities.py`，精确有理数运算）：
   取 `u = (1, 3)`、`h = 1`，则
   `Σ_j (u_j + u_{j+1})(u_{j+1} − u_j) = (1+3)(3−1) = 8 = u₁² − u₀² = 9 − 1`（对称形式**成立**），
   而单边形式 `Σ_j 2u_j(u_{j+1} − u_j) = 2·1·2 = 4 ≠ 8`（**不成立**）。
   只有**平均形式** `avg(u)·D u` 才给出精确的边界项。
2. **对象与适用范围**：格点非线性项 `u u_y` 的离散化。
3. **假设与边界条件**：周期 `y`-条件（此时边界项应为 0）；反例中边界项非零因而更清楚地暴露差异。
4. **Lean 定理名称**：无独立定理；对称形式（成立的）为 `DLW.DirD.avg_sbp`。**另有一条我最初写成 `d_mul_left` 的单边乘积法则被 Lean/数值双重判定为假并已删除，见 `report.md` §7 的诚实记录。**
5. **文件位置**：`proofs/DirD.lean`（删除记录）、`experiments/e1_exact_identities.py`（反例）
6. **验证命令**：`python -u experiments/e1_exact_identities.py`；Lean 命令同上

## D-8 连续极限与线性化病态性（本路线不能修复）

1. **数学陈述**
   (a) 候选离散格式的符号：`μ = (e^{iαh} − 1)/h`，`ν = (1 + e^{iαh})/2 = e^{iαh/2}cos(αh/2)`；`h → 0` 时 `μ → iα`、`ν → 1`，格式相容。
   (b) 常背景线性化给出 `[σ + i(u₀+2a)k]² = k⁴ − (v₀+2λ)k³/Λ_h(ℓ)`，其中 `k⁴` 的系数对**每一个**相容符号都恰为 1（已核验六种符号：中心、前向、后向、交错、P1 一致质量有限元、谱）。
   (c) 因此 `|Re σ| ~ k²`：**Hadamard 病态**。离散守恒、SBP、隐式性与耗散**都不能**去除它——它们是离散化的性质，而该阻断是连续 `x`-符号的性质。
   (d) 机制：`k²` 增长率由 `(1)` 中的 `∂_x² v` 承载，而 `∂_x² v` 不含 `y`-导数，故任何 `y`-离散化都无法改变它。格点最大可分辨模 `α = 2/h` 处的增长率反而随 `h → 0` 发散（`h·Re σ → |sin 2|/2 ≈ 0.4546`，即 `Re σ ~ O(1/h)`），**加密使病态更严重**。
2. **对象与适用范围**：DLW 系统在常背景 `(u₀, v₀)` 附近的线性化。
3. **假设与边界条件**：周期 `x`-域；`y` 方向 SBP 边界；线性化背景为常数。
4. **Lean 定理名称**：无。**未形式化。**
5. **文件位置**：`experiments/e2_linear_symbol.py`
6. **验证命令**：`python -u experiments/e2_linear_symbol.py`
7. **构建结果**：exit code 0
8. **未形式化的桥接步骤**：全部。SymPy 精确符号计算给出 `(a)`–(d)；Lean 中未涉及。
9. **外部依赖**：Physica D 432 (2022) 133140，DOI `10.1016/j.physd.2021.133140`
10. **证据等级**：`实验验证`

## D-9 中心差分 / P1 一致质量有限元在 Nyquist 处的伪核（与方向 C 的接口）

1. **数学陈述**：中心差分符号与 P1 一致质量有限元符号在 Nyquist 点 `ℓh = π` 处均**为零**（方向 C 已 Lean 验证）。因此若把 `D` 换成中心差分型 SBP 算子，会多出一个**伪核**：`ℓh = π` 的格点模被算子零化，而它在连续意义下并非零模。
2. **处理方式**：本方向**不**使用中心差分作为 `D`。`D` 取单侧前向差分，其符号 `μ = (e^{iαh}−1)/h` 只有在 `αh ≡ 0 (mod 2π)` 时为零，即仅零模；Nyquist 处 `|μ| = |e^{iπ}−1|/h = 2/h ≠ 0`，**无伪核**。这是选择前向差分 + 平均通量（而非中心差分）的一个具体好处。
3. **对象与适用范围**：格点微分算子的核结构。
4. **假设与边界条件**：周期格点。
5. **Lean 定理名称**：`DLW.DirD.constraint_kernel`（只覆盖零模/常数核；Nyquist 无伪核的断言由符号计算给出）
6. **文件位置**：`proofs/DirD.lean`、`experiments/e1_exact_identities.py`
7. **验证命令**：同上
8. **未形式化的桥接步骤**：`μ` 在 Nyquist 处非零的符号计算未形式化。
9. **外部依赖**：方向 C 的 Lean 结果（`ctr_altOf` 等，见其 `CONCLUSIONS.md`）

## 诚实记录：被删除的假命题

推导过程中我曾写下两条**假**命题并在 Lean 中失败，最终删除（未使用 `sorry`/`admit`）：

* `d_mul_left`（初版陈述 `D(xy)_j = (Dx)_j(y_j + avg y_j) + x_j (Dy)_j`）——数值反例：`x_j=1, x_{j+1}=3, y_j=2, y_{j+1}=5, h=1` 时左端 `19`、右端 `10`。
* `flux_gauge_identity`（初版陈述 `D(xy)_j = x_j (Dy)_j + (avg x_j)(Dy)_j + (Dx)_j(avg y_j)`）——同一反例下右端含多余项 `x_j (Dy)_j`。

**正确的**单边形式是 `D(xy)_j = x_{j+1}(Dy)_j + avg(y)_j (Dx)_j`（该反例下两端同为 `19`），但把它作为独立 Lean 定理需要额外的 `avg` 展开技巧，在预算内未完成，故**不纳入**已证清单。这不影响任何守恒结论：D-1 的对称形式已足以支撑全部通量论证。
