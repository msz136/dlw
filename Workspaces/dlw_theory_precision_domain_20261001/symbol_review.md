# T04：实际 x 符号、时间误差与带宽联合极限的独立复核

2026-10-01。这里只处理一个固定模型：x 为长度 L 的周期域，y 为允许模态 exp(iηy) 的周期域，η≠0 固定，a∈R 与 T>0 固定，背景为零。y 不离散。频率 ξ=2πm/L。比较同一初始物理振幅的连续传播、实际四阶中心 x 差分传播及 Euler / 经典 RK4 传播。不外推到当前 y 开链鬼点闭合。

## 1. 已有事实与实现核对

来源 `dlw_factor_model_20260930/REPORT.md` §3、7–8 给出

M(ξ) = [ −2iaξ, −iξ²/η ; i(ηξ²+4ξ), −2iaξ ],

λ±(ξ)=−2iaξ±γ(ξ)，γ(ξ)=sqrt(ξ⁴+bξ³)，b=4/η。

平方根取非负实部。高 |ξ| 时判别式为正，且

γ(ξ)=ξ²+(b/2)ξ−b²/8+O(1/|ξ|)，
γ′(ξ)=2ξ+b/2+O(1/ξ²)。

这里 ξ 是有符号频率；两端都以 ξ² 为首项。高频增长已是项目已有结论。

实际代码 `dlw_semidiscrete/numerics/lib/solver.py` 86–87 行为 D1=periodic_diff_matrix(..., order=4)、D2=D1@D1；`lib/dynamics.py` 的 Grid.d2 同样复合两次 d1。D1 的模板系数是 (1,−8,8,−1)/(12k)，所以

D1 exp(iξx)=i d_k(ξ) exp(iξx)，D2 exp(iξx)=−d_k(ξ)² exp(iξx)，

d_k(ξ)=[8 sin(ξk)−sin(2ξk)]/(6k)。

因此本周期常系数、连续 y 模型的离散矩阵严格为 M(d_k(ξ))。这不是假定独立五点二阶导数。当前代码的 y 開链、基值及鬼点边界另有矩阵，`lib/linearized.py` 的 open_block 明确显示这一差异；本固定 η 定理不等于它的谱定理。SDR 的非线性重构还需可恢复该物理模态，不能在 d_k=0 的模态上无条件使用坐标等价。

## 2. 新推导：符号与增长率误差的首常数

Taylor 展开为

d_k(ξ)=ξ−k⁴ξ⁵/30+k⁶ξ⁷/252+O(k⁸ξ⁹)。

若 |ξ|→∞ 且 k|ξ|→0，则 d_k/ξ→1，并由中值定理及上式得到

γ(d_k)−γ(ξ)=−k⁴ξ⁶/15 · [1+O(1/|ξ|)+O((kξ)²)]。

λ+(d_k)−λ+(ξ)=−k⁴ξ⁶/15 · [1+O(1/|ξ|)+O((kξ)²)]
                         + i a k⁴ξ⁵/15 · [1+O((kξ)²)]。

证明的余项来自 γ′(ξ)(d_k−ξ)、O((d_k−ξ)²) 与符号的 k⁶ξ⁷ 项。相对于实首项，它们分别为 O(1/|ξ|)、O(k⁴ξ⁴) 与 O(k²ξ²)；后一项控制前者的平方项。领先增长误差是负数，表示此范围内差分低估物理增长。其阶为 k⁴K⁶，绝不是 k⁴K⁴。

低频判别式零点不使用单个平方根导数展开。M(ξ) 的矩阵指数是 ξ 的解析函数，有限频段可用 Duhamel 恒等式直接控制；不会由特征值合并产生本节的虚假奇异常数。

## 3. 新推导：时间指数误差的首常数

令 δ=T/N，N∈N，z=δλ，且 |z|→0。Euler 的 R_E(z)=1+z，RK4 的 R_4(z)=1+z+z²/2+z³/6+z⁴/24。沿靠近 z=0 的对数分支，

δ⁻¹ log R_E(δλ)=λ−δλ²/2+O(δ²|λ|³)，
δ⁻¹ log R_4(δλ)=λ−δ⁴λ⁵/120+O(δ⁵|λ|⁶)。

在增长支，|ξ|→∞、k|ξ|→0、δξ²→0 时，λ+(d_k)/ξ²→1，故实指数差满足

Re[λ_E,eff(d_k)−λ+(ξ)]
 =−k⁴ξ⁶/15·(1+o(1))−δξ⁴/2·(1+o(1))，

Re[λ_4,eff(d_k)−λ+(ξ)]
 =−k⁴ξ⁶/15·(1+o(1))−δ⁴ξ¹⁰/120·(1+o(1))。

时间部分余项与首项的比是 O(δξ²)，所以 δK²→0 是展开条件，而 TδK⁴ / Tδ⁴K¹⁰→0 是累计相对精度条件，不能混用。两个领先实项同号，不能在此高频极限中指望空间和时间首项互相抵消。固定 a 带来的虚部在对应实首项低一阶。稳定支的数值稳定仍须另查；下面的 δK²→0 使两支均处于方法在零点附近的一致区。

## 4. 同一物理初值下的相对传播定理

给高频 ξ 取 M(ξ) 的单位增长特征向量 r+(ξ)，并给连续与离散相同初值 r+(ξ)。写 B=M+2iaξ I，则 B²=γ²I，P±=(I±B/γ)/2。高频时 B/γ 趋于固定非退化矩阵，因此 P± 一致有界，且

P±(d_k)−P±(ξ)=O(|d_k−ξ|/ξ²)=O(k⁴|ξ|³)。

这一点避免将离散增长特征向量替换后偷换初始物理态。确切分解为

exp[−Tλ+(ξ)] exp[TM(d_k)] r+(ξ)
 = exp[T(λ+(d_k)−λ+(ξ))] P+(d_k)r+(ξ)
 + exp[T(λ−(d_k)−λ+(ξ))] P−(d_k)r+(ξ)。

时间离散将 exp[Tλ±(d_k)] 替换为 R(δλ±(d_k))^N。第二项因 2Tξ² 的指数间距衰减，投影扰动也趋零。因此上一节的有效指数控制共同初值的相对物理误差。

对带宽 K→∞、kK→0、δK²→0，定义相对传播误差

E_rel = sup_{|ξ|≤K} exp[−T Re γ(ξ)] · ||S_{k,δ}(T,ξ)−exp[TM(ξ)]||。

低频用矩阵 Duhamel，高频用上面的有界投影分解。若首项累计至多为固定小常数，可得

Euler：E_rel ≤ C_T [k⁴(1+K)⁶ + δ(1+K)⁴]，
RK4： E_rel ≤ C_T [k⁴(1+K)⁶ + δ⁴(1+K)¹⁰]。

其中 C_T 仅依赖 L、η、a、T 和固定小量界。故候选条件逐项成立：固定 T 时 Euler 需要 k⁴K⁶→0、δK⁴→0；RK4 需要 k⁴K⁶→0、δ⁴K¹⁰→0。条件也是高频共同增长初值上相对一致逼近的必要条件：若任一非负首尺度不趋零，负的累计实指数不趋零，相对误差不能趋零。此必要性限定在 kK→0、δK²→0 的解析区，不声称覆盖不解析的网格频段。

## 5. 一条预先声明的联合律：相对阈值 2/3

为同时隔离空间机制并包含两种时间器，固定

δ_k = T / ceil(T/k⁵)，K_k≈k^(−α)，0<α<1，

K_k 取最近的允许周期 Fourier 频率。该律只定义一个理论比较序列，未提出新的算法参数或数值实验。Euler 的 δK⁴ 与 RK4 的 δ⁴K¹⁰ 均趋零，所以空间首项独自决定阈值：

- α<2/3：相对带限传播误差趋零。
- α=2/3：对 |ξ_k|≈k^(−2/3) 的共同单位增长初值，离散 / 连续增长振幅比趋于 exp(−T/15)，相对误差趋于 1−exp(−T/15)>0。
- 2/3<α<1：同一比值趋零，相对误差趋于 1。

若 K_k≈c k^(−2/3)，临界比值是 exp(−Tc⁶/15)。这里的失效发生在 kK→0 的充分分辨模态，故与 Nyquist 异常不同。这个结论不能改写为“α<2/3 时绝对物理误差收敛”。

## 6. 绝对误差必须保留传播与输入幅值

对增长初值 ε_k r+(ξ_k)，在首项累计趋零时

||error(T)|| = |ε_k| exp[Tγ(ξ_k)] ·
 O(Tk⁴|ξ_k|⁶ + Tδ|ξ_k|⁴)，

RK4 将第二项换为 Tδ⁴|ξ_k|¹⁰。对单一高频共同增长模态、空间首项占优时还有首常数 Tk⁴|ξ_k|⁶/15 的渐近等式。物理传播是 exp[T(ξ²+2ξ/η+O(1))]，不能只写一致性阶。

例如上一节任意 α∈(0,2/3) 都给相对收敛，但单位或仅多项式衰减的 ε_k 仍造成绝对误差发散。若以初态 H^s 范数归一，ε_k=(1+ξ_k²)^(−s/2)，终点仍用 H^s 范数，则这一多项式完全相消；指数障碍保留。

同一固定时间步律下，还可给出一条绝对带限算子阈值：取

K_k²≈c log(1/k)，c>0。

Euler 的时间首项 k⁵K⁴ 低于空间 k⁴K⁶，RK4 的时间项更低。全带宽增长上界为 G(K)=K²+2K/|η|+O(1)，故 H^s 带限单位球到 H^s 的绝对误差满足

E_abs ≤ C exp[TG(K)] k⁴(1+K)⁶。

- c<4/T：E_abs→0，因为其对数至多 (Tc−4)log(1/k)+O(sqrt(log(1/k)))+O(log log(1/k))。
- c>4/T：在 ξ_k 与 η 同号、|ξ_k|≈K_k 的单位 H^s 增长初值上 E_abs→∞；同一对数表达的首项为正。

临界 c=4/T 不能仅凭 ξ² 首项决定；需保留 2ξ/η、带宽取整及 K⁶ 因子。上面只证明严格两侧。这是比较同一 P_{K_k} 初态的带限算子结论，不包含完整固定初态被截掉的尾部；更不是 Sobolev 全空间适定性定理。

### 6.1 精确时间传播的带限算子首系数

若 K 是最大允许频率，K→∞、kK→0、Tk⁴K⁶→0，且不离散时间，则在两场欧氏 L² 范数下

||S_k(T)−S(T)||_{P_KL²→L²}
 ∼ κ_η · (T/15) k⁴K⁶ exp[Tγ_max(K)]，

γ_max(K)=sqrt(K⁴+4K³/|η|)，κ_η=(|η|+|η|^(−1))/2。

理由是误差首矩阵为 −(T/15)k⁴ξ⁶ exp[Tλ+(ξ)] P+(ξ)；投影变化相对它低三阶，平移相位误差低一阶。P+ 在高频极限的矩阵是 [1,−i/η;iη,1]/2，是秩一斜投影，其欧氏算子范数为 κ_η。最大模态取 ξ 与 η 同号、|ξ|=K。一般 η 不能漏掉 κ_η；η=±1 时它恰为 1。若只比较单位增长特征初值，则相应模态前系数为 T/15。

### 6.2 一个可判定的临界例外：η=1 的整数向下取整带宽

固定 L_x=2π 以使 ξ∈Z，η=1，并写 ℒ=log(1/k)，

K=floor sqrt(4ℒ/T)，r=sqrt(4ℒ/T)−K∈[0,1)。

K≥1 时 γ(K)≥K²+2K−2：右侧平方等于 K⁴+4K³−8K+4，不超过 γ(K)²。于是

Tγ(K)−4ℒ ≥ 2T(1−r)K−Tr²−2T ≥ −3T，

k⁴K⁶ exp[Tγ(K)] ≥ exp(−3T)K⁶→∞。

同时 k⁴K⁶→0，所以 6.1 的渐近有效。这个指定临界律的绝对带限算子误差发散；其至少为对数三次幂的量级。证明用到了 η=1 的线性次项 2K 抵消整数向下取整的最坏线性损失，不能推广成任意 η、任意周期频率间距或任意临界 K≈sqrt(4ℒ/T) 都失败的断言。

## 7. Nyquist 与离散最大增长：精确位置

设 θ=ξk，f(θ)=k d_k(ξ)=sinθ(4−cosθ)/3。在 [0,π] 上 f≥0，f(0)=f(π)=0；又

f′(θ)=(4cosθ−cos2θ)/3，
f′(θ)−1=−(2/3)(cosθ−1)²≤0，

所以 0≤f(θ)≤θ。唯一内部最大点满足

cosθ*=1−sqrt(6)/2，

f_max² = 1/4 + 2sqrt(6)/3 ≈ 1.883。

因此 d_max=f_max/k，而不是 π/k。Nyquist θ=π 的 M(d_k)=M(0)=0，故精确离散、Euler 及 RK4 在此模态的增长因子都等于 1；连续同频模态有约 exp(Tπ²/k²) 的增长。不能把后者称作当前离散增长率。

在全对称周期频率上，增长最大的高分辨模态取与 η 同号的 ξ，并最大化 |d|，因为相应判别式为 |d|⁴+|b||d|³，严格单调。连续 θ 的峰在 sign(η)θ*；有限网格取相邻的允许 θ，偏差 O(k)，从而

max Re λ+_k = f_max²/k² + 2f_max/(|η|k) + O(1)。

该式针对固定 η 的周期模型。对实际 y 开链，最大增长必须由实际 block 与边界算出，不能用此公式代替。

## 8. 状态与使用边界

已有事实：连续零背景高频增长、实际四阶中心模板及 D2=D1²、Euler/RK4 的标量有效指数公式。

本次新证明：增长率误差首常数 1/15；共同物理初值的有界高频投影控制；相对联合条件；预先声明律的 α=2/3 阈值；绝对带限 log 带宽的严格两侧阈值；实际符号峰与 Nyquist 的精确区别。

条件性推导：推广到固定非零 h 的周期 SD 判别式可以重新以 d 替换 ξ 并保留该判别式，而非偷换为连续 y；其首 γ~ξ² 仍可给相同次数，但常数和低频域须重算。

未解：当前 y 开链和有限窗的网格一致传播；孤子变系数背景的 Gaussian 半径估计；非线性乘法与受迫项的半径损失；真实算法的误差注入频谱和尾部控制。零背景结论不能替代这些问题。
