DLW：离散双线性方程的
两种非线性形式及 Lean 证明

2026年10月2日

摘要。从同一组有限格距双线性方程出发，严格推出 Report 的 \(u,\omega\) 两场系统，以及 \(Q,R,M\) 系统与物理 \(u,v\) 重构。两条推导均已落实为实际实函数及其导数的 Lean 定理。以下列出共同假设、完整结论与证明中的关键残差恒等式。

1　共同起点

固定 \(a\in\mathbb R\)、\(h\ne0\)。对每个 \(j\in\mathbb Z\)，\(F_j,G_j:\mathbb R^2\to(0,\infty)\) 是关于 \((x,t)\) 的全域联合实解析函数，并满足

\[ \begin{gathered} B_{a-h/2}F_j\cdot G_j=0,\qquad B_{a+h/2}F_j\cdot G_{j+1}=0,\\ B_s=D_x^2+D_t+2sD_x. \end{gathered}\tag{1} \]

这正是 Lean 的 SemiPair a h F G。正实性使对数和中心平方根具有确定的实分支。正则性由 SmoothL 表述：当前证明所用的 ContDiff ℝ ⊤ 对应解析阶 \(\omega\)。

记 \(\alpha_j=\log F_j\)、\(\beta_j=\log G_j\)，定义

\[ u_j=(2\alpha_j-\beta_j-\beta_{j+1})_x,\qquad \omega_j=(\beta_{j+1}-\beta_j)_x. \]

使用 \(\delta_-f_j=(f_j-f_{j-1})/h\)、\(M_-f_j=(f_j+f_{j-1})/2\) 和 \(\delta_0f_j=(f_{j+1}-f_{j-1})/(2h)\)。这里的 \(\omega\) 未乘以 \(4/h\)。

2　命题一：两场 \(u,\omega\) 闭合

在上述共同假设下，所定义的 \(u_j,\omega_j\) 满足 Report 式（7）的完整系统：

\[ \begin{aligned} 0={}&\delta_-u_{j,t} +\partial_x\delta_-\!\left[\frac{u_j^2+\omega_j^2}{2}+2au_j-h\omega_j\right]\\ &+\partial_x^2\!\left(\delta_-u_j+\frac4hM_-\omega_j\right),\\[3pt] 0={}&\omega_{j,t} +\partial_x\!\left[(u_j+2a)\omega_j-hu_j\right]-\omega_{j,xx}. \end{aligned}\tag{7} \]

证明要点。将两条双线性方程除以相应的正 \(\tau\) 乘积，再对归一化残差作和、差运算。两场换元和格点恒等式精确消去辅助对数势；乘积微分与相应导数的交换均由实际函数的微积分定理证明。

形式化端点：bilinear_to_report7。

3　命题二：\(Q,R,M\) 系统及物理重构

定义中心比值与势

\[ \begin{aligned} M_j&=\beta_{j,x},\\ Q_j&=\exp\!\left(\alpha_j-\frac{\beta_j+\beta_{j+1}}2\right) =\frac{F_j}{\sqrt{G_jG_{j+1}}}>0,\\ R_j&=\frac{1-\omega_j/h}{Q_j}. \end{aligned} \]

同一组假设推出 Report 式（21）的两条演化方程和格点约束：

\[ \begin{aligned} 0={}&Q_{j,t}+Q_{j,xx}+2aQ_{j,x}\\ &+\left[(M_j+M_{j+1})_x+\frac{h^2}{4}(Q_j^2R_j^2-1)\right]Q_j,\\[3pt] 0={}&R_{j,t}-R_{j,xx}+2aR_{j,x}\\ &-\left[(M_j+M_{j+1})_x+\frac{h^2}{4}(Q_j^2R_j^2-1)\right]R_j,\\[3pt] 1={}&\frac{M_{j+1}-M_j}{h}+Q_jR_j. \end{aligned}\tag{21} \]

所得物理场与命题一使用的 \(u\) 相同，并满足 Report 式（22）的全部重构：

\[ \begin{aligned} u_j&=2\frac{Q_{j,x}}{Q_j},\\ \omega_j&=h(1-Q_jR_j)=M_{j+1}-M_j,\\ v_j&=4(1-Q_jR_j)+\frac{u_{j+1}-u_{j-1}}{2h}. \end{aligned}\tag{22} \]

形式化端点：bilinear_to_report21_22；中心平方根比值由 Q_is_centered_ratio 给出。

4　关键残差恒等式

记两条归一化双线性残差为

\[ A_j=\frac{B_{a-h/2}F_j\cdot G_j}{F_jG_j},\qquad C_j=\frac{B_{a+h/2}F_j\cdot G_{j+1}}{F_jG_{j+1}}. \]

令 \(E_Q,E_R\) 分别为式（21）两条演化方程的左端，\(E_\omega\) 为式（7）第二条的左端。另设 \(P_j=Q_jR_j=1-\omega_j/h\)，并记

\[ E_P=P_{j,t}-P_{j,xx}+2aP_{j,x} +2\partial_x(Q_{j,x}R_j). \]

实际指数、商与乘积微分给出

\[ \boxed{\begin{gathered} E_Q=\frac{Q_j}{2}(A_j+C_j),\\[3pt] E_P=-\frac{E_\omega}{h},\qquad E_P=R_jE_Q+Q_jE_R. \end{gathered}} \]

由式（1），\(A_j=C_j=0\)，第一恒等式直接给出 \(E_Q=0\)。它保留了未取 \(x\) 导数的双线性信息，因此不需要逆向积分选取常数。命题一给出 \(E_\omega=0\)，于是 \(E_P=0\)；再由 \(Q_j>0\) 和第三恒等式得到 \(E_R=0\)。整个推导允许 \(R_j\) 为零。

以上结论均为从共同双线性起点到两种非线性形式的前向蕴含。统一定理 bilinear_to_both 同时收束两条系统、物理重构和中心 \(\tau\) 比值。
