# SHARED_MATH_SPEC — DLW 系统沿 y 方向离散化的公共数学规格

本文件由主 Agent 维护，八个方向的 Sub Agent 以它为唯一数学口径。凡与论文不一致处以此为准（并为歧义点给出论文出处）。

## 1. 连续系统（论文 (1)–(2)，Sheng & Yu, Physica D 432 (2022) 133140）

```
u_yt + v_xx + u u_xy + u_x u_y + 2a u_xy = 0              (E1)
v_t + (u v)_x + u_xxy + 2a v_x + 2λ u_x = 0               (E2)
```
- a, λ 为任意常数；首轮取 λ = −2（论文第 2 节 p.2 第 134 行“we take the parameter λ = −2”），a 保留任意。
- 变量变换 VT（论文 (5)）：
```
u = 2 (∂x ln(f/g)) = 2 (f_x/f − g_x/g)·1  (即 2(ln(f/g))_x)
v = 2 ∂x∂y ln(f g)
```
其中 f, g 为 tau 函数。

## 2. Hirota 双线性形式

Hirota 算子（论文 (8) 的 D 定义）：D_x^m D_t^n D_y^l f·g = (∂δ)^m(∂ε)^n(∂η)^l f(x+δ,y+η,t+ε) g(x−δ,y−η,t−ε) |_{δ=ε=η=0}。

定义 B = D_x^2 + D_t + 2a D_x。论文 (6)–(7) 的双线性系统：

```
B f·g = 0                                (BL1)
(D_y B + 2λ D_x) f·g = 0                 (BL2)
```

主 Agent 已逐字核对：论文 (6) 为 [D_y(D_x^2+D_t+2aD_x) + 2λ D_x] f·g = 0，(7) 为 (D_x^2+D_t+2aD_x) f·g = 0。与任务书中一致。

## 3. w 改写（非线性、局部化）

令 w = u_y。则 (E1),(E2) 等价于（需各方向独立核验）：

```
w_t + ∂x [ v_x + (u+2a) w ] = 0          (N1)
v_t + ∂x [ (u+2a) v + w_x + 2λ u ] = 0   (N2)
w = u_y                                   (C)
```

- (C) 的积分约束：在周期 y（周期 L）上 ∫_0^L w dy = 0（u 周期性 ⇒ u_y 零均值）；恢复 u 需一个积分常数（零模态）。
- 沿 y 离散时 (C) 的核空间、均值条件与 u 的恢复是核心。
- 若 w 仅用作辅助变量，则离散后 (C) 的离散版本决定核空间大小与棋盘格模态。

## 4. 线性化与色散

常数背景 u=u_0, v=v_0，扰动 e^{s t + i(k x + ℓ y)}，ℓ≠0。线性化特征关系（已有计算，各方向应独立核对）：

```
[s + i(u_0 + 2a) k]^2 = k^4 − (v_0 + 2λ) k^3 / ℓ
```

含义：若 (v_0+2λ) k^3/ℓ 的虚部符号使 Re(s)>0，则高频增长（Hadamard 不适定或双曲传播），对一般初值稳定性和收敛理论是实质性限制。不得以隐式时间离散、守恒离散、有限元或辛离散为由宣称该障碍消失；只能作为“特定初值类/带限类”下的受限结论。

## 6. 谱参数约定（与论文 mKP 归约一致）

论文 (12)–(15)：
φ_i^(n) = (p_i − a)^n e^{ξ_i}，ψ_j^(n) = (−q_j − a)^{−n} e^{η_j}，
ξ_i = p_i x_1 + p_i^2 x_2 + x_{−1}/(p_i − a) + ξ_{i0}，
