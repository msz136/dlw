# 兼容基准不适合展示 Endpoint 的一般一阶 v 误差

**同日后续已解决新参数筛选：** [非退化基准](../nondegenerate_benchmarks/PROOF.md)给出v0=4−3u0_y的纯高斯／正弦、严格参考与非零首项。该关系仅在初时成立，因而不受本文件“恒持仿射配对”排除结论限制。下面“尚无合格参数”的历史状态已被该构造取代；对v=4±u_y分支的退化结论仍成立。

2026-10-24。用户明确要求真正的高斯／正弦初始化，且不能由u、v特殊关系消掉要研究的误差首项。此前建议的有理三角周期波不满足严格的纯正弦形状要求，应排除。

## 已核实的退化

依据 [首项推导](../../spatial_audit_20261023/separated/leading_y_analysis.md) 所列内部节点、精确场初始化、解析x导数的半离散RHS缺陷：

    r_Endpoint,v = h C_v + O(h²),
    C_v = −(1/4)∂x[v²−u_y²−8v]
        = −(1/4)∂x[(v−4)²−u_y²].

v=4−u_y与v=4+u_y均使C_v恒等为零，且只要解留在该分支就对所有时间成立。调整振幅、宽度、波数或正负分支均不能解除。这只说明特定的一阶首项退化；不意味着所有误差消失，也不单凭此推出终态全误差的收敛阶。

因此兼容高斯／正弦可作精确参考及退化机制检查，不能作为展示一般非零O(h)系数的主算例。此前将其推荐为一般误差展示基准的建议需要收窄。首项公式适用范围及当前Centered版本应分别处理，不能把该Endpoint结论泛化为所有格式首项均为零。

## 纯波形、非退化的原始候选

保留原问题两组独立初始化（κ=π/4,z=y+2）：

正弦 u0=.03 sin(κz)cos(πx/12)，v0=.02 sin(κz)sin(πx/12)。
在y=0,x=0，C_v=2(.02)(π/12)=π/300≈.0104719755，故首项严格非零。

高斯 u0=.05 sin(κz)G(x)，v0=.03 sin(κz)G(x)，G为周期192、宽度6的周期高斯。
在y=0，C_v=(.06−.00045G)G_x。G非恒定且0<G<1.000001，故C_v不恒为零。

leading_term_check.py/json用符号计算核对以上恒等式。两组原始候选的初始时间导数可解析求出，可以研究t=0的空间缺陷；其T=.01连续全场参考仍未认证，不能拿兼容基准的误差证书替换。小幅破坏兼容关系虽一般能恢复首项，但也会破坏已证明的热方程参考；不能将小扰动自动视为已有认证。

候选须同时满足：真正的高斯／正弦初值；目标首项非零且量级可辨；所需时间区间内有可认证参考。当前已分别解决兼容数据的参考和非兼容数据的非退化首项，尚未在同一组数据上满足这三项。原goal仍未完成。

## 仿射配对参数筛选（同日补充）

尝试更一般的常数参数约束v=b+c u_z，要求它在时间演化中持续成立，仍有下边界u=0。第一条DLW方程积分得

    u_t=−c u_xx−(u+4)u_x.

将其代入第二条方程的残差，精确得到

    (1−c²)u_xxz+(b−4)u_x=0.

该恒等式经SymPy展开核对。对u0=A sin(κz)F(x)，A≠0，F为非恒定正弦或周期高斯：在z=0，u_x=0而u_xxz=AκF_xx不恒为零，故c²=1；再取内部z，u_x不恒为零，故b=4。于是该更一般配对族只能回到v=4±u_z，仍然消掉目标首项。

这是对常数仿射导数配对构造的排除，不是对所有高斯／正弦初始化的不可得性定理。若只在t=0给定其他b,c而不要求关系持续，仍是合法候选数据，但上述精确参考构造不再成立。目前不能给出满足用户全部要求的已认证参数组。
