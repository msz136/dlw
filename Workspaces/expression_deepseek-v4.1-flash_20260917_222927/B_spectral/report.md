# 方向 B：`y`-半离散化的谱与伪谱方法

**对象**：(2+1) 维色散长波（DLW）系统，`λ = −2`、`a` 任意，只离散 `y`，`x, t` 保持连续。

$$
\begin{aligned}
&u_{yt} + v_{xx} + u\,u_{xy} + u_x u_y + 2a\,u_{xy} = 0, \tag{1}\\
&v_t + (uv)_x + u_{xxy} + 2a\,v_x + 2\lambda\,u_x = 0. \tag{2}
\end{aligned}
$$

**方法选择**：主结果为 `y` 方向的 **Fourier–Galerkin 截断**（保留模式 `−N..N`，槽位 `Fin (2N+1)`）；
伪谱（配点）作为对照，用于**定量**刻画混淆（aliasing）。Chebyshev 只在"非周期有限 `y` 区间"
这一备选情形中讨论（§5），并明确标注其未形式化部分。

---

## 0. 摘要（TL;DR）

1. **`y`-离散不改变 `x`-符号**：`y`-导数在 Fourier 模式空间是对角乘子 `iℓ`，因此截断 `N` 只
   决定"保留哪些 `ℓ`"，完全不进入色散关系。色散关系
   `(σ + i(u0+2a)k)² = k⁴ − (v0+2λ)k³/ℓ` 与无穷维情形逐字相同（Lean：`dispersion_relation`）。
2. **零模 sector 是唯一的退化**：`ℓ = 0` 时 (1) 化为精确的 `∂_x² v̂_0 = 0`，故
   `v̂_0 = α(t) + β(t)x`；(2) 给出 `v̂_0` 的演化。`v ≡ −2λ`、`u = U(x,t)` 任意是**精确解族**
   （V7），且在任意截断下保持精确（§1.3，Lean：`kernel_eq_zero_mode_line`，实验 Sec 2/3）。
3. **逆算子障碍不是格点现象**：非零模乘子 `iℓ` 可逆（Lean：`invMult_mult`、`mult_invMult`），
   `∂_y` 在带内只有 1 维核 —— 即零模线；格点中心差分的核维数在奇 `M` 下也是 1，但
   **偶 `M` 下会多出 1 维**（实验 Sec 7），所以"`2N+1` 个格点"是刻意的选择。
4. **主要否定结论（对应 spec 的 refutation 项"固定截断稳定冒充网格一致稳定"）**：
   对**每一个**截断 `N ≥ 1` 与**每一个** `k ≠ 0`，带内都存在不稳定模；增长率
   `Re σ = √(k⁴ + c k³) ≥ k²`（`c = v0+2λ > 0`），**结论中不含 `N`**
   （Lean：`band_unstable_uniform_in_N`）。因此"某个 `N` 上数值稳定"绝不能读作
   "网格一致稳定"。实验 Sec 6(a)(b) 给出等价的数值表。
5. **截断真正正则化的是 `ℓ → 0` 方向**：连续符号的增长率在固定 `k` 下随 `ℓ → 0⁻` 无界
   （`Re σ ~ √(c k³/|ℓ|)`），而带内最大值 `√(k⁴+ck³)` 有限。所以 `y`-截断消除了 `ℓ = 0` 的
   奇性，**不能**消除 `k → ∞` 的 Hadamard 不适定（§8）。这是本方向对 spec §2 标准阻碍的
   精确表述，而不是"消除"。
6. **混淆被定量**：`M = 2N+1` 点时顶模 `N` 的平方（频率 `2N`）与带内模 `−1` 在网格上
   不可分辨，伪谱在模 `−1` 上产生**与数据同阶**的虚假系数（O(1) 相对误差，不是小量）；
   去混淆阈值恰为 `M ≥ 3N+1`（Lean 3 点实例 + 一般恒等式 `sample_alias`；实验 Sec 5 对
   `N = 1..8` 精确验证）。零模 `ℓ = 0` 对二次非线性**永不**被混淆（`M > 2N` 时）。
7. **去混淆的作用是精确但有限的**：它把伪谱恢复为精确的 Galerkin 卷积（非线性转移项），
   但**不改变**线性色散关系、**不改变**零模 sector、**不改变**增长率（§7）。

## 1. 构造

### 1.1 模式空间与乘子

取周期 `y`（周期 `2π`），
`u(x,y,t) = Σ_{ℓ∈ℤ} û_ℓ(x,t) e^{iℓy}`，`v` 同理。截断到 `|ℓ| ≤ N`，用槽位
`Fin (2N+1)` 索引，`modeIdx N i = i − N`，零模下标 `zeroIdx N = ⟨N, _⟩`。

* 乘子 `multLin N : (Fin (2N+1) → ℂ) →ₗ[ℂ] (Fin (2N+1) → ℂ)` 定义为
  `(multLin N c) i = (modeIdx N i : ℂ) * c i`，即**对角**乘子 `iℓ`。
* 去平均子空间 `zeroMean N = {a | a (zeroIdx N) = 0}`。
* 逆乘子 `invMultLin N`：在非零模上 `1/(iℓ)`，在零模上取 `0`。

Lean 已证的结构性事实（`proofs/Spectral/Multiplier.lean`）：

| 命题 | 内容 |
|---|---|
| `mult_eq_zero_iff` | `multLin N c = 0 ↔ modeIdx N i = 0` 处的分量任意、其余为 0，即核恰是零模线 |
| `kernel_eq_zero_mode_line` | `∂_y` 在带内的核 = 1 维零模线（与 `N` 无关） |
| `invMult_mult` / `mult_invMult` | 在 `zeroMean N` 上互逆；在零模上合成投影 `modeProj` |
| `mult_comp_modeProj` / `modeProj_comp_mult` | 逆与乘子的合成分解 = 零模投影 |
| `mean_mult` | 零模分量在 `multLin` 下仍为 0（乘法不产生零模） |

**与格点路线的对比**：`proofs/Common/Operators.lean` 的 `Common.ctr_kernel` 说明中心差分
`ctr` 在 `w(j+1) = w(j−1)`（即常值/交错常值）时为零。实验 Sec 7 精确验证：在 `ℤ/M` 上中心
差分的零空间维数为 **1（`M` 奇）**、**2（`M` 偶）**。Fourier 带内只有 1 维（零模线），
这正是用 `2N+1` 个格点（奇）而非 `2N` 个的原因。

### 1.2 Galerkin 半离散系统

把 Fourier 展开代入 (1)(2) 并取第 `ℓ` 个模式（`x`-导数与模式分解交换）：

$$
\begin{aligned}
\text{(G1)}_\ell:\quad & i\ell\,\partial_t \hat u_\ell \;+\; \partial_x^2 \hat v_\ell
   \;+\; i\!\!\sum_{m+n=\ell}\!\! n\,\partial_x(\hat u_m \hat u_n)
   \;+\; 2a\,i\ell\,\partial_x \hat u_\ell = 0,\\[2mm]
\text{(G2)}_\ell:\quad & \partial_t \hat v_\ell \;+\; \partial_x\!\!\sum_{m+n=\ell}\!\!\hat u_m \hat v_n
   \;+\; i\ell\,\partial_x^2 \hat u_\ell \;+\; 2a\,\partial_x \hat v_\ell
   \;+\; 2\lambda\,\partial_x \hat u_\ell = 0 .
\end{aligned}
$$

求和在保留带 `|m|,|n| ≤ N` 内进行（**精确卷积** = Galerkin）。四个非线性来源分别是
`u u_xy`、`u_x u_y`（二者之和给出 `i Σ n ∂_x(û_m û_n)` 的分裂形式）、`(uv)_x`、以及线性的
`u_xxy = iℓ ∂_x² û_ℓ`。

### 1.3 零模 sector（`ℓ = 0`）

* (G1)₀：`i·0·∂_t û_0` 项与 `2a·i·0·∂_x û_0` 项消失，二次项
  `i Σ_{m+n=0} n ∂_x(û_m û_n) = −(i/2)∂_x Σ_m m⋯ = 0`（反对称配对；实验 Sec 2 精确验证）。
  于是
  $$\partial_x^2 \hat v_0 = 0 \qquad\Longleftrightarrow\qquad \hat v_0(x,t) = \alpha(t) + \beta(t)x .$$
  **`û_0` 在 (G1)₀ 中完全不出现**：`u` 的零模是 (1) 的规范自由度。
* (G2)₀：`i·0·∂_x² û_0 = 0`，于是
  $$\partial_t \hat v_0 + \partial_x\Big[\textstyle\sum_m \hat u_m \hat v_{-m} + 2a\hat v_0 + 2\lambda \hat u_0\Big] = 0 .$$
  与 `∂_x² v̂_0 = 0` 合并得到**相容性约束** `∂_x³[Σ_m û_m v̂_{−m} + 2a v̂_0 + 2λ û_0] = 0`。
* **V7 精确族**：`v ≡ −2λ`（即 `v̂_0 = −2λ`，其余 `v̂_ℓ = 0`），`u = U(x,t)` 任意。
  此时 (G2)₀ 化为 `∂_x[−2λU + 2a(−2λ) + 2λU] = −4aλ·∂_x(1) = 0`，全部 `ℓ ≠ 0` 方程为
  恒 `0`。实验 Sec 2/3 对 `N = 1,2,3` 与 `ℓ ∈ {−3..3}` 精确验证该族是**任意截断下的精确解**。
* 因此零模 sector 的"信息损失"恰好是 `û_0` 一个模态，且仅在 `v̂_0 = −2λ` 时 `û_0` 是自由的。

### 1.4 连续极限与相容阶

* **`y`-方向无离散色散误差**：乘子 `iℓ` 是精确的，`u_{xxy}` 的乘子 `(ik)²(iℓ)` 也是精确的。
  固定 `k` 与 `ℓ`（`N ≥ |ℓ|`）时，半离散符号与连续符号**逐字相同**
  （Lean：`dispersion_relation` 的陈述中根本没有 `N`）。全部误差只能来自**投影**与
  **非线性求值的混淆**，这与有限差分路线（有 `O(h²)` 相容误差）本质不同。
* **`N → ∞`**：Galerkin 卷积在光滑/解析类上收敛到精确卷积；投影误差为标准谱界
  `‖u − P_N u‖ ≤ C N^{−s}‖u‖_{H^s}`（**未形式化**，见 §10）。源解的 tau 函数含
  `exp(y/(p±a))`，属于解析类，故谱收敛是合适的期待。
* `x` 方向保持连续（全直线 `k ∈ ℝ`）；即使改用有限 `x`-区间 + 周期边界，`k` 只变成离散但
  **仍无界**，§8 的不稳定性结论逐字保留。

## 2. 线性化与色散关系（Lean 已证）

设 `u = u0 + U e^{σt+i(kx+ℓy)}`、`v = v0 + V e^{σt+i(kx+ℓy)}`（常量背景 `(u0,v0)`）。
(1)(2) 的一阶项为

$$
\begin{aligned}
\text{(1L)}:\quad & (i\ell\sigma)U - k^2 V - (u_0+2a)k\ell\,U = 0,\\
\text{(2L)}:\quad & \big(\sigma + i(u_0+2a)k\big)V + i(v_0+2\lambda)k\,U - ik^2\ell\,U = 0 .
\end{aligned}
$$

**定理（`dispersion_relation`，Lean）**：若 `k ≠ 0, ℓ ≠ 0, U ≠ 0` 且 (1L)(2L) 成立，则

$$
\big(\sigma + i(u_0+2a)k\big)^2 = k^4 - (v_0+2\lambda)\,\frac{k^3}{\ell}. \tag{3}
$$

Lean 中该结论以"无除法"形式陈述（`∀` 假设下），除法只在最后一步用 `k ≠ 0, ℓ ≠ 0` 消去；
`nontrivial_dispersion_relation` 处理 `U = 0`（此时 (1L) 强制 `V = 0`，故非平凡模必有 `U ≠ 0`）；
`mode_of_dispersion_relation` 证明 (3) 也是充分的（`U = 1`、`V = (iℓs − (u0+2a)kℓ)/k²` 给出解），
所以 (3) **刻画**了全部非平凡线性模。消元中唯一用到 `i² = −1` 的地方被隔离为显式引理
`I_factor`；实验 Sec 1 用 SymPy 独立重做同一消元并复核 (1L)(2L) 的每一项。

记 `c = v0 + 2λ`。则

$$R(k,\ell) := k^4 - c\frac{k^3}{\ell} = k^3\Big(k - \frac{c}{\ell}\Big), \qquad
\operatorname{Re}\sigma = \pm\sqrt{R}\ \ (\text{若 } R>0),\qquad \operatorname{Re}\sigma = 0\ (\text{若 } R<0).$$

`mode_of_nonneg_discriminant`（Lean）构造 `R ≥ 0` 时的根 `σ = −i(u0+2a)k + √R`，
`neutral_mode_of_negative_discriminant`（Lean）证明 `R < 0` 时两根纯虚（中性）。这给出**精确二分**。

## 3. 稳定性：单侧扇区 vs 全带

`c > 0` 时由 `R = k³(k − c/ℓ)` 立即得到：

| 区域 | 判别式 | 结论 |
|---|---|---|
| `kℓ > 0` 且 `|k| < c/|ℓ|` | `R < 0` | **中性**（既不增长也不衰减） |
| `k > 0, ℓ > 0, k > c/ℓ` | `R > 0` | 不稳定，`Re σ = √(k⁴ − ck³/ℓ)` |
| `kℓ < 0`（任意 `k ≠ 0`） | `R > 0` | **不稳定**，`Re σ = √(k⁴ + ck³/|ℓ|)` |
| `ℓ = 0` | — | 非零模不存在（退化为 §1.3 的约束/规范） |

* **单侧扇区**（`ℓ ≥ 1`，即 `k > 0`）：中性当且仅当 `k ≤ c/ℓ`；对保留带 `1..N`，阈值是
  `k ≤ c/N`。Lean：`band_stability_threshold`（正面）、`band_instability_threshold`（阈值锋利）。
  实验 Sec 6(c) 用扫描精确复现 `k* = c/N`（`N = 1,2,4,8,16`）。
* **全带（这是关键）**：`ℓ = −1` 属于**每一个** `N ≥ 1` 的带，而它在**任意** `k > 0` 下都不稳定，
  且 `Re σ = √(k⁴+ck³) ≥ k²`。故

> **定理（`band_unstable_uniform_in_N`，Lean）**：`N ≥ 1`、`c > 0`、`k > 0` ⟹ 带内存在模
> `ℓ = −1`（`modeIdx N i = −1`）以及一个根 `σ`，满足 `(σ+i(u0+2a)k)² = k⁴+ck³`、
> `Re σ = √(k⁴+ck³) ≥ k²`。**陈述中不含 `N`。**

这就是 spec refutation 项"固定截断稳定性冒充网格一致稳定性"的形式化：
`N` 截断的线性化系统在**每一个** `k ≠ 0` 处都不稳定，且增长率的主项 `~k²` 与 `N` 无关。
`band_contains_growing_mode` 给出较弱但更"物理"的版本（用 `ℓ = 1`、`k ≥ c`，增长率
`≥ k² − ck`），两条互不替代。

**诚实的范围声明**：`band_stability_threshold` 是**单侧**结论（`ℓ ≥ 1`）。不能把它读成
"截断系统在 `k ≤ c/N` 时稳定"，因为同带的 `ℓ < 0` 模在该区间不稳定。`report` 与
`CONCLUSIONS.md` 均如此标注。

## 4. VT（变量变换）可行性

源文使用的变换本质是令 `w = u_y`：此时 (1)(2) 成为 `x`-方向的一阶守恒形式

$$
w_t + \partial_x\big[v_x + (u+2a)w\big] = 0,\qquad
v_t + \partial_x\big[(u+2a)v + w_x + 2\lambda u\big] = 0 . \tag{4}
$$

（用到 `u u_{xy} + u_x u_y = (u u_y)_x`。）

* **正向（`u → w`）在 Fourier 下代价为零**：`ŵ_ℓ = iℓ û_ℓ`，非零模可逆。
* **反向（`w → u`）丢失零模 `û_0`**：`∂_y` 的核正是零模线（Lean：`kernel_eq_zero_mode_line`、
  `mult_eq_zero_iff`）。在谱离散下这是**恰好 1 维**的损失，而不是格点路线中"核依赖于
  `w(j+1)=w(j−1)` 这类更大假设类"的现象。
* **零模的恢复条件**：§1.3 表明 `û_0` 是规范自由度当且仅当 `v̂_0 = −2λ`（V7）。因此
  VT 在谱离散下**不引入额外障碍**；唯一代价是必须显式固定 `û_0`（或沿用 V7 的规范）。
* 结论：VT 与 Fourier 截断相容；与格点路线相比，VT 的信息损失更小、更清晰。

## 5. 边界条件：为什么用 Fourier，Chebyshev 何时才该用

* **Fourier（主结果）**：要求 `y` 周期。优点：(i) 乘子精确对角，`y`-导数无相容阶损失；
  (ii) 混淆结构完全显式（§6），去混淆阈值精确（§6.3）；(iii) 无额外条件数问题。
* **Chebyshev（备选，仅非周期有限 `y`-区间）**：源解的 tau 函数含 `exp(y/(p±a))`，解在 `y` 上
  是解析/整的，Chebyshev 谱收敛是合理的；但 (i) 必须显式给定 `y`-边界条件，(ii) 微分矩阵
  条件数 `O(N²)`，这是**数值伪影**而非适定性问题（不能据此声称改善了 `|Re σ| ~ k²`），
  (iii) 零模 sector 的 `α(t) + β(t)x` 自由度会被边界条件固定，从而改变 `û_0` 的规范结构。
* 因此：**主结论（线性增长、混淆、零模）全部在 Fourier 下陈述**；Chebyshev 情形标注为
  "未形式化、仅作可行性讨论"（§10）。

## 6. 混淆的定量分析（`u u_xy`、`u_x u_y`、`(uv)_x`、`u_xxy`）

### 6.1 精确模型

在 `M` 点均匀网格上（`ζ` 为 `M` 次本原单位根），频率 `ℓ + Mt` 与 `ℓ` 的**采样完全相同**
（Lean：`sample_alias`：`ζ^((ℓ+Mt)j) = ζ^(ℓj)`）。由此，配点（伪谱）在模 `m` 处的乘积系数为

$$\widehat{(fg)}^{\text{coll}}_m \;=\; \sum_{p+q \equiv m \ (\mathrm{mod}\ M)} f_p g_q,$$

而 Galerkin（精确卷积）是 `Σ_{p+q=m} f_p g_q`。两者的差 = **外带贡献**。实验 Sec 5 用
单位根滤波恒等式 `Σ_j ζ^{tj} = M·[M|t]` 精确验证该公式，再与卷积公式逐一比较。

### 6.2 四项非线性

* `u u_xy`、`u_x u_y`、`(uv)_x`：在 `y`-次数上都是**二次**。`x`-导数与 `y`-模式分解交换，
  所以混淆结构与纯乘积 `u·u` 完全相同：带内积的频率落在 `[−2N, 2N]`，外带部分以模 `M`
  折回带内。**四项统一适用同一条 2/3 规则**。
* `u_xxy`：**线性**，模式乘子 `(ik)²(iℓ)` 精确，**没有混淆**。这是"谱方法在 `y` 方向没有
  相容阶损失"的直接体现，也是它与有限差分路线的关键区别。
* 逐项混淆定量（`M = 2N+1`，带内 `−N..N`）：
  * Lean：`out_of_band_folds_into_band` —— 每个频率 `f ∈ (N, 2N]` 与某个 `i ∈ [−N,−1]`
    相差**恰好** `M = 2N+1`；故**每个** `N ≥ 1` 的带都被污染。
  * Lean：三点实例 `three_point_collision`（`ω₃^{2j} = ω₃^{3−j}`）、`alias_offset`。
  * 实验 Sec 5：对 `N = 1..8`，`M = 2N+1` 时顶模 `N` 的平方把模 `−1` 污染成
    **精确值 0 对伪谱值 1**（未归一化 `3`），即**相对误差无界/O(1)**，绝不是小量。

### 6.3 去混淆阈值（精确、锋利）

配点与精确卷积在带内一致 ⟺ 对任意 `m ∈ [−N,N]`、`s ≠ 0` 有 `m + sM ∉ [−2N,2N]`，即
`M − N > 2N` ⟺ `M ≥ 3N+1`（2/3 规则）。

* 实验 Sec 5：`M = 3N+1` 对 `N = 1..8` **精确**复原全部 Galerkin 系数（有理整数算术，
  无浮点）；`M = 2N+1` 与 `M = 3N` 都被污染。阈值两边都验到。
* **零模 `ℓ = 0` 的例外（重要）**：`p+q ≡ 0 (mod M)` 且 `|p+q| ≤ 2N < M` 迫使 `p+q = 0`，
  故 `ℓ = 0` 的二次乘积系数在 `M > 2N` 时**与 Galerkin 完全相同**。实验显式验证
  （`0 not in bad` 对 `N = 1..8`）。结合 §1.3：**V7 零模族在去混淆前后都是精确解**。

## 7. 去混淆的效果（显式陈述）

1. **恢复精确 Galerkin**：padding 到 `M ≥ 3N+1`（或 2/3 规则）后，伪谱非线性 = 精确卷积
   （实验 Sec 5 精确验证）。
2. **不改变线性层**：色散关系、增长率、稳定性区域都与是否去混淆无关（线性层本来就没有混淆）。
3. **不改变零模 sector**：`ℓ = 0` 的二次系数在 `M > 2N` 时本就无混淆（§6.3）。
4. **不去混淆 = 求解另一个问题**：受影响模受到与数据同阶（O(1) 相对）的扰动，因此
   "未去混淆的伪谱解"不能声称是 DLW 的 Galerkin 投影解。这一步在 Lean 中被形式化为
   **反例**：`aliasing_breaks_projected_identity`
   `(Σ_{j<3} ω₃^{2j}ω₃^j) = 3 ≠ 0 = (Σ_{j<4} I^{2j}I^j)`，即"投影恒等式被混淆破坏"。
5. **去混淆不能修复适定性**：它只修非线性转移项，不触及 §8 的 `k²` 增长。

## 8. 有限带增长 vs 连续高频增长（谱诊断）

固定 `c = 1`（如 `v0 = 5, λ = −2`），定义带内最大增长率
`G(k,N) = max_{1 ≤ |ℓ| ≤ N} Re σ(k,ℓ)`。实验 Sec 6 的表格给出：

| `k` | `N=1` | `N=2` | `N=4` | `N=8` | `N=16` | `N=32` | `√(k⁴+ck³)` |
|---|---|---|---|---|---|---|---|
| 0.25 | 0.1398 | 0.1398 | 0.1398 | 0.1398 | 0.1398 | 0.1398 | 0.1398 |
| 1 | 1.4142 | 1.4142 | 1.4142 | 1.4142 | 1.4142 | 1.4142 | 1.4142 |
| 8 | 67.8823 | … | … | … | … | 67.8823 | 67.8823 |
| 64 | 4127.8760 | … | … | … | … | 4127.8760 | 4127.8760 |

（`G(k,N)` 与 `√(k⁴+ck³)` 在 `N = 1..32`、`k ≤ 64` 上逐位一致；比值 `G/k² → 1`：
`k = 16` 时 1.0308、`k = 32` 时 1.0155、`k = 64` 时 1.0078。）

四项诊断结论：

1. **带内最大值恒在 `ℓ = −1`**，故 `G(k,N) = √(k⁴+ck³)` 与 `N` **完全无关**
   （Lean 给出 `Re σ = √(k⁴+ck³)` 与 `≥ k²` 的下界；上界的平凡估计见 §10）。
2. **每一个 `N ≥ 1`、每一个 `k ≠ 0` 都不稳定**（数值与 Lean 一致）。
3. **增长率的主项 `~k²` 与 `N` 无关**：加密 `y`-分辨率既不能恢复稳定，也不能降低 `k`-增长率。
4. **连续-带差异只在 `ℓ → 0` 方向**：固定 `k = 1` 时

   | `ℓ` | `−10⁻¹` | `−10⁻²` | `−10⁻³` | `−10⁻⁶` |
   |---|---|---|---|---|
   | `Re σ` | 3.3166 | 10.0499 | 31.6386 | 1000.0005 |
   | `√(ck³/|ℓ|)` | 3.1623 | 10 | 31.6228 | 1000 |

   即连续符号在 `ℓ → 0⁻` 时无界，而带内（`|ℓ| ≥ 1`）最大值有限（`k = 1` 时为 1.4142）。

**结论**：`y`-谱截断**正则化了 `ℓ → 0` 方向的奇性**（`|ℓ| ≥ 1` 的带是有界的），
但**完全没有触及 `k → ∞` 方向的 Hadamard 不适定**。spec §2 的标准阻碍 `|Re σ| ~ k²` 依旧成立，
本方向只把它**定位得精确**：它在每一个固定截断上都存在，且不随 `N` 改善。
