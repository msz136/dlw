## A. 障碍算子的结构（Lean 代数验证）

**结论 1.**
`Θ := diag(w) C − Cᵀ diag(w)` 的元素为 `Θ_{ij} = w_i C_{ij} − w_j C_{ji}`。
对象：任意格点数 `n`、任意交换环 `K`、任意离散 `∂_y^{-1}` 矩阵 `C`、任意场 `w`。
假设：无（不要求 `Cᵀ = −C`，不要求 `w` 非退化）。
Lean：`DLW.E.theta_entry`（`proofs/E_Poisson.lean`）。
等级：**Lean 代数验证**。

**结论 2.**
`Θ` 恒反对称：`Θᵀ = −Θ`。
对象/假设：同结论 1（一般 `n`、一般 `C`、无额外假设）。
Lean：`DLW.E.theta_antisym`。
等级：**Lean 代数验证**。
说明：`Θ` 与 `∂_x` 同型（反对称），这是"常对称核 `Q` 无法抵消它"的结构性原因。

**结论 3.**
若离散 `∂_y^{-1}` 取斜伴随约定 `Cᵀ = −C`（周期格点/零均值伪逆），则 `Θ = diag(w) C + C diag(w)`（反对称换位子的加倍）。
对象/假设：一般 `n`、`Cᵀ = −C`。
Lean：`DLW.E.theta_eq_of_skew`。
等级：**Lean 代数验证**。

**结论 4.**
`Fin 3` 单侧累加和约定（`u₀ = 0, u₁ = w₀, u₂ = w₀+w₁`）下：`Θ₁₀ = w₁`，`Θ₂₀ = w₂`。
对象/假设：`n = 3`、`C = cum3`（严格下三角）、`K = ℚ`。
Lean：`DLW.E.Theta3_one_zero`、`DLW.E.Theta3_two_zero`、`DLW.E.cum3_one_zero` 等。
等级：**Lean 代数验证**。

**结论 5（非平凡性）.**
`w₁ ≠ 0 ⟹ Θ ≠ 0`；反之 `Θ = 0 ⟹ w₁ = 0 ∧ w₂ = 0`。
对象/假设：`Fin 3` 累加和约定；`w₁` 即耦合开启的判据。
Lean：`DLW.E.Theta3_ne_zero`、`DLW.E.Theta3_eq_zero_forces`。
等级：**Lean 代数验证**。

**结论 6（退化情形）.**
`w ≡ 0`（即 `u` 不依赖 `y`）时 `Θ = 0`。
对象/假设：`Fin 3`，`∀ i, w i = 0`。
Lean：`DLW.E.Theta3_eq_zero_of_w_eq_zero`。
等级：**Lean 代数验证**。
说明：这只在"约束不含信息、`u` 退化为参数"的退化位置成立。

## B. 主要否定结论（Lean 代数验证 + 未形式化桥接）

**结论 7（类 𝒞 中无 Hamiltonian）.**
设 `P = ∂_x Q`，`Q` 为场无关、`x`-平移不变、可逆的常对称 `2n×2n` 核（类 𝒞）。则对一般场值（`Θ ≠ 0`），类 𝒞 中**不存在** `H` 使 `∂_t(w,v) = ∂_x Q (δH/δw, δH/δv)ᵀ`。Helmholtz 分块方程为 `q₁₁•Θ = 0`、`2q₁₂ = 0`、`q₂₂+q₁₁ = 0`，其唯一解为 `Q = 0`（奇异，非 Poisson/辛算子）。
对象：`y`-离散、`x,t` 连续的 DLW 系统（`λ = −2`，`a` 任意）；`Fin 3` 累加和格点的显式实例。
假设：`w₁ ≠ 0`（耦合开启）；三条 Helmholtz 方程作为假设取入。
Lean：`DLW.E.no_invertible_constant_poisson_bracket`、`DLW.E.no_nontrivial_constant_poisson_Q`。
未形式化的桥接：由"Hamiltonian 存在"推出三条 Helmholtz 方程所需的连续 `x` 形式变分学（Fréchet 导数形式自伴性 + 按 `D_x` 幂次/分块作系数匹配 + 测试函数 `φ≡1`、`φ=x` 分离系数）。
等级：**Lean 代数验证**（结论的代数内核）；桥接为 `数学证明，尚未完整形式化`。
**范围声明**：只否定类 𝒞。类 𝒞 之外的更大类**未被否定**（见结论 16）。

**结论 8（一般常矩阵 `Q`，实验验证）.**
不假设 `Q = q ⊗ I`，允许任意常对称 `2n×2n` 块矩阵。五条分块方程 (S1)–(S5)：
`n = 2`、一般反对称 `C`（自由符号元素）、`w,v,a,λ` **全符号** ⟹ 唯一解 `Q = 0`。
`n = 3,4` 循环反对称 `C`（两组独立精确有理采样）⟹ 唯一解 `Q = 0`。
Lean：unformalised。
脚本：`experiments/e2_poisson_antisym.py`（E5、E6、E8 段）。
等级：**实验验证**（SymPy 符号/精确有理）。

**结论 9（单侧累加和约定的残解是奇异的，实验验证）.**
`n = 3,4` 单侧累加和下，Helmholtz 系统的唯一解为 `Q₁₁ = p·E_{n-1,n-1}`、`Q₁₂ = 0`，故 `Q` **奇异**，不是括号。
脚本：`experiments/e1_poisson_search.py`（E1）、`e2_poisson_antisym.py`（E7）。
等级：**实验验证**。

**结论 10（障碍是结构性的，不随离散化消失）.**
`h → 0` 时 `Θ_h → Θ_∞ = w ∂_y^{-1} + ∂_y^{-1} w ≠ 0`（`w` 非 `y`-常数）；中心差方案下 `Θ_h − Θ_∞ = O(h²)`。故不存在"保 Poisson 的 `y`-离散化"。
Lean：unformalised。
等级：**数学证明，尚未完整形式化**。

## C. 相容性与构造性说明

**结论 11（相容阶）.**
`u_y` 的离散逼近：中心差 `O(h²)`，单侧差 `O(h)`；`u = Cw` 重构：约定 (a) `O(h²)`，约定 (b) `O(h)`；半离散系统相容阶相应为二阶/一阶。
等级：**数学证明，尚未完整形式化**（形式 Taylor/象征层面；**不是**余项估计，**不**蕴含收敛）。

**结论 12（约束与核）.**
`u_y = w` 在格点上只能解到 `y`-常数；单侧累加和约定下 `w_{n-1}` 不出现在 `Φ` 中。须固定规范（取 `u` 的格点均值为 0）。
共享模块依据：`DLW.Common.ctr_kernel`（已 PASSED，非本方向成果）。
等级：**数学证明，尚未完整形式化**（共享模块中相关算子事实为 Lean 已验证）。

**结论 13（标准 Dirac 配对失败）.**
在扩展相空间 `(u,w,v)` 上保留约束 `u_y = w`、取标准配对 `{u,v} = c∂_x` 时，约束传播的 Helmholtz 条件要求 `(u+2a)/c = −(u+2a)/c`，故 `c = 0` 或 `u ≡ −2a`：该配对**不产生**约束括号。
Lean：unformalised。
等级：**数学证明，尚未完整形式化**（手算）。

## D. 零模与稳定性

**结论 14（精确零模被精确保持，且是障碍消失的唯一位置）.**
`v ≡ −2λ = 4`、`u = U(x,t)`（`w ≡ 0`）是精确解；离散格式逐点精确保持它（所有 `y`-导数项消失）。此时 `Θ = 0` 且 `E = 0`，障碍消失，可取 `Q = diag(q,−q)`。
`w ≡ c ≠ 0`（`u` 为 `y` 的常斜率线性函数）时 `Θ = 2c·C ≠ 0`，障碍**不**消失。
Lean：部分对应 `DLW.E.Theta3_eq_zero_of_w_eq_zero`；"零模是精确解"本身 unformalised（需分析）。
等级：`w ≡ 0 ⇒ Θ = 0` 为 **Lean 代数验证**；零模精确性为 **数学证明，尚未完整形式化**。

**结论 15（稳定性只可条件陈述；结构不消除阻碍）.**
半离散线性化色散 `(σ + i(u₀+2a)k)² = k⁴ − (v₀+2λ)k³/μ_h(ℓ)`，`μ_h → 1`，故每个相容格式都有 `|Re σ| ~ k²`（Hadamard 不适定，连续象征的性质）。
**明确不主张**：Hamiltonian/Poisson/辛结构消除该阻碍。本方向的结论更强：类 𝒞 中连括号都不存在。
结构（若存在）能买到：精确守恒量、结构保持、零模精确保持、障碍的显式刻画。
结构买不到：一致适定、网格一致稳定、`k²` 增长消除、任意初值收敛。
所有稳定性陈述条件化于：带限 `|k| ≤ K`、解析/带限初值、固定截断维数 `n`。线性化/有限带/非线性稳定性互不蕴含，本报告不证明其中任何一个。
等级：依据 spec §2（MAIN-VERIFIED V6）；**unformalised**。

## E. 明确开放（未论证）

**结论 16（开放范围）.**
未被否定的类：`Q = Q(w,v,…)` 场相关核（仅证明 0 阶情形下 `Q₁₂ = 0`，`(1,1)` 分块化为泛函方程 `w S(aφ) + a S(wφ) = 0`，一般场无解）；含 `∂_x^{-1}` 且系数依赖场的 `x`-非局域括号（最可能藏有真正 mKP 型结构，本方向未触及）；约束 Dirac 括号的其他配对。
等级：**unformalised / 尚未解决**。

**结论 17（其它缺口）.**
无稳定性/适定性/收敛定理；离散系统的非线性对数闭式未处理（属方向 G）；VT 的规范退化阻断括号推前（数学证明，未形式化）；未做独立文献检索，**不主张新颖性**。
等级：**unformalised**。

## 独立于方向的元结论

**结论 18.**
"相容性"不能挽救类 𝒞：离散障碍收敛到非零连续障碍（结论 10），因此"更高阶格式"与"保 Poisson"在本类中不相容。这是本方向最具方法论价值的一点：**先检验连续对象是否允许括号，再谈保结构离散化**。
等级：**数学证明，尚未完整形式化**（离散部分有 Lean/实验支撑）。
