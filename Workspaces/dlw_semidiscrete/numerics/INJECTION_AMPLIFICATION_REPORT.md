# 固定网格 SD：误差注入、传播放大与参数指导的配置选择

2026-09-23。本文把 SD 实际求解器相对**同一个有限 h Gram 精确解**的误差作为对象。空间区间 L=20，y 半宽 1.5；x 为四阶周期差分，时间为 RK4。除边界对照外，使用背景相对二次外推右闭合。本文的时间窗为 T=0.01；多孤子局部窗为 0.005。移动网格、FD 排名和长距离散射不在此次实验内。原生产求解器、Gram 公式、Lean 均未改。

## 1. 离散误差方程及可核对的分解

令 \(\bar Z_n\) 是有限 h Gram 场在实际固定网格上的状态，\(Z_n\) 从 \(\bar Z_0\) 出发，\(\Psi_n\) 是**实际的 RK4 一步映射**，包含四个内部级与随时间变化的解析边界数据。定义

\[
b_n=\Psi_n(\bar Z_n)-\bar Z_{n+1},\quad
M_n=D\Psi_n(\bar Z_n),\quad
q_n=\Psi_n(\bar Z_n+e_n)-\Psi_n(\bar Z_n)-M_ne_n.
\]

于是 \(e_{n+1}=M_ne_n+b_n+q_n\)；零初始误差时，线性响应 \(\ell_{n+1}=M_n\ell_n+b_n\)，实际误差与线性响应之差是已传播的非线性余项。状态输出始终通过同一闭合的 \(O_u,O_v\) 重构。下表的“原始注入”是 \(\|O_f\sum_n b_n\|_\infty\)，“线性响应”是 \(\|O_f\sum_n\Phi_{N,n+1}b_n\|_\infty\)；其比值记录**实际缺陷方向**的有限时间增益与抵消，既不是算子范数，也不是严格稳定界。另存每步输出范数之和，避免把有符号相消误称为注入变小。

按状态最外两行把每步 \(b_n\) 分为边缘与其余行，再分别通过相同的 \(M_n\) 传播。这是**注入位置诊断**：边界闭合会改变内部行和物理输出重构，因此边缘分项不能称作“纯边界误差”。两分项的最大范数也不能直接相加。程序逐步核对 \(\ell=\ell_{\rm edge}+\ell_{\rm interior}\)；18 条单孤子轨道的线性响应与实际误差的相对差均低于 \(10^{-3}\)。

## 2. 参数、x 分辨率和时间步如何改变两场误差

四个已有机制参数：P1=(4,1,2,3)，P5=(4,0.5,1,1.5)，P6=(4,1,3,4)，P10=(2,1.5,2,3.5)，顺序为 \((a,p,q,\rho)\)。固定 h=1/8、T=0.01、dt=0.00025；下表为二次外推闭合，数值取自 `out/injection_amplification/mechanism.json`。

| P1 | 128 | 4.79e-4 / 1.58e-4 | 5.11e-4 / 1.30e-4 | 1.07 / 0.82 | 2.30e-4 / 1.22e-4 |
| P1 | 256 | 3.48e-5 / 1.35e-5 | 3.77e-5 / 1.24e-5 | 1.08 / 0.91 | 2.30e-4 / 1.22e-4 |
| P5 | 128 | 3.11e-6 / 6.71e-7 | 3.14e-6 / 5.95e-7 | 1.01 / 0.89 | 5.98e-5 / 2.98e-5 |
| P5 | 256 | 2.02e-7 / 5.19e-8 | 8.40e-7 / 3.97e-7 | 4.16 / 7.64 | 5.98e-5 / 2.99e-5 |
| P5 | 512 | 6.66e-7 / 2.23e-7 | 4.12e-3 / 2.51e-3 | 6181 / 11248 | 5.98e-5 / 2.99e-5 |

P6 的 nx=128→256 主要削减注入，两场求解误差约下降 11.0/7.5 倍；继续到 512，注入继续下降，但响应/原始注入比增加，收益小于纯四阶外推。P10 在 h=1/8 的模型差比求解误差大一个到两个数量级，因此只加 x 对连续场总误差作用有限；其接近正则边缘的参数同时改变了波形、相位斜率和模型差，不能把差异归因于单个参数。P5 更强：nx=256→512 时原始注入的 u/v 数值约变成 3.3/4.3 倍，线性响应却增大约 4900/6300 倍。该区间的主导变化是有限时间传播，而非时间积分误差。

P5 补测 nx=384 与 512 的终点实际 u/v 误差分别为 2.46e-5/1.47e-5 和 4.12e-3/2.51e-3；512 点的 u 误差从 t=.002 的 4.04e-7 连续增长到 t=.010 的 4.12e-3。u 误差的 x 傅里叶最大分量在高半频带；512 点减半 dt 后终点变为 4.121e-3/2.513e-3，变化小于 0.1%。实际 RK4 切向的中心差分残差低于 2e-8，线性传播和实际非线性轨道吻合。**这验证所测轨道上的高频放大；未单独识别最初高频种子来自周期尾部不匹配、差分缺陷还是浮点舍入，也未给出一般非线性不稳定定理。** `p5_controls.json` 保存时间序列和步长控制。

边界闭合也显著改变注入：在 nx=128，原固定外侧 P/右幽灵闭合的 P1/P5/P6 的 v 误差分别为 2.15e-3/1.31e-5/1.48e-2；二次外推闭合为 1.30e-4/5.95e-7/1.00e-3，P10 却从 4.37e-3 变为 4.71e-3。这是**不同边界问题**的对照，不能叫作对原问题的等价修复。四组在二次外推闭合下 dt 减半，nx=128 的两场终点误差变化最大约 5e-12，当前短时窗并非由所选步长主导。

## 3. 已锁定规则与全新参数验证

规则在任何 H 参数轨道推进前由 `config_rule_lock.py` 写入 `locked_rule.json`，SHA-256 为 `fb4a8e882c7380ac8eed63818830c47228b8d0bdcd1091193d6309687214db9c`。新参数均不在 P1–P10 的谱参数组内：H1=(4.5,.9,2.6,2.2)、H2=(3.2,1.2,2.2,3.7)、H3=(2.3,1.65,2.4,3.4)、H4=(5.2,.65,1.2,2)。给定 T=.01、每场误差门槛为该场初始有限 h 峰值的 0.1%，只从 h∈{1/8,1/16,1/32}、nx∈{128,256} 中选择。

只计算解析有限 h 与连续场之差 \(C_f\)，以及 t=0 的物理输出缺陷 \(d_f=\|O_f(F(0,\bar Z_0)-\dot{\bar Z}_0)\|_\infty\)，预报保守量 \(\widehat E_f=C_f+1.5T d_f\)。系数 1.5 盖住 P1/P5/P6/P10 在 nx=128 和除已知 P5 放大异常外的 nx=256 样本；**P5 的异常被明确列作规则的排除区**。选择双场 \(\widehat E_f\) 都低于门槛且 `步数 × nx × 状态行数` 最小的候选。nx>256 要先做传播增益试探，不能按此规则盲目加密。该量是经验安全余量，不是数学上界；下文检验它在留出候选上是否真为上界。锁定文件只用了新参数的解析场和 t=0 缺陷，没有读取它们的数值轨道。

| 留出参数 | 锁定选择 h,nx | 基线双场最大门槛比 | 选择后最大门槛比 | 预测错误的候选 | 选择/基线工作量；实测中位耗时 |
|---|---|---:|---:|---|---:|
| H1 | 1/8, 256 | 0.872 | 0.226 | 基线其实通过 | 2.00；1.72 |
| H2 | 1/8, 256 | 1.228 | 0.552 | h=1/16、1/32 且 nx=128 其实通过 | 2.00；1.73 |
| H3 | 1/32, 256 | 7.608 | 0.497 | 无 | 8.26；4.12 |
| H4 | 1/8, 128 | 0.152 | 0.152 | 无 | 1.00；1.00 |

门槛比为 \(\max_f\|z_f^{\rm num}-z_{0,f}^*\|_\infty/(0.001 A_f)\)，其中 \(A_f\) 是该配置初始有限 h 场峰值；这是**相对连续精确场的总误差**，并非求解误差的两项范数和。24 个预列候选全部真实推进；4 个锁定选择都通过，两场预测保守量在 24 个候选的 48 个输出中均未被实际总误差超过，但“是否通过”有上述 3 个假阴性。H1 花了约 1.72 倍推进时间处理本来已通过的基线；H2 的 h=1/16,nx=128 也通过，单次耗时 0.189 s，低于锁定选择的 0.230 s，显示规则并非成本最优。H3 的 x 单独加密仍远不够，h 单独细化也未达到 v 门槛；两者必须同调。H4 不需加密。中位推进耗时来自基线/选择配置各三次顺序执行，其他候选只计一次。

`config_rule_cost.py` 另将**六个候选的全部特征计算**计入：四组各重复三次的中位诊断耗时为 0.114–0.119 s。诊断加所选推进相对只跑基线的实测时间比为 H1/H2/H3/H4 的 2.57/2.52/4.98/1.75；即使 H4 不需改配置，执行完整选择器也有成本。上述时间不含 Python 进程启动、报告写入或对候选进行真实验证的成本；对只做一次短时推进的任务，当前完整六候选规则**没有计算时间节约**。它的价值在于避免 H2/H3 的预定精度失败；若要主张成本净收益，需在多次同参数生产运行中摊销诊断，或先实现经留出验证的候选剪枝。参数是定向挑选的四例，不据此报告总体成功率。

### 3.1 改变目标时间的第二次锁定检验

保持同一 1.5 系数、候选网格、双场 0.1% 门槛和选择方法，仅把输入目标时间改为 T=.02；在任何新轨道推进前，`locked_time_rule.json` 锁定 H5=(3.7,.85,2.35,3.0) 选 h=1/8,nx=256，H6=(2.7,1.35,2.55,3.3) 选 h=1/16,nx=256。两者都是与训练、第一批留出不同的新谱参数组。锁定 SHA-256 为 `fb45a2bb4500353ea796693103da0e803b53099d5d2cb414633f8b6abd4a19c1`。

| T=.02 留出参数 | 基线最大门槛比 | 锁定配置最大门槛比 | 12 个候选中的通过/失败误判 | 实际误差超过预测量的候选 |
|---|---:|---:|---:|---:|
| H5 | 1.343 | 0.344 | 0 | 0 |
| H6 | 4.594 | 0.824 | 0 | 5 |

H6 锁定配置的实际 u/v 总误差分别为预测量的 1.258/1.056 倍；h=1/32,nx=256 更达到 1.87/1.49 倍。故 1.5T 初始缺陷公式在更长窗口**不是保守上界**，尽管此次两个配置分类建议仍正确。12 条轨道全部完成，但只有单次推进计时，不能以其秒数主张成本最优或总体成功率。时间变长后需要在决策前加入低成本的方向性传播探针，重新留出验证其诊断成本与预测收益；不能仅把当前系数调大后追认这两组结果。

这些结果给出实际使用顺序：先比较解析模型差与缺陷预算；若模型差已超过目标，优先缩 h，但要复核 x 求解地板；若初始 x 缺陷主导且已测增益温和，先增加每波宽 x 点数；若原右闭合的 v 输出占主导，可比较相容边界，但须承认边界问题改变；若如 P5 出现高频增益，就先测传播窗口或改变算法环节，不能继续盲目加 x；只有步长控制显著时才优先减 dt。该流程的量化门槛目前只在上述短时、二次外推、单孤子扇区经留出检验。

## 4. 多孤子迁移检查

对 N2=(p,q,ρ)=((1,2),(1,3),(3,4))，在 t0=-4、0、4 分别从**新的有限 h 精确状态**开始推进 0.005，h=1/4、nx=256；以着装相位匹配的 N1 为分离阶段控制。相同注入/传播递推给出：

| 窗口 | 最终 u/v 求解误差 | 传播响应÷原始注入 u/v |
|---|---:|---:|
| N2 分离前 | 6.214e-4 / 5.585e-4 | 1.684 / 1.030 |
| 匹配 N1 前 | 6.220e-4 / 5.592e-4 | 1.684 / 1.030 |
| N2 重叠 | 1.455e-4 / 8.845e-5 | 1.175 / 0.986 |
| N2 分离后 | 6.181e-4 / 5.592e-4 | 1.667 / 1.033 |
| 匹配 N1 后 | 6.187e-4 / 5.597e-4 | 1.667 / 1.033 |

N2 重叠阶段将 nx 提到 512，误差降至 1.01e-5/6.27e-6；传播比为 1.245/0.967。分离阶段与匹配 N1 的两场误差相差小于 0.2%，当前短时诊断没有发现额外的碰撞传播放大。所有窗口的非线性余项相对实际两场误差低于 0.1%。这些是独立局部窗口；不构成未重置的完整碰撞轨道、散射相移或长期稳定验收。原先连续轨道在碰撞前即未通过双场 1% 门槛。

## 5. 复现、检查及范围

在本目录顺序运行 `python -u experiments/injection_amplification.py`、`python experiments/config_rule_lock.py`、`python -u experiments/config_rule_validate.py`、`python -u experiments/amplification_controls.py`、`python -u experiments/injection_multisoliton.py`、`python -u experiments/config_rule_cost.py`、`python experiments/config_rule_time_holdout.py lock`、`python -u experiments/config_rule_time_holdout.py verify`、`python experiments/injection_validate.py`。**复核已冻结预测时，不应重跑两个 lock 入口覆盖其字节；直接从已存锁定文件开始验证。** 八份主 JSON 保存配置、失败/通过、数组归约、计时及源码哈希；`validation.json` 的 163 项检查包括源文件哈希、两个锁定文件哈希、逐点分解、切向差分、步长控制、匹配 N1 和较长窗口的预测量失效记录。没有把有限采样或代数递推提升为连续时间严格误差界。下一阶段如需移动网格，应先让原 DLW 固定网格双场轨道可信传播约一个波宽；这一步仍未完成。
