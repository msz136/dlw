# S1–S4 的方程缺项（供接手 Agent）

这不是“实验失败”或“误差为零”。当前 `numerical_analysis.html` §2.4 尚未定义这四个方法。本次数据只能补齐数学定义已固定的 S5/S6，不能声称六组合表已经全部完成。

## 为什么不能直接替换网格速度

已有原可积系统固定质量参数 a，满足

\[
d_k=x_{k+1}-x_k,\quad v_k=u_{k+1}-u_k,\quad r_k=a/d_k,
\qquad \dot d_k=-v_k.
\]

网格运动的几何恒等式则为 \(\dot d_k=V_{k+1}-V_k\)。因此保留原系统时，必有

\[
V_{k+1}-V_k=-(u_{k+1}-u_k),\quad V_k=-u_k+b(t).
\]

- **固定网格** V=0 与此兼容，仅当各节点 u 相同；这里的非平凡单孤子不满足。
- **Rm 网格** \(V=-u-(\rho-1)/(2R_m)\) 与此兼容，要求附加速度在空间上为常数。当前单孤子的附加速度在波区与远场不同，并非该情形。

这是对“保持原方程只换速度”的明确障碍；**不是**对所有可能的新可积固定/Rm网格系统的不可能性证明。

## 缺失的不只是一个速度公式

连续密度满足 \(\rho_t=(u\rho)_x\)。任意运动胞元的质量为

\[
a_k(t)=\int_{x_k(t)}^{x_{k+1}(t)}\rho(x,t)\,dx,
\qquad
\dot a_k=[(u+V)\rho]_{x_k}^{x_{k+1}}.
\]

原生速度 V=-u 令该通量为零；固定网格或 Rm 网格一般不能让各胞元质量恒定。离散层面原式的 \(a=r_kd_k\) 正是固定质量标签，不能在更换运动法则之后照搬。否则例如固定 d 且固定 a 会强迫 r 不随时间变化，与一般密度演化冲突。

一般 ALE 的场导数还必须带上输运项：

\[
(\partial_t+V\partial_x)\rho=(u+V)\rho_x+\rho u_x.
\]

仅添加连续链式法则项可以启发一个新的数值格式，但不会自动证明有限格距下可积。原校准 \(C=a+\sqrt{1+a^2}\) 也依赖同一个固定质量步长；换成可变胞元质量后，必须重新推导修正方程及误差系数。

## 接下来若确实要四格都有数值

须先给出这四个新系统的闭合右端、变量/网格映射、初边值、连续极限和校准定义，再核对可积结构并做误差实验。若采用未经可积性证明的 ALE 改造，则应明确另命名为“可积式启发的 ALE 格式”，不能仍把它当作已经验证的原/校准可积系统。把旧原生网格解插值到固定或 Rm 节点只改变输出位置，不能充当这些节点上的时间演化。
