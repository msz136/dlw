## 第 0 部分 · 主控跨方向结论（M 系列）

### M1 — 不适定性在 `y` 离散下不变（**本次运行的核心结果**）

常数背景线性化，`∂_y` 被任意一致离散算子（完整符号 `Λ_h(ℓ)`，`Λ_h → ℓ`）替换后：

```
[ σ + i (u₀+2a) k ]² = k⁴ − (v₀ + 2λ) k³ / Λ_h(ℓ)
```

* `k⁴` 系数**恒为 1**，与 `Λ_h` 无关；
* 固定 `Λ_h ≠ 0`、`|k| → ∞`：`|Re σ| / k² → 1`。

**范围**：六个具体一致符号（中心、前向、后向、交错、P1 一致质量 FEM、谱）全部验证。
**边界**：`Λ_h = 0`（中心差分与 P1 FEM 在 `ℓh = π`）是退化波数，本结论不适用，需独立 DAE 分析。
**等级**：**Lean 代数验证**（消元恒等式 `semidiscrete_elimination`）+ **Lean 分析验证**
（`growth_lower_bound`、`growth_unbounded`）+ `实验验证`
（`experiments/MAIN_discrete_dispersion.py`，D1–D5 全通过）。
**未形式化**：从"线性化模增长"到"非线性 Hadamard 不适定"的桥接。**全项目通病**。

### M2 — 唯一干净的正面条件结论

当 `v₀ = −2λ`（即 `λ = −2` 时 `v₀ = 4`）时，`k³` 项系数**恒为零**，离散色散关系
对**每一个**格点符号、**每一个**模、**每一个** `h` 精确等于连续色散关系（`D² = k⁴`）。

**范围**：所有六个符号。
**边界**：这是"离散不比连续更坏"，**不是稳定性定理**；连续问题本身仍不适定（M1）。
**等级**：`实验验证`（+ `数学证明，尚未完整形式化`）。

### M3 — 精确零模 / 非唯一性

`v ≡ −2λ` 且 `u = U(x,t)` 任意（`u_y = 0`）是 (1)(2) 的**精确**解；`λ = −2` 时为 `v₀ = 4`。

**等级**：`实验验证`（V7 PASS）。

### M6 — 交错双 tau 构造在 `N ≤ 5` 上精确成立

`C_S = Π_{i∈S} 1/(p_i+q_i) · Π_{i<k} (p_i−p_k)(q_i−q_k)/((p_i+q_k)(p_k+q_i))`，

**边界**：**任意 `N` 的行为未证明。** 全符号 `N = 2` 检查（V8）在本次会话**未跑完**。

### 否面结论（**本方向最重要**）

**C1.** P1 一致质量（及中心差分）的 `μ_h` 在 Nyquist **确实为 0**：`μ_h(π/h) = 0`。
该零**不来自质量矩阵**（`2+cos θ ∈ [1,3]` 处处非零，`det = h²/12 ≠ 0`），而来自**分子中的中心差分模板** `sin θ`。
后果：`D_h` 有由交错向量 `(−1)^j` 张成的**虚假核**，半离散系统退化为 DAE；
退化模上出现**虚假 O(1) 增长模**（`u₀=.4, a=.7, λ=−2, v₀=1.1, k=1.3` 时 `Re σ = ±1.604`）。
⇒ 提示中"FE/DG 符号无 Nyquist 零"对 **P1 一致质量为假**，仅对 **DG 迎风为真**。
**等级**：`Lean 结构验证`（`muP1_nyquist_zero` 否面、`dg_symbol_no_nyquist_zero` 正面）。
**主控独立复核**：手算确认 P1 迁移矩阵即中心差分，`M` 符号 `(h/3)(2+cos θ)`，
故 `M^{-1}A` 符号 `= i·3 sin θ/(h(2+cos θ))`；并用 SymPy 独立验证 `R(π) = 0`。**一致**。

**C2.** **FEM 特有非局部性**：`(M_h^{-1})_{jk} = (√3/h)Σ_w r^{|j−k+wN|}`，`r = √3 − 2 ≈ −0.2679`
⇒ **稠密全耦合**。只能**条件性闭合**（指数截断误差 `0.268^{m+1}`；或 Neumann 级数
`M = h(I+(h²/6)Δ)`，截断 `M` 项 ⇒ `(2M+1)`-带状，算子范数误差 `≤ (3/h)(2/3)^M`）。
反之 **P0 DG 完全局部**（`M = hI`）。
**等级**：`实验验证` + `Lean 结构验证`。

**C3.** **VT 在离散层不可行**：`ln ∘ 插值 ∉ V_h`（投影须解 `MU = b`，节点对数导数不等价）；
P1 的 `Aᵀ` 在 Nyquist 使约束 `w = u_y` 不可解；双线性恒等式**非投影不变量**。
唯一正面点是 P1 保正性使逐点 `ln` 良定义。**离散层无双线性/tau 解族。**

**C4.** 连续极限正确（`h→0` 得 (1)(2) ⇒ 论文 (6)(7) 在 `λ=−2`）。

**路线状态：`条件可行`**（须用 DG 迎风或集中质量避开 P1 的 Nyquist 虚假核；须带限制/固定截断；
VT 仅在连续极限层）。**证明覆盖度：`Lean 结构验证`**。
**推荐变体**：**DG 迎风**（无 Nyquist 零、约束精确可解、`M = hI` 完全局部），代价是 1 阶精度。
