## 2. 主控核心成果：不适定性在 `y` 离散下的不变性

### 2.1 结论

设 `∂_y` 被任意一致离散算子替换，其**完整符号** `Λ_h(ℓ)`（`Λ_h → ℓ` 当 `h→0`）。
则常数背景线性化给出

```
[ σ + i (u₀+2a) k ]² = k⁴ − (v₀ + 2λ) k³ / Λ_h(ℓ)
```

* `k⁴` 系数**恒为 1**，与 `Λ_h` 无关；
* 对固定 `Λ_h ≠ 0` 与 `|k| → ∞`：`|Re σ| / k² → 1`；
* 六个具体一致符号（中心、前向、后向、交错、P1 一致质量 FEM、谱）全部通过该检验；
* `v₀ = −2λ`（`λ=−2` 时 `v₀ = 4`）时 `k³` 项**恒消失**，离散色散与连续**精确一致**。

**因此：隐式格式、守恒格式、SBP 耗散、FEM/DG 质量矩阵、辛/多辛结构，没有任何一种
能消除该障碍。** 这是一个**否面结论**，而且是结构性的：不适定性是连续 `x` 符号的性质，
而 `y` 离散只作用于 `y`。

### 2.2 Lean 形式化边界（必须说清）

`proofs/MainNoGo.lean` 形式化了：

* `semidiscrete_elimination`：`E1 = 0 ∧ E2 = (I·μ·û/k²)·charFun`，其中
  `charFun D k μ λ v₀ = D² − k⁴ + (v₀+2λ)k³/μ` — **Lean 代数验证**；
* `growth_lower_bound`：`k²/2 ≤ √(k⁴ − c k³/μ)`（当 `c ≤ 3kμ/4`）— **Lean 分析验证**；
* `growth_unbounded`：`∀ M, ∃ k>0, M < √(k⁴ − c k³/μ)` — **Lean 分析验证**。

**未形式化的桥接（必须显式声明）**：
"线性化模以 `~ e^{k²t}` 增长 ⇒ 非线性初值问题 Hadamard 不适定"这一步
**没有**在本运行中形式化。它是标准的（线性化不适定 ⇒ 不适定），但按用户要求，
不得把"Lean 里有一串通过的定理"读成"整个不适定性命题已在 Lean 中证明"。

另外 `growth_dichotomy` 只证明了 `Re σ = 0` **或** `(Re σ)² = R`；
**未**证明增长支确实被取到（`∃k` 的存在性）——这是已知缺口。

## 3. 主控自己犯过并修正的错误（如实记录）

> 这一节是本文件最重要的部分之一。**三个缺陷都在主控侧**，
> 其中 §3.2 若不发现，会让本项目对 workspace 既有结论作出**虚假否定**。

### 3.1 缺陷一：色散关系 `μ` 的归一化约定混淆

**现象**：方向 C 报告 `(σ+iAk)² = k⁴ − i(v₀+2λ)k³/μ_h(ℓ)`，主控 `D2` 检查使用
`(σ+iAk)² = k⁴ − (v₀+2λ)k³/Λ_h(ℓ)`。表面上矛盾。

**诊断**：不矛盾，只是 `μ_h` 的定义不同。方向 C 取 `μ_h := iΛ_h`（复符号，`→ iℓ`），
主控取 `Λ_h`（完整实/复符号，`→ ℓ`）。代入 `μ_h = iΛ_h` 后两式完全相同。

**处理**：在 `common/SHARED_MATH_SPEC.md` **§2.0** 中钉死三种等价写法
（`Λ_h`、`r_h = Λ_h/ℓ`、`μ_h = iΛ_h`）并明令"任何下游结论不得混用"。
同时修正 `experiments/MAIN_discrete_dispersion.py` 中 `D4` 的标签
（原先 `D2` 用完整符号、`D4` 用归一化符号却共用名字 `mu_h`，属真实隐患）。

**教训**：同一个符号在两处指不同对象，是跨方向整合中最容易产生假矛盾的地方。

### 3.2 缺陷二（**最严重**）：残差分组用错了等价的判据

**现象**：V9 报告 `N=1..5` 共 **680 个非零残差**，`N=1` 通过而 `N≥2` 全部失败，
且同一个 2-指标项 `(0,1)` 的残差 `805/551` 在 `N=2,3,4,5` 中**重复出现**。
这看起来像"交错双 tau 系统从 2-孤子起就是错的"。

**诊断（主控手算复核）**：V9 把残差按 `(dk, dw) = (Σk_F − Σk_G, Σω_F − Σω_G)` 分组。
但双线性展开的每个**单项式** `E_1^{m_1}…E_N^{m_N}` 必须**整体**为零；
同一个单项式会被**多个** `(SF,SG)` 对以**不同** `dk` 贡献
（例如 `((), (0,))` 给 `dk = −k₀`，`((0,), ())` 给 `dk = +k₀`，二者**同属** `E_0E_1` 项）。
按 `(dk,dw)` 分组把**一个**单项式拆成几块，必然产生**伪非零**报告。

手算 `N=1`：残差 `= (1/k)[k²−ω−2sk] + (rr/k)[k²+ω+2sk] = 2(p−s) + 2·(−(p−s)/(q+s))·(q+s) = 0` ✓，
证实分组方式（而非构造）才是问题。**V8 使用的是正确的并集单项式分组**
（`key = (m.count(1), m.count(2))`），故 V8 与 V9 的分组方式不一致。

**处理**：V9 改为 `key = tuple(sorted(SF + SG))`（并集多重集）。

### 3.3 缺陷三：`C_S` 重复计入 `1/(p_i+q_i)` 因子

**现象**：修正 §3.2 后 `N=1` 两个方程均通过，但 `N≥2` 仍然失败。

**诊断**：主控直接读取 workspace 原始构造
`lean-toda/dlw_staggered_construction.md` §4：

```
C_S = Π_{i∈S} 1/(p_i+q_i) · Π_{i<k} (p_i−p_k)(q_i−q_k) / ((p_i+q_k)(p_k+q_i))
```

而 V9 的 `Gamma(S)` 里写的是
`(p_i−p_k)(q_i−q_k) / ((p_i+q_i)(p_i+q_k)(p_k+q_i)(p_k+q_k))`，
即**多除了** `(p_i+q_i)(p_k+q_k)`。由于 `coef_side` 之后**又**乘了 `Π 1/(p_i+q_i)`，
实际相当于多算了 `Π_i (p_i+q_i)^{|S|−1}`。
这正好解释"`N=1` 通过、`N≥2` 的 2-指标项失败"——
因为 `|S|=1` 时该多余因子为 1，`|S|=2` 时多出一个 `(p_1+q_1)(p_2+q_2)`，
而 `|S|=2` 的相互作用系数恰在 `N=2,3,4,5` 中都是同一个，故残差重复出现。

**处理**：`Gamma(S)` 改为只返回 `Π_{i<k} Γ_{ik}`，`Γ_{ik} = (p_i−p_k)(q_i−q_k)/((p_i+q_k)(p_k+q_i))`。

**修正后结果**：

```
[PASS] V9  staggered tau family: exact rational N=1..5 x 4 parameter sets,
       2904 coefficients, all zero, arbitrary theta constants a=1..3, h in (0,1/2)
```

**⚠ 结论性教训**：修正后 workspace 的交错构造**在 `N=1..5` 上通过了精确有理数检验**。
若主控停留在第二次失败、不去读原始构造就下结论，本项目将**错误地否定**一个正确结果。
这是"必须核对原始来源、不得信任转录"这一硬规则在**主控自己身上**的实例。

### 3.4 缺陷四：主控 F 方向实验的两处期望值写错（非数学错误）

1. 曾断言"P1 一致质量符号在 Nyquist 非零"——**错**，为 0。
   修正后该结论**支持**方向 C 的 `muP1_nyquist_zero`。
   主控另行手算确认：P1 迁移矩阵即中心差分 `(u_{j+1}−u_{j−1})/2`，

### 3.5 缺陷五：V4 采样撞上**奇异参数** `p_i = a`

**现象**：V4 报告

```
N=1 p=[5]      q=[2]:   eq6=True  eq7=True  eq1=True  eq2=True
N=2 p=[1, 2]   q=[3, 5]: eq6=False eq7=True eq1=False eq2=False
```

表面上"论文的双线性系统从 `N=2` 起不成立"——这会是**重大**否定结论。

**诊断（主控逐条核对 PDF 原文）**：主控直接读取 `pdftext/PhysD.txt` 第 113–227 行，
逐项确认 V4 的实现是**忠实**的：

* 论文 (6)：`[D_y(D_x² + D_t + 2aD_x) + 2λD_x]f·g = 0` ✓ 与 V4 的 `DyB` 逐项一致；
* 论文 (9)：`(D_{x_{-1}}(D_x² − D_{x_2} + 2aD_{x_1}) − 4D_{x_1})τ_{n+1}·τ_n = 0`；
  在 `x_{-1}=y, x_1=x, x_2=−t` 下 `−D_{x_2} = +D_t` ✓，且 `λ=−2` 时 `2λ = −4` ✓；
* 论文 (14)(15)：`ξ_i = p_i x_1 + p_i²x_2 + x_{-1}/(p_i−a) + ξ_i0`、
  `η_j = q_j x_1 − q_j²x_2 + x_{-1}/(q_j+a) + η_j0`；
  代入 `x_2 = −t` 得 `−p_i²t` 与 `+q_j²t` ✓ 与 V4 一致；
* 论文 (13)：`m_ij^{(n)} = c_jδ_ij + (1/(p_i+q_j))(−(p_i−a)/(q_j+a))^n e^{ξ_i+η_j}` ✓；
  主控并**手算验证**了 Lemma 2.1 的秩一关系
  `m_ij^{(n+1)} = m_ij^{(n)} + φ_i^{(n)}ψ_j^{(n+1)}` 确实成立
  （两边相减得 `(1/(p_i+q_j))γ^n(γ−1)` 与 `−γ^n/(q_j+a)`，而

**真正的原因**：论文 (13) 含**奇异位移** `p_i − a` 与 `q_j + a`

`N=2` 抽到 `p=[1,2]` 而 `a = 2`，于是 **`p_2 = a`**，
使 `y/(p_2−a)` **除零**、`γ_{2j} = −(p_2−a)/(q_j+a) = 0`，`τ` 退化 ⇒ (6) **理应**不成立。
即"`N=2` 失败"是**采样缺陷**，不是论文的缺陷，也不是 V4 实现本身的缺陷。

**处理**：为 V4 加护栏 `p_i ≠ a`、`q_j ≠ −a`。修正后 `N=1` 仍 PASS；
`N=2` 的符号计算很慢，已移至后台单独运行（`proofs/v4_output.txt`）。

**⚠ 与 §3.2–§3.3 同一类教训（第二次）**：**再次**是主控自己的**校验器**（而非被检对象）
