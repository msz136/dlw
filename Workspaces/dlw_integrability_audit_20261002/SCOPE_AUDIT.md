# DLW 可积结构的对象范围核对

2026-10-02。只读核对既有证明与报告；本文不报告新实验或新 Lax 定理。未改根报告、原代码及共享进度记录。

## 1. 当前能够成立的判断

当前 DLW 有**明确可积结构支持的 y 半离散系统**：两壁双线性对、一般双线性解的 Darboux 交织、任意 N 纯 `(x,t,j)` Gram 解、精确谱波函数及非平凡谱渐近比。这里 x、t 仍连续。可以把它称为“具有已证 Gram/Darboux 结构的可积半离散构造”，但不应省略结构与对象范围后写成“一般初值的 S 可积性已经完整证明”。

后续的 x 四阶中心差分、Euler/RK4 时间推进、共同 x 守恒密度网格及间歇重映射，各是额外步骤；尚无证据把完整实际算法称为已证可积全离散或可积自适应离散。没有这些证明也不能反过来推出不可积。

| 对象 | 当前已证或已明确推导 | 未覆盖范围 |
|---|---|---|
| 两壁双线性对 `B_(a-h/2) F_j·G_j=0`、`B_(a+h/2) F_j·G_(j+1)=0` | 有限 h 精确结构；任意 N Gram 实例；正谱数据域内 τ 全实域正则 | 任意连续双线性解直接采样后满足有限 h 方程；一般初值 IST |
| SD：Report (7)，或等价物理 (8) | 由共同双线性起点精确推出；一般局部开链可模积分自由度反向重构；精确守恒律 | 任意边界/平均模态下全局双射、唯一演化；实际 x/t 离散后的谱保持 |
| SDR：Report (21)、物理重构 (22) | 同一个双线性起点精确推出 Q/R/M 演化及格点约束；恢复同一个 u/v | 任意数值 Q/R/M 状态均与 SD 唯一等价；任意离散边界下动力可投影 |
| 显式 Gram 谱构造 | 任意 N 谱波函数满足时间与格点线性关系；归一化渐近比 `∏(z-p_i)/(z+q_i)` 与 t/j/h 无关 | 一般场 Jost 解存在唯一性、散射数据完备性、直接/逆变换及一般初值重构 |
| SD/SDR + x 差分 + RK4 | 已有局部一致性、时间阶、表示缺陷和有限实验 | 与实际推进等价的离散 Lax 相容条件、谱不变量或可积时间映射 |
| 守恒密度共同 x 网格 | 密度/通量守恒推导；正分支上的坐标依据；几何与短时全耦合实验 | 一般轨道密度正性；完整双线性/谱结构在非均匀 x 离散、RK4及重映射后的保持 |

主要依据：`S_INTEGRABILITY_STATUS.md` §§1–6；`GRAM_INTEGRABILITY_REASSESSMENT.md` §§3、7、8；`NONLINEAR_CLOSURE.md` §5；`theory_results.html` 的 L02–L05、D04、D10、D14。

## 2. Report (7)/(21) 的真实证明方向

`Workspaces/lean_contracts/proofs/ReportEndpoints.lean` 明确将三个命题区分为：

- `Report7`：两条 u/ω 残差为零；
- `Report21`：Q/R 两条演化残差为零，以及 `(M_(j+1)-M_j)/h+Q_jR_j=1`；
- `Report22`：物理场的全部重构恒等式。

`bilinear_to_report7`、`bilinear_to_report21_22` 和 `bilinear_to_both` 的共同前提是 h≠0、F/G 满足 `SmoothL`、F/G 全实域正，以及 `SemiPair a h F G`。导数是实际实函数导数，格点为全部整数 j；证明中的 x/t 没有替换为中心差分或 RK 步进。当前根页面将 `SmoothL` 的 `ContDiff ℝ ⊤` 正则性表述为联合实解析。

这些端点证明的是“同一个双线性解推出两种非线性表示和相同物理场”。它们没有证明任意 SD/SDR 数值状态的全局坐标双射、任意初边值问题的解存在唯一性或一般逆散射。`dlw_bilinear_nonlinear_lean.html` 的标题及正文也是前向非线性化命题，没有给出这些更强结论。

还应注意，F/G 正只直接保证 Q 正。定义 `R=(1-ω/h)/Q` 本身不能替代网格密度 `Q R=1-ω/h` 的一般正性证明。

局部反向重构实际包含三个步骤：格点递推重构 β_x 和 α_x；共同势变换消掉与 j 无关的残差；依赖 t 的层间规范消掉剩余 A_j/C_j。周期或指定衰减边界可能禁止这些自由选择。因此不能把局部重构升级成任意边界下全局等价。实际中心 x 导数还有已成立的偶数周期棋盘模态非单射反例（D10）；它目前只证明重构在全状态空间不单射，并没有证明隐藏模态增长或实际开链边界必然失败。

## 3. 已有 Darboux 与谱证据应如何解释

设 `V_j=2(log G_j)_xx`、`H_j=∂_t+∂_x²+V_j`，并从两壁种子定义 `T_j^±=∂_x-w_j^±`。一般双线性对给出

`H_j^F T_j^-=T_j^- H_j`，`H_j^F T_j^+=T_j^+ H_(j+1)`，以及 `T_j^+ ψ_(j+1)=T_j^- ψ_j`。

它们不是仅在有限几个孤子点拟合出来的矩阵；任意试探 ψ 的交织障碍是归一化双线性残差的 x 导数。物理格点关系为

`[∂_x-a-u_j/2+h(W_j-4)/8]ψ_(j+1)=[∂_x-a-u_j/2-h(W_j-4)/8]ψ_j`，`W=v-δ₀u`。

时间势 V 的物理重构需要相应积分自由度与规范。这是从“有形式相容结构”推进到“指定一般场及边界的谱问题”首先需要补上的具体环节。

任意 N Gram 波函数进一步采用独立 z、与背景 Möbius 格点色散匹配的归一化，得到非平凡谱渐近比。波函数中的平面波规范可以让 z 从部分算子系数消失，却不能单凭这一点抹去边界归一化中的谱信息。另一方面，有限 N（即便 N 任意）的显式孤子族也不等于一般场散射变换的完备性。

旧 `lax/VERDICT.md` 的指定无谱矩阵乘积，以及未核验周期端点的开链乘积，都不能作全系统不可积证据。旧“只是弱 Lax/S 可积”、由 Painlevé 失败决定可积分类等标签也不应继续沿用。

## 4. 替代离散化并没有扩大已证的一般谱范围

`ALTERNATIVE_DISCRETIZATIONS.md` 给出的局部族取 `s_±=a+c h²±(h+κh³)/2`，精确格点乘子由 `γ(s_-)/γ(s_+)` 决定。它保留任意 N Gram 两壁恒等式及二阶连续极限；若允许重命名有效中心和格距，属于原交错机制的重参数化。它证明固定物理 a/h 下系数并非无条件唯一，不等于已经建立新的不等价可积层级或一般初值 IST。

只有固定两壁 s_±、固定 Gram γ、固定 B_s 和 F/G 模板后，单孤子系数才唯一决定格点乘子。非局部 `log T` 对照则只在指定指数/解析采样类和对数分支上精确；不能将它作为任意格点初值的独立局部可积系统。

## 5. 守恒密度 x 网格的准确对象

现有半离散 W 守恒律给出

`r_j=1-W_j/4`，`q_j=(u_j+2a)r_j-r_(j,x)-2a`，`r_(j,t)+q_(j,x)=0`。

以固定横向权重取共同 `𝓡=Σ w_j r_j`、`𝓠=Σ w_j q_j`，在 `𝓡>0` 的分支可定义共同守恒坐标。固定左端规范时的微分形式是 `dξ=𝓡 dx+(-𝓠+𝓠_left)dt`，故物理节点速度是 `(𝓠-𝓠_left)/𝓡`。这首先是 x 连续时的 reciprocal/ALE 坐标变换；正则可逆坐标变换本身不会自动丢失已有形式结构。

当前数值实现则还采用非均匀 x 导数、各 RK4 级当前场驱动的网格演化，以及某些方案的样条重映射；这些额外离散步骤尚未被完整 Lax/双线性证明覆盖。`MOVING_MESH_REPORT.md` §§1、5 和 `MOVING_MESH_ROUTE1_REPORT.md` 均明确保留这一限制。FD 共用同一监控密度的实验也不能解释成 FD 自动满足 SD 的精确离散守恒律。

2HS 原文流程提供的参照是：新双 τ 表达 → 空间离散及约化 → 离散 reciprocal 变换 → 同时包含场和物理网格的半离散方程 → Lax 核验。它的可积标签覆盖论文的完整空间半离散构造；后加 Euler/RK4 也不能自动得到全离散可积性。本项目 DLW 已有前面的双 τ/半离散结构和守恒坐标来源，缺的是把选定离散网格/场方程与对应相容结构接起来，而不是再收集更多精确孤子图片。

## 6. 可立即开展的最小检验目标

建议先完成以下前两项，再依据剩余残差决定是否另建可积 x/时间离散；无需先启动完整 IST 工程。

1. **一般场相容障碍。** 以实际 W/u、V 的重构及一套明确开链/衰减或周期规范，写出上述时间—格点算子的相容残差。要求对任意试探 ψ 的各微分系数，证明障碍恰由 N1/N2、约束及规范残差组成；反向允许哪些积分自由度要一并说明。可先用符号恒等式核验，不能仅在 Gram 族测试。这样可把已有 Darboux 证据明确提升到“指定物理场与边界的正式 Lax 表述”，尚无需宣称 IST 已建立。
2. **共同守恒坐标的相容关系。** 仍保留 x/t 精确微分，在共同 ξ 坐标中代入 `∂_x=𝓡∂_ξ`、`∂_t|x=∂_T|ξ+(𝓠_left-𝓠)∂_ξ`。检验时间—格点相容障碍新增项是否恰为 `𝓡_t+𝓠_x`，并声明固定权重、共同坐标、密度正性和左端规范。它只核对连续 reciprocal 变换，避免把任何非均匀数值导数提前认作精确 Lax 离散。
3. **定位实际推进破坏结构的那一步。** 在同一有限 h、同一边界，分别测 x 差分前后交织残差、单步 RK4 前后候选谱量漂移、移动/冻结以及重映射前后的增量。首先从非 Gram 的小幅平滑数据做一般相容残差核验；周期迹量只有在周期场和端点时间算子真正相容时才使用。零残差才支持精确结构，随步长收敛的残差只支持近似保持。这是小规模诊断，不是要求立即重写整个求解器。

数值可积性检验还应与误差检验分开：x 高频有增长支，不可从精确孤子或低谱漂移直接推出一般初值稳定、长时精度或自适应优势。
