# 下一阶段建议：求解误差机制、参数预测与算法选择

2026-09-23。本文是研究规划，不是新增实验结论。本轮阅读最新专题、理论推导和存档记录，重新运行 `experiments/route2_validate.py`，76 项检查通过；没有重跑数值轨道或 Lean。建议以固定网格误差机制为主线，移动网格保留为有条件恢复的支线。

## 1. 当前证据支持的判断

| 方向 | 已有结果 | 下一步仍缺什么 |
|---|---|---|
| SD/FD 多孤子 | SD 对自身有限 h Gram 流形有更好的短时贴合；进一步加密 x 后区别明显 | 共同连续问题上的一般优势、可信的完整数值散射 |
| 总误差 | 未发现统一 SD/FD 胜者；不同参数、场和扰动方向可反转 | 能事先预测优势区域或选取算法的机制模型；目前也未证明二者误差等价 |
| 模型/求解分解 | SD 的有限 h 精确族使两项可以分别核对；已做留出 h 和留出参数预测 | 求解误差的来源、方向与有限时间放大；超出精确族时的可用诊断 |
| 固定/移动网格 | 初始重分布有短时收益；受控输运中移动有长距离收益 | 原 DLW 的准确传播窗口太短，尚未验证长距离移动收益 |

误差分解的加减恒等式本身并非 SD 独有。SD 的价值是拥有可计算的有限 h 精确参照，使某些解族上的模型误差和求解误差能够独立验证。FD 也可理论分解，但当前不能把 SD Gram 场当成 FD 自身的有限 h 真解。

移动与冻结短时接近是所测条件下的结果，尚不是数学等价。受控输运的三组参数跨三档 x 分辨率通过实用幅度门槛，是确定性数值证据；现阶段 DLW 的主要缺口是目标方程上的准确长距离轨道，增加统计重复不能补上这个缺口。

## 2. 主问题与优先级

主问题：给定系统参数、边界、网格和目标传播距离，能否在低成本试跑后，预测两场误差的主要来源、可信传播窗口，以及下一份计算预算应该投入哪里？

建议资源分配约为：误差注入与传播放大 60%，参数留出预测及算法决策 25%，多孤子迁移检验 15%。这是执行优先级，不是工期承诺。移动网格暂不新增大规模扫描；保留已有实现、数据及失败结果。

已有路线二不能从头重复：初始缺陷预测、保守 K/C 界、短时受迫线性化、RK4 离散伴随均已存在。真正的新工作是解释这些方法何时有效、何时失效，并用预测选择改进。

## 3. 阶段 A：固定网格的误差注入与放大

### A1. 固定参照和误差定义

先研究 SD，从有限 h 精确初态启动，以同一有限 h 精确场为参照，避免把模型误差混入求解误差。对于共同连续初值另作方法比较；初值与有限 h 参照不一致时，保留初始误差及其传播，不能沿用零初始误差公式。

沿有限 h 参照状态 Z̄(t)，采用实际一步映射 Ψ_n：

    b_n = Ψ_n(Z̄_n) − Z̄_(n+1)
    M_n = DΨ_n(Z̄_n)
    q_n = Ψ_n(Z̄_n+e_n) − Ψ_n(Z̄_n) − M_n e_n
    e_(n+1) = M_n e_n + b_n + q_n

这是实数运算下的离散递推恒等式；浮点实现需记录闭合残差。q_n 是实际轨道上的后验量，不能当成事先可用的预测输入。已有伴随实验主要以连续背景定义 b_n，需明确改成有限 h 背景后所解释的对象。

### A2. 将注入与放大分开测量

按时间推进线性响应，分别记录初值贡献、每步 b_n 的传播贡献、非线性余项和闭合残差。内部与边界行的缺陷可按明确投影分组；若同一步含多个算法机制，不能仅凭其位置命名为纯空间或纯边界误差。

研究 Φ_(N,n+1)=M_(N−1)…M_(n+1)，比较实际缺陷方向上的响应与固定物理权重下的有限时间增益。小网格用完整矩阵，大网格沿用切向/伴随作用，避免扩展完整雅可比。涉及状态范数时固定归一化，最终统一报告 u/v 物理场指标，防止状态变量缩放制造放大差异。

关键区分：瞬时缺陷小，不代表最终误差小；特征值增长率也不等于所有有限时间放大。孤子背景随时间变化，冻结矩阵和零背景谱只能作对照。若怀疑非正规瞬态放大，先用传播增益验证，不能预先作因果结论。

算法机制用受控干预识别：固定模型和边界改变 x 算子；固定空间实现改变时间步；边界变化单列为不同闭合问题。保留交互项，不把不同算法的误差范数差当成可加的纯机制贡献。解析背景缺陷修正仅作诊断及非零扰动对照，零背景保持本身不能证明算法更准确。

### A3. 第一批最小实验

选择 P1、P5、P6、P10：一般背景、初始缺陷预测异常背景、已知求解误差主导背景、近正则边缘背景。先固定现有二次外推闭合；原闭合作机制对照。

| 变量 | 建议安排 | 用途 |
|---|---|---|
| h | 先固定 1/8，再以 1/16 检查关键结论 | 避免一开始混入多方向加密 |
| x 分辨率 | 128、256、512，记录每波宽点数 | 看缺陷下降和传播增益是否相互抵消 |
| 时间 | 从现有短时窗开始，逐步延长至首次精度失败 | 找到预测失效与场误差失效的先后关系 |
| 时间步 | 代表配置减半；只有影响显著才扩展 | 已有结果显示当前短时误差通常不由时间步主导 |
| 诊断 | 全域与固定内部区域双场误差、误差频谱、位置/形状、源项响应 | 同时定位空间位置、频率与物理输出 |

频谱诊断优先采用均匀固定网格；全域误差为验收主指标，内部指标用于定位，不能删去边界宣布通过。用细化观察时刻估计首次越阈时间区间，避免把离散观察点当精确临界时间。

预先建议的验收：在双场各低于初始峰值 1% 的观察窗内，线性传播预测对两场误差量级的相对偏差不超过 20%，并能解释最大误差区域；接近零的量使用预定绝对容差。该阈值是研究设计，非定理。若不满足，查明非线性余项、时间离散或浮点残差何时变得重要，不继续外推。

交付：误差来源与传播放大的分项图；P5 类异常的解释或明确未解释结论；可信预测时间窗。必要时再增加高精度对照，区分截断误差与舍入误差的放大。

## 4. 阶段 B：参数关系与真正的留出预测

把参数效应组织为可解释因素，而非扩大原始参数表：

- 正则性裕量 min(a−p−h/2, q+a−h/2)，必要时按谱尺度归一化；先核对正则条件。
- 实测波宽、Δx/波宽及相邻 y 格点的相位增量 |logχ|，分别描述 x 与 y 的有效分辨率。
- 波速 p−q 与位移/初始波宽；静止波不能用此位移指标，另按交互时间尺度评价。
- 孤子脊线到有限域边界的距离，以局部波宽或相应 y 尺度归一化；ρ 主要通过相位位置进入，不能解释成单独的全空间增长参数。
- 当前背景的缺陷大小、方向、有限时间增益和边界闭合类别。

先沿受控参数路径识别变化：例如固定 p+q 调速度时，另核对正则裕量和剖面变化；固定每波宽点数比较不同宽度。参数之间无法完全独立时明确报告，不能把相关扫描解释成单因素因果关系。

比较三级预测：已有初始缺陷中位数因子；少量短时缺陷采样；包含沿背景传播的方向性预测。把预测成本纳入算法成本，避免用与完整求解等价的工作量声称便宜预测。

新参数先选定并锁定预测再推进验证。按谱参数族分组留出；只改变 ρ 的近亲不能算全新谱族。纳入 P5 类异常区、近正则边缘区和新 N2 配置，不只挑已有成功区域。原 P1/P6/P10 已成为已知基准，不再算新盲测。

建议输出：主导项分类、误差倍率偏差、首次越阈区间、预测成本及全部失败例。建议目标为留出误差量级大部分落在因子 2 内；具体通过比例在新参数确定前冻结。没有预定义抽样分布时不报告总体胜率或统计显著性。

## 5. 阶段 C：用预算选择一次有针对性的算法改进

| 诊断 | 优先候选 | 必须同时检查 |
|---|---|---|
| 模型误差主导 | 调整 h | 求解误差是否形成地板；两项是否抵消 |
| x 缺陷注入主导、放大温和 | 增加有效波宽分辨率，或比较一种更合适的 x 算子 | 同成本总误差与边界/尾部相容性 |
| 边界及输出重构主导 | 比较有明确问题定义的相容闭合 | 两模型同步；改变边界属于不同问题 |
| 高频传播增益主导 | 先判断增长的模型来源，再研究适用精度与时间窗 | 隐式或指数时间积分不会自动消除真实正增长模态 |
| 时间离散主导 | 时间步或推进器 | 必须先有时间误差实测证据 |

不预先承诺加密必然更好。更细 x 可以减小注入，也可能放开更强的高频增长。若后者被证实，研究成果可以是“可用分辨率—时间—精度区域”，无需强行做出长期稳定算法。

滤波或附加耗散若被引入，单列为正则化方案，量化其引入的偏差与原模型结构变化。精确背景平衡若依赖已知解，须增加未知非解族扰动，说明适用范围。每次只选择有诊断支持的一项改进及必要对照。

共同连续问题上的 SD/FD 使用相同物理初边值、比较位置和目标误差。FD 的求解层精度用通过交叉检查的同模型数值参照，不用 SD 有限 h Gram 代替。等节点数只衡量离散效率，同计算成本另测精度效率。

建议验收指标：预先指定留出配置，在两场目标精度都满足的前提下，比较总成本；或在固定成本下比较两场误差和可信传播距离。可把 20% 成本/误差改善作为实用门槛，保留退化案例，不能仅比较误差比而忽略绝对误差。

## 6. 多孤子迁移与移动网格恢复条件

多孤子先做一个有限任务：将阶段 A 的误差传播诊断迁移到 N2 的分离、重叠、离开三个短时窗口，并配匹配 N1 控制。已有超过 99.8% 的法向缺陷只相对于固定谱相位切空间；如扩展至幅度/宽度或谱参数切向，必须报告拟合条件数。法向不能直接命名为辐射。

新问题是“单孤子的误差机制能否解释局部多孤子失真，碰撞是否新增了不同放大机制”。这比再画一张 SD/FD 误差排名表更有信息量。完整散射仍要求不中途精确重置的连续轨道通过全过程双场门槛。

恢复移动网格研究的条件：固定或冻结网格的真实 DLW 轨道，在非零速度代表背景上至少准确传播约一个波宽，两场达到预定精度且有分辨率/时间步验证。随后从完全相同初始节点比较冻结、持续移动和间歇重分布，评价两个波宽内全过程误差及同成本收益；检查密度、最小点距和网格 Jacobian。

如果短期达不到该条件，网格部分以已验证的初始加密和受控输运机制收尾。受控输运可以支撑网格机制文章的限定命题，不能代替 DLW 验收。

## 7. 理论推进与论文定位

现有条件性 h 一致界已经使用离散乘积恒等式并控制新边界重构，不应再次把粗范数重推作为主要新成果。理论优先目标是在明确有限维问题、背景范围和时间窗内，给出可核对的“传播算子 + 缺陷 + 二次余项”后验控制，或解释分辨率与可信时间的关系。

若追求严格计算误差界，需控制整个时间区间的系数与缺陷，处理余项和浮点误差；有限时刻采样不能替代。只有范围清楚、常数有用的新命题才值得进入 Lean 形式化。现有 32/32 冻结目标的完成不等于新增数值误差定理已证明。

建议论文主张：可积半离散结构提供可核对的有限格距解族，从而支持分层误差诊断；误差传播分析进一步解释参数、边界与分辨率如何决定实际可计算性。SD 的流形保真优势与通用连续场误差排名分别陈述。

本阶段最小完整成果是：一个经新参数留出检验的误差预测方法、一套有证据支持的算法/分辨率选择规则，以及对其失败区域的明确说明。长期传播改善是后续验证目标，不作为预设结论。
