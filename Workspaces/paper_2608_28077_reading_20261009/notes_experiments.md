# 数值例、结论与对 2HS / DLW 的借鉴

来源：Chang–Liu–Tao, arXiv:2608.28077v2。以下页码均为 PDF 印刷页码（亦为 PDF 文件页序）。本记录仅阅读论文，不产生新的数值证据。

## 实验总设定与 sharp

- §5 开头，p.17：除特别说明外，时间推进采用经典四阶 Runge–Kutta，时间步 `Δt = O(h)`；误差指标是 `sqrt(E(U-u,R-r)) = sqrt(||U-u||² + ||R-r||²)`，其中 `R=U_x`，`r` 为 LDG 辅助导数变量。因此这里讨论的是离散能量范数中的精度，不是仅 `u` 的 L² 误差。
- p.3 最后一段明确说数值实验验证“predicted k-th order convergence”的 sharpness；p.17 Theorem 4.1 / (4.29) 给出 `||U-u||² + ||R-r||² ≤ C h^(2k)`，即范数误差 `O(h^k)`。`sharp` 的含义是观测到该 k 阶主导趋势，通常无法把这个范数的统一结论提高到 k+1 阶；它不是“峰子尖锐”，也不是得到最优常数。
- Theorem 4.1 限 `k≥1`，且 p.9 (4.1) 要求 `U,U_t ∈ L∞(0,T;H^(k+3)(Ω))`。例 5.1 的 P⁰ 行属于额外数值实验，不能说由该定理覆盖。
- p.3 提到可采用 relaxation Runge–Kutta [18] 实现全离散能量守恒/耗散，但 §5 并未明确说这些例子改用 RRK；p.23 结论明确分析只针对半离散，全离散留待后续研究。不可由空间半离散恒等式推出默认 RK4 的精确守恒。

例 5.1 直观数字：α=.5、N=640，守恒 P¹/P²/P³ 误差为 `1.13e-3 / 7.04e-6 / 6.33e-8`，最终观测阶 `1.01 / 2.00 / 2.75`（表 1）。耗散表 2 对应 `9.81e-4 / 6.59e-6 / 5.67e-8`。不能据这些数字声称耗散通量必定比守恒通量准确；峰子长期形状中趋势相反，问题和指标不同。

## 图中的能量漂移与理论范围

Theorem 3.1，p.7，(3.1)–(3.3)：两种空间半离散方案均保持 `∫m dx`；守恒通量有 `dE/dt=0`，耗散通量有 `dE/dt≤0`，`E=||u||²+||r||²`。峰子实验画的是 `E(0)-E(t)`，不等于“解的误差”；守恒了这个数也不自动意味着峰顶高度/位置准确。

作者在 p.21 用“near machine precision”描述例 5.4 的能量差。但图 3（p.22）守恒方案放大纵轴为约 `10^-8`（范围 -2e-9…1.2e-8）；图 4（p.24）守恒方案放大纵轴为约 `10^-10`（范围 -5e-11…4.5e-10）。导读宜称“能量漂移很小”，保留作者说法时说明图中绝对差量级；不能据此称双精度约 `10^-16` 的精确全离散守恒。

峰子属于连续但导数有跳跃的弱解，通常不属于 H²，更不满足 (4.1) 的高阶光滑性。因此论文两类结论应明确区分：光滑解有先验误差证明；峰子有数值捕捉证据。文章也没有证明 LDG 离散保持 Lax 结构、谱不变量、Poisson 结构或 Liouville 可积性。

## 对用户 2HS / DLW 项目可借鉴的内容

1. **先从能量/守恒结构反向设计通量。** 本文将高阶空间式改成一阶辅助变量系统，再用成对 LDG 算子的离散分部积分/相消设计守恒或耗散通量。可借鉴这个设计顺序，但 2HS、DLW 的未知量、符号、能量是否正定、边界项均须重新推导，不能照搬本篇的 `E=||u||²+||r||²`。
2. **同时记录剖面误差与结构误差。** 对 2HS/DLW 建议并排报告场误差、导数或辅助变量误差、守恒量漂移、峰位/峰高、正性或网格几何量；能量守恒与解准确度需要分别验证。本文正好提供“光滑收敛表 + 尖峰剖面 + 能量时间曲线”的组织范例。
3. **区分空间离散结论与时间推进结论。** 用户现有 DLW 的 C–N 迭代容差会污染细化阶这一背景下，尤其值得用小到足够的时间误差验证空间阶，再固定空间精度验证时间阶；若使用非线性迭代，也应使容差随 Δt 缩放或独立检查。本文 `Δt=O(h)` 的实验设计不能自动替代这些隔离检验。
4. **给近临界参数做独立解析度检查。** 表 3 的 α=.7 是很好的提醒：同样光滑，常数和所需 N 可以极大。对 2HS 的陡化、DLW 的高频增长或接近正性失效区，可按参数分组做网格加密，不能仅靠一组看似漂亮的局部阶。
5. **数值稳定性与可积离散分开评价。** 本文 p.2 将 [28,29] 的可积半离散另列；当前 LDG 是面向数值分析的高阶有限元路线。它可以作为用户可积半离散/传统差分的比较基准，但保存一项能量并不等于保持全部可积结构。
