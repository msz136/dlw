# 从唯一性到有公式的条件误差界

2026-10-24。证明稿，自查及代数/区间常数核验；不是原初始化存在证明。保留原方程、初值和下边界。

## 1. 前提必须由原问题另行提供

设 Z 为原问题的精确解，Zc 为同精确初值的近似轨迹，两者满足 INITIAL_VALUE_UNIQUENESS.md 所列强正则性。两者用原函数恢复 u，因此边界也相同。令 W=Z−Zc，H=L²(T_192×[0,4];R²)。近似轨迹的全连续方程残差为 f，满足 sup_t ||f||_H≤epsilon。不是有限网格采样残差。

精确差分为 W_t=AW+BW−f，W(0)=0。假设已证明统一常数

    ||BW||_H≤c1||W_X||_H+c0||W||_H,
    sup_t||W||_H≤M.

为得到物理场的一致误差，再假设 W 在 X,z,t 三个方向有统一 Lipschitz 常数 Lx,Lz,Lt（向量欧氏范数）。所有前提均条件于真解存在，当前原初值尚未验证它们。特别是 Lz 不能从候选的有限差分代替。

## 2. 含残差的加权能量不等式

取 0<r<s<T，phi(t)=exp(−ct)，c=4c1²+1，m=c exp(−cT)，K=8c1⁴+4c0²。
令 lambda≥max(1,2K/m)，chi=1 在[0,s]，在T处为零，|chi'|≤2/(T−s)，且chi'仅支撑于[s,T]。令 Y=exp(lambda phi)chi W。

唯一性证明的自伴恒等式与吸收步骤仍适用。此次右端增加 exp(lambda phi)chi f，使用

    ||BY+exp(lambda phi)(chi'W−chi f)||²
      ≤2||BY||²+4exp(2lambda phi)(|chi'|²||W||²+chi²||f||²)

可得明确上界

    J_r := integral_0^r ||W(t)||_H² dt ≤ Jbar,
    Jbar = 8/(lambda m) [
       T epsilon² exp(2lambda[1−phi(r)])
       + 4 T M²/(T−s)² exp(−2lambda[phi(r)−phi(s)]) ].       (C1)

截断可取分段线性，先平滑再取极限；上面的导数常数留有余量。初始 W=0 使时间边界项为零。该论证没有从小残差直接断言小误差：M及各系数界是必需前提。

## 3. 包括终点的全场一致界

任取 0<lx≤192、0<lz≤4、0<lt≤r。对每个(x,z,t)，取长度lx、lz、lt的单侧区间构成盒子，空间区间包含x,z，时间区间位于[0,r]。若t>r，使其紧贴r；否则包含t。任意盒中点到目标点的坐标距离不超过 lx,lz,T−r+lt。

盒中至少一个点的 |W| 不超过 sqrt(Jbar/(lx lz lt))。由 Lipschitz 界得到全闭柱上的

    sup |W| ≤ D := sqrt(Jbar/(lx lz lt))
                    +Lx lx+Lz lz+Lt(T−r+lt).              (C2)

因此完整物理场满足

    eta_u≤2 sqrt(2) D,   eta_v≤D/sqrt(2).                  (C3)

这里 u差=integral_0^z(alpha+beta)/2，v差=(alpha−beta)/2。若近似轨迹求值另有舍入/插值包围，应再加到对应物理误差。盒子论证不要求周期z；端点用单侧区间。

固定有限的先验常数时，这确实是趋零的条件误差模量：先选r靠近T及小盒边，使(C2)后三项小；再固定s∈(r,T)，增大lambda使(C1)第二项小；最后使epsilon足够小，压低第一项。因此它与此前无先验约束的小残差反例不矛盾。

## 4. 当前常数下的实际可用性检查

如果两条轨迹都在已有 rho=.1、R=.7 小球，可沿用 c1=20,c0=13，M≤1.4 sqrt(768)。这仍是对未知原解的假设，不是已证事实。取r=.009、s=.0095。仅为使(C1)第一项≤1，就必要要求

    log(epsilon) ≤ 0.5 log(lambda m/(8T))
                     −lambda(1−phi(r)).                  (C4)

对允许的lambda，此右端随lambda严格递减；最大值出现在lambda_min=2K/m。区间运算检查表明其对应的 log10(epsilon) 甚至小于 −10^9。即便把1e−12采样残差误当成已证全残差，此界也远远不能给出有用误差。

这只说明本次粗略加权估计的常数不实用，不是实际误差的下界，也不是任何算法都不可能认证。更强的系数处理可能显著改善它。当前更根本的存在性、真解先验界及严格全残差仍未取得。

## 5. 研究决策

本轮将“唯一性不能直接量化误差”补成一个有全部常数与物理范数转换的条件定理，并实际检验了当前常数。它不能完成本目标，不能给候选填写eta。下一步不应把这份粗估计当成现成验证器反复提高浮点精度，而应继续解决精确匹配/存在性，或利用方程结构改善先验估计。
