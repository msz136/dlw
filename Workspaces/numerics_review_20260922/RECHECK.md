## 剩余发现

### [P1] E6 仍不能称为实际开链求解器的最大增长率

位置：`Workspaces/dlw_semidiscrete/numerics/experiments/e6_growth.py` 中 `lh2=0.25`、`sigma_roots(abs(kv),l,h)` 和 `kpert_eff`；`e2_e3_solver.py` 的 `gmax_discrete` 有相同建模限制。

现在修正了 x 差分波数，但仍把固定格点相位 l 代入无限/周期格点的色散式，没有构造实际开链边界的线性化算子，也未对允许的格点模态取最大值。因此 `g_max_discrete` 是固定 l 下的 x 离散色散估计，不是实际开链全算子的谱上界。REPORT 速览和中心结论仍称其为“硬约束”“唯一的硬限制”，证据不够。

扰动实验另有确定的模板不匹配：预测使用 sin(θdx)/dx（二阶），实际 XGrid 使用四阶。独立作用于同一个 Fourier 向量：nx=64 的实际有效波数为 0.827885，预测用 0.754247；nx=128 为 1.655770 对 1.508494。扰动又是沿 j 常量、叠加在非零孤子背景上的 P 分量扰动，而公式使用非零 l 和零背景；它不是单个增长本征模，不能要求最大范数短时增长率等于该公式。

建议：先将现有预算明确改名为“固定格点相位的色散估计”，取消硬界表述；如要完成原验收，计算与边界相符的实际线性化谱，并以对应背景、本征向量和模式投影测增长。所有波数预测使用实际四阶算子。

所谓 E7 回归只检查已有 JSON 能读取，并无时间阶断言，也不执行当前 run。即使恢复旧的漏更新代码，只要保留 JSON，仍会 PASS。E1/E6 的多项检查也主要依赖已有输出或字段存在，未绑定源码哈希；`all(...)` 对空列表还可能通过。因此全部 PASS 不能替代行为验收。本次独立执行当前 E7 已确认修复有效，问题在防回归能力，而非当前 E7 结果。

建议：直接调用无副作用的推进函数做短时间自收敛并断言阶数；要求非空、有限值、成功到达目标时间。若采用预生成产物，核对生成源码哈希与运行参数。

### [P2] E1 把包含两端点的 x 网格当作不含重复端点的周期网格

位置：`experiments/e1_continuum.py:44`、`:90`。

`np.linspace(-1.5,1.5,25)` 默认包含两端，而 norms 使用全部等权求和；注释称 x 不含端点重复，并以此取消梯形半权重，理由不适用这个有限区间。对 [-1.5,1.5]² 上恒等于 1 的场，当前 L2 给出 3.061862，精确值为 3。与第一次审查不同，现在 dx 和 h 已补齐；剩下是 x 端点求积偏差，不推翻二阶趋势。

建议：当前 x 网格使用梯形权重，或改为明确定义的中点网格；周期不含重复端点的 E2/E3 网格则使用 dx 等权和。

### [P2] 新增 E5 守恒检测的格点编号和时间基准有误

位置：`experiments/e5_conservation.py` 第二个 `integrate_full` 内 `k=MID-(J_L+1)` 及后续积分。

u 和 W 都从 J_L 开始编号，只有 P 从 J_L+1 开始。用 P 的索引访问 u/W，实际检测 j=MID−1，却在 JSON 声称 site=MID。本次参数宣称 j=0，实际 j=−1。此错误不意味着守恒漂移一定变大，但指标对应错了格点。

另外，record 只在接受时间步后调用，IW[0]/Iv[0] 是第一个时间步之后的积分，缺少相对 t=0 的完整漂移；周期 x 网格还用了 `np.trapezoid`，漏掉最后一个周期区间。当前孤子尾部很小，所以影响可能被隐藏。小至 1e-16 的线性积分漂移可以源于离散导数的零均值结构，不能单独证明解精度或长期稳定。

建议：改为 k=MID−J_L；显式记录初态并使用周期 dx 求和；同时记录最终时间/失败原因，并报告守恒与解误差两类指标。
