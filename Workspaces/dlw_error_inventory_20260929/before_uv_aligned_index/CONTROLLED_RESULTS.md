我们只问：在原文单／二孤子上，离散化SD／SD2／FD、Euler／RK4、固定／自适应动网格，怎样改变共同物理场u、v的误差？

## 对照一：只换离散化——优势由算例决定

固定RK4、均匀固定网格和T=.01。以同一行FD误差为1；小于1较好，每格u/v。

| 算例 | SD / FD | SD2 / FD |
|---|---:|---:|
| 单孤子图1(a) | 0.703 / 0.841 | 7.56 / 8.59 |
| 单孤子图1(b) | 1.75 / 1.91 | 2.75 / 17.1 |
| 二孤子图3 | 1.16 / 1.77 | 2.70 / 27.5 |

**有效信息：SD和FD没有普遍赢家。** 仅原文的两个单孤子点，就足以否定“结构来源自动保证更小总误差”和“FD总是更好”这两个猜想。二孤子图3提供了相互作用波形上的对应观察，而不是更多同类单孤子重复。

补充的图4给出SD/FD=0.708/0.857，与图1(a)接近；图1(b)和含其谱对的图3均为FD较好。因此目前看不到“从单孤子变成二孤子就必然改变赢家”的证据。不能把不同谱参数下的差异全归因于孤子数量。

SD2栏回答的是完整方案的总误差。报告已说明SD2的初始物理场恢复和离散边界与SD/FD不完全一致，因此该栏不能单独裁决“Q/R变量本身是否较差”。图3固定组的v初误差为5.4135e−5，T=.01仍为5.3876e−5；仅看终点会把初始表示误差误认为全部由时间演化产生。不要用两个最大误差范数相减来消除它。

## 对照二：只换时间算法——时间阶与总误差排名是两件事

固定图3、均匀固定网格、各自离散化、相同Δt和T=.01。下表为Euler总误差 / RK4总误差。

| 离散化 | u比值 | v比值 |
|---|---:|---:|
| SD | 2.04 | 4.11 |
| SD2 | 0.584 | 1.25 |
| FD | 1.47 | 7.21 |

**有效信息：换RK4通常能明显降低这组时间误差，但总误差不保证每个分量都更小。** SD2的u是一个明确反例：Euler的总误差反而较小。报告给出的三档Euler时间步自收敛阶为0.9791–1.0003，支持一阶时间行为；它与上述反例并不矛盾，因为总误差还包含空间、初值恢复等有符号误差的抵消。

还有一个必须保留的“时间算法×离散化”交互：图3动网格T=.01，Euler下SD2的u误差7.1722e−6，低于FD的9.5557e−6；RK4下SD2为1.3851e−5，却高于FD的5.8074e−6。**某种离散化的名次不能脱离时间算法单独报告。** 这已由现有配对实验给出，无需新增参数扫描。

对时间误差估计，保留Δt、Δt/2、Δt/4的同空间数值场差来测阶。对总精度，仍对连续精确解比较。二者分开呈现；不把总误差比当时间阶。这里相同Δt比较精度，不声称相同计算成本。

## 对照三：只换网格方案——两场未必同时受益

固定图3、RK4、各自离散化和T=.01。下表为moving / fixed总误差。

| 离散化 | u比值 | v比值 |
|---|---:|---:|
| SD | 0.980 | 1.071 |
| SD2 | 0.597 | 0.511 |
| FD | 0.676 | 1.101 |

**有效信息：动网格不是统一的误差缩小系数。** FD的u改善约32%，v反而变差约10%；SD变化不大且两场方向不同；SD2在这组主配置双场改善。故不能只看u或只看一套离散化就宣布动网格占优。

这项实验比较“均匀固定”与“初始自适应布点＋持续移动”的两套网格方案，初始节点分布也变了。如果问题就是两套网格策略谁更准，这个对照有效；若进一步问收益来自初始布点还是后续移动，现有两组无法区分，才需要补一个“相同自适应初始节点、随后冻结”的组。

图4的细动网格在T=.02误差增加，给出适用范围的反例；它的贡献是阻止把粗网格收益外推，不是再增加一份主排名表。

## 当前缺口，只按问题补

二孤子已经有完整2时间法×3离散化×2网格主矩阵；单孤子当前同口径材料主要是RK4三离散化×两网格。旧短域单孤子Euler不能直接拼入这个矩阵。

若下一步只问“时间法结论能否迁移到单孤子”，优先在图1(b)固定网格补三离散化的Euler主／半／四分之一步，与现成RK4配对即可；无需立刻复制所有动格、扩域和更高阶时间算法。若要完整宣称单孤子的时间法×网格交互，再补对应动格组。此处是最小补测建议，本轮未运行。

若目标转向“哪个空间格式的误差常数更小”，则先用时间误差已小的RK4、固定网格，仅沿h_y加密，固定其他条件；发现Δx误差主导时才单独做x控制。当前主表给的是指定配置下总误差差异，尚不能据此拟合一般空间收敛阶或网格无关误差界。

目前最有根据的研究结论是：误差表现存在时间法、离散化和网格之间的交互，单独按可积性、时间阶数或是否动网格都不足以排序。下一步应沿一个清楚的配对问题增加证据，而不是继续扩大全部组合。
